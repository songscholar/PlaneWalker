# 3.4 祝福与诅咒系统深度设计

> **文档版本**: v1.1  
> **最后更新**: 2026-05-25  
> **适用游戏**: Plane Walker: Chronicles of Collapse  
> **设计目标**: 为祝福与诅咒系统提供首发可执行规格、储备池筛选规则、风险经济模型与边界条件

> v1.1收敛：本文档中的43个祝福和30个诅咒是完整设计储备池。首发默认启用25-30个祝福、15-18个诅咒。祝福只负责强化时间技能或武器流派；诅咒只负责高风险高回报和打法约束变化。纯ATK/HP/DEF/暴击等通用数值项必须降级为补短板、替换为机制效果，或移入扩展池。

## 3.4.1 系统设计哲学

### 祝福与诅咒的关系定位

祝福与诅咒是Build构建中的两个不同杠杆，但不再承担所有成长功能。道具负责触发器和特殊规则，天赋负责本局路线，魂祭坛负责补短板；祝福和诅咒只处理时间/武器专精与风险经济。

| 维度 | 祝福 | 诅咒 |
|------|------|------|
| 本质 | 时间技能/武器流派专精 | 双刃剑，增益伴随打法代价 |
| 风险 | 零风险 | 高风险高回报 |
| 决策压力 | "选哪个好"（优化型） | "要不要拿"（挣扎型） |
| 对角色强度的影响 | 强化已有打法，不新开独立Build池 | 提高上限，同时改变生存或输出规则 |
| 情感体验 | 专精感、打法成型感 | 紧张感、压迫感、赌上限 |

**核心定位原则**：祝福让玩家当前的时间技能或武器节奏更专精，诅咒让玩家用更苛刻的打法约束换更高上限。一个纯祝福Build是稳健路线，一个祝福-诅咒混合Build是高风险高上限路线；重诅咒Build只能作为高手挑战，不应成为最优默认解。

### 首发启用池筛选规则

首发版本不直接启用完整储备池，而是按以下规则筛选：

| 内容 | 首发目标 | 筛选标准 |
|------|----------|----------|
| 武器祝福 | 10-12个 | 每把武器至少2个，强化该武器独有节奏 |
| 时间祝福 | 8个左右 | 每个时间技能至少2个，明确改变站位、窗口或风险 |
| 通用祝福 | 5-8个 | 只做补短板或跨流派桥接，不做万金油数值 |
| 轻/中诅咒 | 12-14个 | 负面必须改变打法，例如视野、治疗、能量、站位、弹幕处理 |
| 重/极重诅咒 | 3-4个 | 只进入高难或特殊事件池，避免新手误拿毁局 |

每个首发祝福/诅咒必须标注服务的核心流派；无法标注的，只能标为"通用补短板"或进入扩展池。

### 风险-回报曲线设计原则

```
收益
 ^
 |          ·  (极重诅咒组合：理论上限极高，实际极难存活)
 |        ·
 |      ·    (中重诅咒：高回报区间)
 |    ·
 |  ·      (轻度诅咒：性价比较高)
 |·        (纯祝福：稳定线性增长)
 +--------------> 诅咒携带量/强度
```

**三条设计铁律**：

1. **第一个诅咒必须诱人但不能自动正确**：轻度诅咒的收益要足够明显，但负面必须让玩家调整打法，而不是无脑拿取。
2. **诅咒的边际负面增速大于边际增益增速**：第N个诅咒的负面效果增幅系数 = 1 + 0.15 × (N-1)，而增益增幅系数 = 1 + 0.05 × (N-1)。
3. **永远存在一条纯祝福通关路线**：任何诅咒都不是必需的，纯祝福Build可以通关最高难度，只是上限不如精心搭配的祝福-诅咒混合Build。
4. **纯倍率诅咒默认不进首发**：例如"+60%伤害 / -30%生命"必须改造成治疗规则、视野、能量、副作用或敌人行为变化后才可进入首发池。

### 选择困境的创造方法

通过四种机制创造有意义的选择困境：

1. **信息不对称困境**：首发版本不默认隐藏关键负面效果。隐藏代价只用于高难挑战、特殊事件或二周目内容，避免新玩家把风险经济理解成随机惩罚。
2. **时机困境**：祝福/诅咒的选择窗口有限（5秒倒计时），超时则随机选择或放弃。制造决策压力。
3. **排他困境**：同槽位互斥，选择A意味着永远放弃B（该局游戏中不再出现B）。同一层出现的3个选项只能选1个。
4. **累积困境**：当前已有的祝福/诅咒会影响后续可选项的权重。已有3个火焰相关祝福时，火焰诅咒出现概率+40%，但冰霜祝福出现概率-30%。

### 对游戏节奏的影响

| 游戏阶段 | 祝福/诅咒投放节奏 | 设计意图 |
|----------|-------------------|----------|
| 第1层（1-3房） | 1-2个祝福，0个诅咒选项 | 建立基础能力，安全感 |
| 第2层（4-6房） | 2-3个祝福，1个诅咒选项 | 诱惑出现，第一次"要不要拿" |
| 第3层（7-9房） | 1-2个祝福，1-2个诅咒选项 | 压力上升，开始取舍 |
| 第4层（10-12房） | 1个祝福，2-3个诅咒选项 | 背水一战，高回报高代价 |
| Boss前房 | 1个强力祝福或1个极重诅咒 | 最后的赌博 |
| Boss战后 | 1个净化机会或1个稀有祝福 | 奖励/修复 |

> 首发节奏约束：一局中玩家通常获得4-6个祝福、0-3个诅咒。超过此范围会显著提高认知负担，应只在高难、事件或特殊Build中出现。

## 3.4.2 祝福系统

### 祝福设计框架

#### 祝福获取规则

| 规则项 | 详细说明 |
|--------|----------|
| 获取时机 | 每层结束后进入"时间圣殿"，从3个祝福选项中选1个；精英怪击杀后额外获得1次选择机会（2选1）；Boss击杀后获得1次稀有祝福选择（2选1） |
| 选择UI | 暂停游戏，屏幕中央弹出3张祝福卡牌，展示名称、稀有度边框颜色、效果描述、数值；鼠标悬停展示完整信息面板（含与当前Build的交互提示） |
| 放弃规则 | 可选择"放弃全部"跳过本次选择，获得1个「时间碎片」（通用货币，50碎片可在商店购买1个祝福）；放弃后不可回退 |
| 重复规则 | 同一祝福不可重复获取；已拥有的祝福在选择池中被移除 |
| 锁定规则 | 上一次选择中未选的2个祝福，有30%概率在下一次选择池中重新出现（每个祝福独立判定） |

#### 祝福槽位设计

| 参数 | 数值 | 说明 |
|------|------|------|
| 最大祝福槽位 | 8 | 硬上限，不可突破 |
| 初始槽位 | 3 | 游戏开始时拥有 |
| 槽位解锁条件 | 第2层开始解锁第4槽；第3层解锁第5槽；击杀第1个Boss解锁第6槽；第4层解锁第7槽；击杀最终Boss前解锁第8槽 |
| 溢出处理 | 槽位满时仍可获取新祝福，但必须选择：替换一个已有祝福（被替换祝福永久消失）或放弃新祝福。替换时获得1个时间碎片作为补偿 |

#### 祝福稀有度分级

| 稀有度 | 颜色标识 | 出现权重 | 数值强度系数 | 说明 |
|--------|----------|----------|-------------|------|
| 普通（Common） | 白色 | 50% | ×1.0 | 基础数值，稳定可靠 |
| 稀有（Rare） | 蓝色 | 30% | ×1.5 | 显著提升，定义Build方向 |
| 史诗（Epic） | 紫色 | 15% | ×2.0 | 强力效果，可能改变玩法 |
| 传说（Legendary） | 金色 | 5% | ×3.0 | 局面改变者，极高数值 |

> **稀有度保底机制**：连续5次选择未出现稀有及以上祝福时，第6次必出至少1个稀有祝福；连续10次未出现史诗及以上时，第11次必出至少1个史诗祝福。

## 3.4.3 诅咒系统

### 诅咒设计框架

#### 诅咒获取规则

| 规则项 | 详细说明 |
|--------|----------|
| 获取时机 | 每层结束时，"时间圣殿"中除祝福选项外，额外出现1个诅咒选项（第1层不出现）；精英房间的"腐化宝箱"打开后必定获得1个诅咒（2选1）；Boss房间"深渊祭坛"可主动选择接受1个极重诅咒 |
| 选择UI | 与祝福类似但视觉风格不同——诅咒卡牌边框为暗红色，背景有裂纹动画；增益效果正常显示，负面效果中30%的诅咒有1项显示为"代价：？？？"（隐藏负面） |
| 接受后果 | 接受诅咒后立即生效，无法通过常规手段撤销 |
| 拒绝后果 | 拒绝诅咒时，当前房间内所有敌人获得10%攻击力和10%生命值加成（永久），且下次出现的诅咒选项强度+1级 |
| 重复规则 | 同一诅咒不可重复获取（与祝福相同） |

#### 诅咒槽位设计

| 参数 | 数值 | 说明 |
|------|------|------|
| 最大诅咒槽位 | 6 | 硬上限，达到6个后不再出现诅咒选项（替换规则仍可触发） |
| 初始槽位 | 0 | 游戏开始时无诅咒 |
| 槽位解锁 | 不需要解锁，获取第1个诅咒自动开启第1个槽位，依此类推 |
| 溢出处理 | 槽位满时，腐化宝箱和深渊祭坛仍可触发，但必须选择：替换1个已有诅咒（旧诅咒消失，新诅咒生效）或拒绝（同拒绝后果）。替换时，新诅咒的负面效果+10%（不可逆） |

#### 诅咒强度分级

| 强度等级 | 标识色 | 增益/负面比 | 出现权重 | 说明 |
|----------|--------|-------------|----------|------|
| 轻（Minor） | 暗绿 | 2.0:1 | 40% | 几乎总是值得的，轻微不便 |
| 中（Moderate） | 暗黄 | 1.5:1 | 30% | 明显增益+明显负面，需要Build配合 |
| 重（Major） | 暗橙 | 1.2:1 | 20% | 强力增益+严重负面，高风险高回报 |
| 极（Extreme） | 暗红 | 1.0:1 | 10% | 极端增益+极端负面，改变游戏方式 |

> **负面效果增幅系数**：第N个诅咒的所有负面效果数值 × (1 + 0.15 × (N-1))。即第2个诅咒负面×1.15，第3个×1.30，第4个×1.45，第5个×1.60，第6个×1.75。

#### 诅咒净化机制

| 净化方式 | 代价 | 说明 |

### 诅咒组合系统

#### 交互规则

| 规则 | 详细说明 |
|------|----------|
| 同类负面叠加 | 相同类型的负面效果（如多个减生命上限）按乘法计算，不是加法。例如CU-009（-25%）+CU-019（-50%）= 0.75 × 0.5 = 0.625，即-37.5%生命上限 |
| 同类增益叠加 | 相同类型的增益效果按加法计算。例如CU-001（+15%攻击）+CU-009（+25%攻击）= +40%攻击力 |
| 矛盾效果处理 | 若两个诅咒的增益和负面相互矛盾（如一个加移速一个减移速），取最终净值，但增益和负面独立计算后合并 |
| 互斥处理 | 某些诅咒组合会导致极端情况，设置下限保护：移速不低于基础40%，生命不低于基础10%，攻击力不低于基础50% |

## 3.4.5 平衡性设计

### 诅咒的风险-回报量化模型

采用"有效DPS提升率"与"有效生存降低率"的比值来量化诅咒的风险-回报：

**公式定义**：
```
回报指数 (ROI) = 有效DPS提升率 / 有效生存降低率

有效DPS提升率 = Σ(攻击力增益% + 攻速增益% × 0.7 + 暴击相关增益% × 0.5 + 其他输出增益% × 0.3)

有效生存降低率 = Σ(生命降低% × 1.0 + 受伤增加% × 0.8 + 移速降低% × 0.3 + 功能丧失等效% × 0.5)
```

**各强度诅咒的目标ROI范围**：

| 诅咒强度 | 目标ROI | 实际范围 | 说明 |
|----------|---------|----------|------|
| 轻 | 1.8-2.5 | CU-001: 2.2, CU-002: 2.4, CU-003: 1.9, CU-004: 2.1, CU-005: 2.0, CU-006: 1.8, CU-007: 1.9, CU-008: 2.5 | 轻度诅咒应"几乎总值得" |
| 中 | 1.3-1.8 | CU-009: 1.6, CU-010: 1.4, CU-011: 1.5, CU-012: 1.7, CU-013: 1.3*, CU-014: 1.4, CU-015: 1.5, CU-016: 1.3, CU-017: 1.5, CU-018: 1.4 | 中度诅咒需要Build配合才值得 |
| 重 | 1.0-1.3 | CU-019: 1.2, CU-020: 1.1, CU-021: 1.3**, CU-022: 1.1, CU-023: 1.0, CU-024: 1.2, CU-025: 1.1, CU-026: 1.0 | 重度诅咒仅在特定Build中有正ROI |
| 极 | 0.8-1.0 | CU-027: 0.9***, CU-028: 0.85****, CU-029: 0.95, CU-030: 0.9 | 极度诅咒单独ROI为负或勉强持平，需配合祝福/组合才超越1.0 |

| 4 | 危险模式 | 高风险，触发「黑暗蜕变」隐藏效果，生存需高度关注 | 需要至少2个防御祝福+1个免死祝福 |
| 5 | 极限模式 | 极高风险，触发「终焉华尔兹」，负面增幅严重 | 需要专门的诅咒流Build，大量防御祝福 |
| 6 | 走钢丝模式 | 瞬间死亡风险，触发「六道轮回」，持续0.5%/秒伤害 | 仅限最顶尖玩家，需完美操作+最优Build |

**设计目标**：大多数玩家的"舒适区"在2-3个诅咒。4个以上诅咒是高端挑战内容。6个诅咒通关应被视为"隐藏Boss级成就"。

### 极端Build的平衡锚点

以下是可能出现的极端Build及其平衡锚点（防止Build过强的安全阀）：

#### 极端Build #1：低血狂暴流
**核心组合**：CU-009暗影吞噬 + CU-011嗜血渴望 + BG-008狂暴之血 + BG-010吸血本能  
**峰值表现**：1%生命时攻击力+80%+25%=+105%，生命偷取11%×~100%效率=11%有效偷取，DPS约为基础的4-5倍  
**平衡锚点**：
- 生命锁定下限10%：无论如何降低生命上限和受伤增幅，生命不会低于基础的10%
- 即死伤害判定：若单次伤害超过当前生命+护盾总和，直接死亡（不经过0%生命阶段，无法偷取回复）
- AOE伤害不可全部偷取：同时受到多来源伤害时，偷取回复有上限（每次攻击回复不超过最大生命的5%）

#### 极端Build #2：无限时间流
**核心组合**：CU-020时间债务 + BT-001时间之眼 + BT-006悖论之力 + CU-012时间裂缝  
**峰值表现**：时间技能无消耗+效果+40%+能量+20%+回溯伤害保留，理论上可无限使用时间技能  
**平衡锚点**：
- 时间债务的-3%生命上限/次：硬性限制使用次数。10次后生命73%，15次后62%，20次后51%——即使无消耗，生命上限持续下降
- 时间技能共用全局CD：所有时间技能间有0.5秒最小间隔，防止无限循环
- 时间回溯伤害保留上限：悖论之力保留的回溯伤害上限为基础攻击力的500%

#### 极端Build #3：不死轮回流
**核心组合**：CU-028永劫轮回 + BG-018不灭意志 + BG-007坚韧意志  
**峰值表现**：死亡复活+5秒不死+1次免死，理论上可"死"3次才真正游戏结束  
**平衡锚点**：
- 永劫轮回每次复活生命上限-15%，6次后到达10%临界点
- 不灭意志每局仅1次（180秒CD且每局最多1次）
- 坚韧意志120秒CD，每层最多触发1次
- 到达10%生命上限后，任何超过当前生命的伤害=真死，无任何保护

#### 极端Build #4：全诅咒六道轮回流
**核心组合**：6个诅咒满槽触发「六道轮回」  
**峰值表现**：所有诅咒增益+30%，时间技能CD-30%，但0.5%/秒不可减免伤害（60秒内自动损失30%生命）  
**平衡锚点**：
- 六道轮回的持续伤害不可减免，不可被生命偷取/回复覆盖（回复正常生效但伤害独立扣除）
- 持续伤害导致"时间限制"——从触发六道轮回起，若无回复手段，200秒内必死（0.5%×200=100%）
- 回复手段上限：回复效果不可超过2%/秒（防止完全抵消持续伤害），确保六道轮回有真实的生存压力

#### 极端Build #5：终焉倒计时速杀流
**核心组合**：CU-030终焉刻印 + BG-012连锁反应 + BG-004战意高涨 + BG-009处决者  
**峰值表现**：全属性+30%+10%攻击+50%处决增伤+连锁击杀延长时间，理论上可无限延长倒计时  
**平衡锚点**：
- 终焉刻印600秒基础倒计时是硬限制——房间之间无敌人时无法延长
- 每层房间间的走廊/商店/圣殿时间计入倒计时（走路的5-10秒也在消耗）
- Boss战若超过120秒未击杀，倒计时可能耗尽（Boss击杀仅延长60秒）
- 即死不可被任何效果阻止（坚韧意志/不灭意志均无效）
