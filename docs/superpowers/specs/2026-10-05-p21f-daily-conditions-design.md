# P21F Complete Daily Native Conditions

- Status: Approved / Current
- Document Role: Current focused specification
- Authority Level: Below the full-product completion specification
- Applies To: Eight authored Daily conditions and native difficulty projections
- Owner: Plane Walker implementation team
- Depends On: `../../../AGENTS.md`, `2026-10-05-p21e-daily-rewards-design.md`
- Last Verified: 2026-10-05

The deterministic UTC+8 calendar chooses one or two distinct conditions from all
eight authored rules. Opposed melee/ranged specializations do not coexist.
Swift Finish enrages at exactly 3600 accepted Boss frames. Dodge Master owns one
additional dash during the native cooldown and removes exactly three base
invulnerable frames. Both dash charges recover when the normal cooldown ends.
Final Strike doubles newly emitted outgoing Boss attacks below ten percent HP.
Bullet Hell multiplies each projectile volley lane count by 1.5, rounded upward,
with unique native generation/hit identities and unchanged payload budgets.

Temporal Disorder doubles cooldowns and multiplies active stop/rift/accelerate
durations and rewind history capacity by 1.5. This duration/history interpretation
makes the original unspecified effect multiplier consistent across all four
abilities without changing damage or energy costs. The native starting Build is
installed before the duration multiplier, so authored duration bonuses also scale.

Daily-only Player behavior subclasses the production controller. Extra dash
state participates in fixed-frame rollback and the terminal native digest.
Canonical Boss definitions retain validated immutable Daily projection metadata.
Cold schema 1/2 saves from the original three-condition catalog migrate to the
new fingerprint without restoring consumed attempts or losing mode ownership.

Acceptance requires actual native dash/time effects, frame-bound enrage and HP
threshold tests, projectile reservations, migration/CAS tests, full existing
Daily regression, and scanned logs without script errors or leaks.
