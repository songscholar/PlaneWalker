## Contract

Only enrolled production native Flow scripts can authorize challenge ownership.
The authority binds Registry, Profile owner/domain, mode fingerprint and storage
scope, then inspects the promoted mode primary. Pending recovery is insufficient.
Exact native session validators derive earned entitlements and shop purchases.

The separate collection stores bounded owned/equipped IDs and at most two source
receipts. Ownership equals the receipts' union, selections require ownership and
cosmetic kinds are exclusive. Ordinary currency and the Launch item/cosmetic
pools retain their original contracts. Legacy Profiles default to an empty
collection; malformed collections refuse configuration.

Claims and equipment use expected revision and physical compare-exchange.
Before-promotion faults expose no ownership, after-promotion faults reconcile the
exact candidate, duplicate claims do not write and stale writers refuse.

The authored catalog freezes effects and presentation into a content-bound
projection with a canonical digest. Walker Proof supplies Boss damage1.15;
Speedwalker Boots supply move1.15/dash1.2. Follow-on runtime integration retains
the exact frozen projection in native Player, checkpoints and replay identity.

## Exit Gate

Real five-stage Boss Rush and seven-day Daily sources grant only earned rewards.
All six Profile save faults, retries, stale writers, legacy migration and corrupt
collections pass with clean Godot logs. Native equipment integration is retained
in a separate follow-on milestone.
