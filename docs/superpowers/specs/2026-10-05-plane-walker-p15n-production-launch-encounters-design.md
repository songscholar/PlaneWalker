Launch and Expansion runs resolve the complete activated Launch encounter catalog.
Recipes bind the actual floor node identity, room type and authored template;
selection uses the deterministic run seed and the existing node recipe resolver.
The M1 compatibility path retains its established catalog and timer behavior.

Native waves, warnings, actors and independently owned hostile payloads advance
only inside accepted Player frames. LaunchEncounterFrameAuthority coordinates
the pure encounter ledger with the exact native hostile effect owner. Published
spawn observations are retained until HostileFrameBridge finishes publication,
then acknowledged against native nodes before the next Player frame. The same
boundary publishes room completion only after all actors and pending work retire.

Actors instantiate the activated content's declared scene and definition,
bind a deterministic hostile source, accepted frame and native authored room
motion geometry, and join the production threat and frame authorities.
Final death receipts remove one matching roster row. Native Boss scenes and
their complete frame contracts are an independently reviewed prerequisite;
missing or incompatible actors fail closed without legacy substitution.

Completion requires production Main launch and actual Host route entry, native
anchor spawns, exact accepted frame identity, paused-frame wave stability,
physical hostile actions, authenticated deaths and finite payload retirement,
exactly-once room rewards, route cancellation and M1 regression coverage.
Arbitrary combat cold restoration remains the following checkpoint milestone.
