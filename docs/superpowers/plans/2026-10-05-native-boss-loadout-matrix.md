1. Enumerate exactly5x5x6x5 unique canonical identities. No legacy Warden,
   substitute damage records, direct Health writes or domain-only cases count.
2. Build each case with production BossRushCatalog/NativeBossArenaBuilder,
   actual Player/loadout, canonical Boss definition, room, effects and bridge.
   The test may choose initial position and semantic inputs. Player survival is
   protected by a declared test source; original weapon/Boss stats remain intact.
3. Run production primary/release/reload inputs and actual native physics until
   final Boss death. Each authored HP phase receives positive Player weapon
   damage. Damage traces retain authentic source, action generation, hit index,
   tags, phase and accepted frame; they are not manually constructed.
4. Both equipped time abilities commit through the actual Player transaction.
   Each pair retains at least one observed positive benefit: Boss Stop delay or
   exposure, actual Rift source/slow, an accelerated physical weapon hit or a
   production Rewind benefit. Time Sovereign response receipts remain actual.
5. Persist an active canonical native world checkpoint through typed Replay
   codec and physical SaveService. Reconstruct fresh actual actors, Player,
   payloads, summons and threats; compare the exact original next frame.
6. Final weapon death produces one canonical authenticated receipt, terminal
   native runtime, empty owned pending/live work and retired native constructs,
   status, controls and conversion sources. Dispose every case with no leaks.
7. Write a closed versioned JSON report containing content fingerprint, exact
   identity coverage, frames, authentic accepted traces, checkpoint digests,
   phase coverage and terminal outcome. Partial environment-selected runs are
   explicitly partial and cannot certify the750 total.

## Scope And Interpretation

The750-case production matrix certifies normal canonical loadouts. Its survival
fixture measures interaction compatibility rather than unassisted victory or
balance. Accelerated wall-clock physics must leave gameplay at the production
fixed60-frame rate. A separately declared hard matrix would contain another750
cases; it cannot be silently folded into the required count.

The30-seed22500 domain trace report, all48 primary/four response moves, every
arena interaction, hostile rollback at every publication boundary, five-floor
Host routing, native visuals, clean exports and human sessions remain separate
P15 Task12 requirements. Passing this focused matrix alone cannot close P15.
