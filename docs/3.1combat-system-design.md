## 3.1 战斗系统深度设计

### 3.1.1 战斗核心框架

#### 3.1.1.1 帧率基准

| 参数 | 值 | 说明 |
|------|-----|------|
| 目标帧率 | 60 fps | 所有帧数设计基于此 |
| 逻辑帧率 | 60 Hz | 逻辑与渲染同步 |
| 最小可接受帧率 | 30 fps | 低于此触发自动降级（粒子/特效减半） |
| 帧时间基准 | 16.667 ms | 1帧 = 16.667ms |
| 时间步进模式 | Fixed Timestep | DeltaTime 固定 1/60s，防止帧率波动导致逻辑不一致 |

#### 3.1.1.2 动作优先级系统

**行动中断规则**（高优先级可中断低优先级动作）：

| 优先级 | 动作类型 | 说明 |
|--------|----------|------|
| 5 (最高) | 闪避/Dash | 任何动作均可被闪避中断（受击硬直除外） |
| 4 | 格挡/Parry | 可中断普攻后摇、特殊技后摇 |
| 3 | 特殊技 | 可中断普攻后摇 |
| 2 | 普攻链下一击 | 仅可中断上一段普攻的后摇 |
| 1 (最低) | 移动 | 不中断任何攻击动作 |

**中断执行条件**：
- 闪避：在当前动作的**可取消窗口**内按下闪避键 → 立即切换至闪避状态
- 格挡：在当前动作的**可取消窗口**内按下格挡键 → 切换至格挡状态
- 特殊技：在当前动作的**可取消窗口**内按下特殊技键 → 切换至特殊技前摇
- 普攻链：在前一段普攻的**连招窗口**内按下攻击键 → 进入下一段普攻前摇

**不可中断状态**：
- 受击硬直（Hitstun）前3帧：完全不可中断（角色受控帧）
- 终极技演出期间：不可中断（设计选择，保证终极技完整演出）
- 换弹动画前8帧（枪）：不可中断

#### 3.1.1.3 硬直与取消机制

**动作三阶段定义**：

```
[前摇 Startup] → [活动帧 Active] → [后摇 Recovery]
```

- **前摇**：动作开始到产生判定的帧数，不可取消（除闪避）
- **活动帧**：判定生效的帧数，不可取消
- **后摇**：判定结束到动作结束的帧数，可被取消

**取消窗口规则**：

| 被取消动作 | 可取消起始帧 | 可被哪些动作取消 | 说明 |
|------------|-------------|-----------------|------|
| 普攻后摇 | 活动帧结束+2帧后 | 闪避、格挡、特殊技、下一击普攻 | +2帧为动作缓冲 |
| 特殊技后摇 | 活动帧结束+4帧后 | 闪避、格挡 | 特殊技后摇更长，取消窗口更窄 |
| 重击后摇 | 活动帧结束+3帧后 | 闪避、格挡、特殊技 | |
| 受击硬直 | 硬直第4帧起 | 闪避（消耗2倍闪避耐力） | 紧急闪避，代价更高 |
| 格挡成功后 | 0帧（瞬发） | 任何攻击动作 | 完美格挡后可立即反击 |
| 闪避结束后 | 0帧（瞬发） | 任何动作 | 闪避无敌帧结束即可行动 |

**输入缓冲系统**：

| 参数 | 帧数 | 说明 |
|------|------|------|
| 输入缓冲窗口 | 8帧 | 在可取消窗口前8帧内的输入会被缓存 |
| 连招输入窗口 | 12帧 | 普攻链的输入可提前12帧预输入 |
| 闪避输入优先 | 最高 | 缓冲中若有闪避输入，优先执行闪避 |

#### 3.1.1.4 受击反馈

**击退力计算公式**：

```
击退距离(base) = 攻击击退力 × (1 + 攻击者击退加成%) × (1 - 目标击退抵抗%)
击退速度 = 击退距离 / 击退持续帧数
击退持续帧数 = MAX(6, FLOOR(击退距离 / 3))
```

**击退力基准值**：

| 攻击类型 | 基础击退力 | 击退持续帧数(默认) |
|----------|-----------|-------------------|
| 剑普攻 | 1.5 格 | 8帧 |
| 剑重击 | 3.0 格 | 12帧 |
| 弓箭 | 1.0 格 | 6帧 |
| 枪射击 | 0.8 格 | 5帧 |
| 散弹 | 2.0 格 | 10帧 |
| 法术弹 | 1.2 格 | 7帧 |
| 拳套轻击 | 0.5 格 | 4帧 |
| 拳套重拳 | 2.5 格 | 11帧 |
| Boss攻击 | 2.0~4.0 格 | 10~15帧 |

注：1格 = 游戏内1个标准地砖宽度 = 1.0 世界单位

**无敌帧设计**：

| 触发条件 | 无敌帧数 | 说明 |
|----------|---------|------|
| 闪避 | 12帧 | 从闪避启动第1帧开始计算 |
| 受击后 | 15帧 | 从受击硬直结束开始计算（防连击陷阱） |
| 完美格挡成功 | 8帧 | 格挡反击判定期间 |
| 起身 | 20帧 | 被击倒后起身期间 |

**受击硬直时长**：

| 受击类型 | 硬直帧数 | 角色状态 |
|----------|---------|----------|
| 轻受击（单次伤害 ≤ 最大HP 5%） | 12帧 | 小幅后仰 |
| 中受击（单次伤害 > 最大HP 5%，≤ 15%） | 20帧 | 明显后仰 |
| 重受击（单次伤害 > 最大HP 15%） | 30帧 | 大幅击退 |
| 击倒（单次伤害 > 最大HP 25%） | 45帧（含起身20帧） | 倒地 → 起身 |

| HEAL_MULT | 治疗增幅 | Heal Multiplier | 1.0 | 乘算 | |
| LUCK | 幸运值 | Luck | 0 | 线性叠加 | 影响掉落和Proc率 |

**属性计算优先级**（从高到低）：

1. 百分比乘算增幅（如"攻击力+30%"） → 先累加所有同类百分比，再乘算
2. 固定值加成（如"攻击力+5"） → 线性叠加
3. 最终乘区（如"伤害×2"诅咒效果） → 最后乘算

**公式化**：

```
最终属性 = (基础值 + Σ固定加成) × (1 + Σ百分比加成) × Σ最终乘区
```

**攻速对帧数的影响**：

```
实际帧数 = ROUND(基础帧数 / 攻击速度)
下限：基础帧数的40%（攻速2.5时）
```

### 3.1.2 伤害公式体系

#### 3.1.2.1 基础伤害计算公式

```
最终伤害 = FLOOR(
  (攻击力 × 技能倍率 × 类型修正 - 防御减伤值)
  × 暴击修正
  × 伤害类型交互修正
  × 各种最终乘区
  × 随机波动
)
```

**随机波动**：

```
随机波动 = 0.95 + RANDOM() × 0.10    // 范围 [0.95, 1.05]，即 ±5%
```

#### 3.1.2.2 暴击系统

| 参数 | 公式/规则 |
|------|----------|
| 暴击判定 | `RANDOM() < 暴击率` → 暴击 |
| 暴击修正 | 暴击时 `暴击修正 = 暴击伤害值`，否则 `暴击修正 = 1.0` |
| 暴击率上限 | 75%（硬上限，任何加成不可超过） |
| 暴击伤害下限 | 100%（不会低于1.0） |
| 保底暴击 | 连续5次非暴击后，第6次必定暴击 |

**暴击率计算示例**：

```
基础暴击率 = 5%
+ 装备加成 = 20%
+ 祝福加成 = 15%
+ 临时Buff = 10%
= 总暴击率 = 50%
实际判定: RANDOM() < 0.50
```

#### 3.1.2.3 防御与减伤计算

```
防御减伤率 = DEF / (DEF + 100)        // 渐近线公式，最大趋近50%
防御减伤值 = 攻击力 × 技能倍率 × 防御减伤率
```

**防穿机制**：

```
实际DEF = MAX(0, DEF - 攻击方穿甲值)
```

**减伤叠加规则**：

```
独立减算公式:
最终受伤 = 原始伤害 × (1 - 减伤A) × (1 - 减伤B) × (1 - 减伤C) ...
每种减伤来源独立乘算，不存在加算叠加
```

**减伤上限**：单次伤害减免不超过原始伤害的90%（至少受10%伤害）

#### 3.1.2.4 伤害类型及交互

四种伤害类型：

| 类型 | 标识 | 特性 |
|------|------|------|
| 物理 | PHY | 基础类型，受DEF减免，无特殊交互 |
| 时间 | TIM | 不受DEF减免（无视50%DEF），可触发时间相关特效 |
| 虚无 | VOD | 无视100%DEF，对处于异常状态目标+25%伤害 |
| 元素 | ELE | 受DEF减免，可触发元素反应 |

**类型交互矩阵**：

| 组合 | 效果 | 触发条件 | 数值 |
|------|------|----------|------|
| 物理+时间 | 时断打击 | 同一击中同时存在 | 该次伤害+15%，目标受击硬直+8帧 |
| 物理+虚无 | 虚空裂伤 | 同一击中同时存在 | 该次伤害+20%，附加3秒流血（每秒10%攻击力的物理DOT） |
| 时间+虚无 | 熵增 | 同一击中同时存在 | 该次伤害+30%，目标被"时间标记"5秒（受到的所有时间伤害+50%） |
| 物理+元素 | 元素共鸣 | 同一击中同时存在 | 该次伤害+10%，触发元素二次伤害（50%攻击力的同类型元素伤害） |
| 时间+元素 | 时空风暴 | 同一击中同时存在 | 该次伤害+20%，在命中点产生半径2格的时空力场3秒（区域内敌人减速30%） |
| 虚无+元素 | 虚化焰 | 同一击中同时存在 | 该次伤害+25%，附加"虚化"状态3秒（目标受到的所有伤害+15%） |

**交互触发规则**：
- 同一击中：单一攻击判定同时携带两种伤害类型
- 不同攻击的两种类型命中同一目标，若间隔≤30帧（0.5秒），也触发交互
- 同一交互效果3秒内不可重复触发（内置CD）

#### 3.1.2.5 DOT伤害规则

| 参数 | 规则 |
|------|------|
| 刻间隔 | 30帧（0.5秒/次） |
| 计算公式 | `DOT伤害/刻 = 基础DOT值 × DOT增幅 × 随机波动` |
| 暴击 | DOT不暴击（来源暴击时，初始DOT值+20%） |
| 叠加 | 同类型DOT取最高值不叠加；不同类型DOT各自独立 |
| 刷新 | 同类型DOT重新施加时刷新持续时间，不重置伤害 |
| 减速影响 | 时间减速不影响DOT刻间隔（按真实时间计算） |
| 死亡判定 | DOT可致死（不会留下1HP） |

**标准DOT状态列表**：

| DOT名称 | 伤害/刻 | 持续时间 | 来源 |
|---------|---------|---------|------|
| 流血 | 攻击力×8% | 6秒(12刻) | 物理+虚无交互 |
| 灼烧 | 攻击力×10% | 4秒(8刻) | 火元素法术 |
| 虚无侵蚀 | 攻击力×6% | 8秒(16刻) | 虚无属性攻击 |
| 时间衰减 | 攻击力×5% | 10秒(20刻) | 时间属性攻击 |

#### 3.1.2.6 伤害数字浮动显示规则

| 参数 | 规则 |
|------|------|
| 显示位置 | 目标头顶偏上1.5格，随机X偏移±0.3格 |
| 上升速度 | 2.0格/秒 |
| 显示时长 | 60帧(1秒) |
| 淡出 | 最后15帧从alpha 1.0线性淡出到0 |
| 合并 | 同一目标30帧内受到多次伤害，数字叠加不重复生成 |
| 字号规则 | 基础14pt，伤害每超过当前阶段平均DPS的50%字号+2pt，上限28pt |
| 颜色规则 | 普通伤害：白色；暴击：金黄+放大1.3倍；时间伤害：青色；虚无伤害：紫色；元素伤害：对应元素色(火红/冰蓝/雷黄)；DOT：对应颜色+字号缩小至10pt |

### 3.1.4 战斗节奏设计

#### 3.1.4.1 单次战斗时长预期

| 房间类型 | 敌人数量 | 预期战斗时长 | 说明 |
|----------|---------|-------------|------|
| 普通战斗房 | 4~8只 | 25~40秒 | 小怪血量低，主要测试清场效率 |
| 精英房 | 1~2只精英+2~4只小怪 | 50~70秒 | 精英怪血量×3~5，需要躲避技能 |
| Mini-Boss房 | 1只Mini-Boss | 60~90秒 | 单体高血量，有阶段转换 |
| Boss房 | 1只Boss(+小怪波次) | 120~180秒 | 3阶段Boss，每阶段40~60秒 |

**设计依据**：
- 普通房节奏快，不拖沓，给玩家"爽快感"
- 精英房需要1~2次攻防切换，考验操作
- Boss房需要2~3次攻防循环+时间技能管理

#### 3.1.4.2 攻防切换频率目标

| 房间类型 | 攻防切换频率 | 说明 |
|----------|-------------|------|
| 普通房 | 每5~8秒一次 | 以进攻为主，偶尔闪避 |
| 精英房 | 每3~5秒一次 | 精英攻击密集，需要频繁闪避/格挡 |
| Boss房 | 每2~4秒一次 | Boss攻击窗口短，需要精确闪避后反击 |

**"攻防窗口"定义**：
- 攻击窗口：Boss/精英攻击后摇期间（可安全输出时间）
- 防御窗口：Boss/精英攻击判定期间（需要闪避/格挡的时间）

#### 3.1.4.3 DPS健康范围

**基准**：以基础攻击力(无Build加成)和标准攻速为参照

| 武器 | 第1层目标DPS | 第3层目标DPS | 第5层目标DPS | Build成型后DPS |
|------|------------|------------|------------|--------------|
| 剑 | 45~55 | 55~70 | 70~90 | 120~200 |
| 弓 | 35~45(满蓄) | 50~65 | 65~85 | 150~250 |
| 枪 | 50~60 | 60~75 | 75~95 | 130~220 |
| 杖 | 40~50 | 55~70 | 70~90 | 140~240 |
| 拳套 | 40~50(0连击) | 50~65(低连击) | 65~80(中连击) | 160~280(高连击) |

**DPS计算方式**：

```
理论DPS = (攻击力 × 平均倍率 × 暴击期望 × 类型修正) / 平均攻击周期(秒)
暴击期望 = 1 + 暴击率 × (暴击伤害 - 1)
```

**各武器理论DPS推导**：

**剑(无Build)**：
- 普攻链总倍率：1.0+1.2+1.5×2+2.5 = 7.7
- 普攻链总帧数：17+16+21+26 = 80帧 = 1.333秒
- 平均倍率/秒 = 7.7/1.333 = 5.78
- 攻击力12，DPS ≈ 12 × 5.78 × 1.05(暴击期望) ≈ 72.9
- 考虑走位/闪避损耗(实际输出时间约70%)：实际DPS ≈ 51

**弓(无Build,平均蓄力1段)**：
- 蓄力1段周期：22帧(蓄力)+14帧(后摇) = 36帧 = 0.6秒
- 每秒倍率 = 1.8/0.6 = 3.0
- 攻击力8，DPS ≈ 8 × 3.0 × 1.05 ≈ 25.2（蓄力1段偏低）
- 实际弓以快速射击+偶尔满蓄混合：约40DPS

**拳套(无Build,15连击)**：
- 普攻链总倍率：0.8+0.9+1.2+1.3+3.0 = 7.2
- 普攻链总帧数：11+10+13+13+25 = 72帧 = 1.2秒
- 攻速加成(15连击) = +15% → 实际帧数72/1.15 ≈ 63帧 = 1.05秒
- 平均倍率/秒 = 7.2/1.05 = 6.86
- 攻击力6，DPS ≈ 6 × 6.86 × 1.12(暴击期望含12%暴击) ≈ 46.1
