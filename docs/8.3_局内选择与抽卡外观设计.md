## 8.3.1 局内选择系统核心设计

### 选择场景总览

游戏中所有需要玩家做出选择的场景统一使用"时间裂隙选择框架"（Temporal Rift Choice Framework），保证交互一致性与视觉辨识度。选择场景共有6种，触发条件与规则各有不同：

| 选择场景 | 触发条件 | 选项数量 | 时间压力 | 暂停规则 | 对应章节 |
|----------|----------|----------|----------|----------|----------|
| 道具选择 | 精英房/Boss房/宝藏房完成后 | 2~3选1 | 无限时 | 全局暂停 | 8.3.1.3 |
| 祝福选择 | 每层结束后进入时间圣殿 | 3选1 | 无限时 | 全局暂停 | 8.3.1.4 |
| 诅咒接受 | 特定事件/商店/暗市商人 | 1~2选1 | 部分有限时5秒 | 全局暂停 | 8.3.1.5 |
| 天赋选择 | 每层结束后与祝福选择交替 | 3选1 | 无限时 | 全局暂停 | 8.3.1.6 |
| 事件选择 | 事件房触发 | 2~3选1 | 无限时 | 全局暂停 | 8.3.1.7 |
| 商店购买 | 商店房/特殊商人交互 | 不限 | 无限时 | 不暂停（购买界面叠加） | 8.3.1.8 |

**选择流程总图：**

### 统一选择UI框架

#### 选择界面通用布局（1920×1080基准）

所有选择界面共享同一基础框架，仅在卡片数量、装饰元素和背景氛围上做场景差异化。

#### 信息展示层级

为避免信息过载，采用三级信息展示机制：

| 层级 | 触发方式 | 展示内容 | 位置 |
|------|----------|----------|------|
| **一级信息** | 卡片默认可见 | 图标、名称、稀有度、分类标签 | 卡片内 |
| **二级信息** | 鼠标悬停(Hover)0.3秒 | 效果描述、Flavor Text、联动提示、堆叠信息 | 卡片内展开 |
| **三级信息** | 鼠标悬停1秒 / 按住Shift | 完整数值面板、与当前Build的详细交互提示、同类道具对比 | 卡片右侧弹出详情面板 |

#### 选择确认/取消交互

| 操作 | 键鼠 | 手柄 | 效果 |
|------|------|------|------|
| 选中卡片 | 鼠标左键点击卡片 | A键 | 卡片放大1.1倍+确认光效，0.3秒后应用效果 |
| 查看详情 | 鼠标悬停 / Shift+悬停 | 按住X | 展开二级/三级信息 |
| 放弃选择 | 点击"放弃"按钮 / Esc | B键 | 弹出确认框："确定放弃？将获得时间碎片×1" |
| 重Roll | 点击"重Roll"按钮 / R键 | Y键 | 消耗重Roll资源，重新生成选项 |
| 快速选择 | 数字键1/2/3 | 方向键←→+A | 直接选择对应位置的卡片 |
| 后悔期 | 确认后1.5秒内按Esc | 确认后1.5秒内按B | 撤回选择（仅道具选择可用） |

#### 选择时的暂停规则

| 选择场景 | 暂停范围 | 时间效果 | 背景动画 |
|----------|----------|----------|----------|
| 道具选择 | 全局暂停，所有游戏逻辑冻结 | 时间能量停止消耗 | 背景粒子缓慢飘浮 |
| 祝福选择 | 全局暂停 | 同上 | 时间圣殿氛围（金蓝光效） |
| 诅咒接受 | 全局暂停 | 同上 | 暗紫光效，屏幕微震 |
| 天赋选择 | 全局暂停 | 同上 | 蓝白符文光效 |
| 事件选择 | 全局暂停 | 同上 | 场景叙事动画播放 |
| 商店购买 | **不暂停**，叠加UI | 时间继续流逝 | 无变化 |

**暂停实现：** `Engine.time_scale = 0.0f` + 选择界面使用 `unscaledDeltaTime` 驱动UI动画。

### 道具选择界面

#### 触发条件

| 触发源 | 触发时机 | 选项数 | 稀有度偏移 |
|--------|----------|--------|-----------|
| 普通战斗房完成 | 击杀所有敌人后，5%概率触发 | 2选1 | 无偏移（标准权重） |
| 精英房完成 | 击杀精英后 | 3选1 | uncommon_mult×1.5, legendary_mult×2.0 |
| Boss房完成 | Boss击杀后 | 3选1 | legendary_mult×3.0, mythic_mult×2.0 |
| 宝藏房（普通宝箱） | 开箱时 | 2选1 | uncommon_mult×1.5 |
| 宝藏房（黄金宝箱） | 开箱时 | 3选1 | legendary_mult×2.0, mythic_mult×1.0 |
| 时间裂隙房 | 交互时 | 3选1（仅时间型道具池） | legendary_mult×2.0, mythic_mult×3.0 |

**排序规则（替换界面中的已有道具排列）：**

```
function sortItemsForReplacement(existingItems, newItem):
    for item in existingItems:
        score = 0
        // 联动因子
        if hasSynergy(item, newItem): score += 100
        // 稀有度因子（低稀有度排前面=更容易被替换）
        score -= item.rarity_tier * 30  // common=0, uncommon=1, legendary=2, mythic=3
        // 堆叠因子（低层叠排前面）
        score -= item.current_stack * 5
        // 功能重复因子（同类效果排前面）
        if item.category == newItem.category: score += 20
        item.replacement_score = score
    return sort(existingItems, by=score, descending=true)
```

#### 选项后果的暗示设计

不直接明说结果，但通过视觉和文字线索给予暗示：

| 暗示手段 | 具体方式 | 玩家学习成本 |
|----------|----------|-------------|
| **图标暗示** | 每个选项前有1~2个小图标，暗示代价/奖励类型 | 低（直觉性） |
| **文字色彩暗示** | 选项文字中的代价词用红色，奖励词用绿色 | 低 |
| **边框色暗示** | 悬停时边框颜色倾向：绿=正面为主、红=风险为主、金=高稀有度、紫=诅咒相关 | 中 |
| **NPC表情暗示** | NPC残影选择某个选项时做出微表情（微笑/皱眉/恐惧） | 中 |
| **Flavor Text暗示** | 选项下方1行小字："据传这曾让一名行者……" | 高（需阅读理解） |
| **环境暗示** | 选择某选项时背景发生微变化（光变亮/暗，粒子增多/减少） | 高 |

**暗示设计原则：**
1. 第1~2层事件：暗示明显（图标+颜色+边框），帮助新玩家学习
2. 第3~4层事件：暗示中等（图标+颜色），需要一定经验
3. 第5层事件：暗示隐蔽（仅Flavor Text），高风险高回报

## 8.3.2 抽卡/Gacha系统

### 设计决策

#### 核心定位：纯装饰性抽卡

**决策：** 本游戏采用"时空祈愿"抽卡机制，**所有抽卡获取的物品均为纯装饰/外观性质，不影响任何数值**。

| 维度 | 决策 | 理由 |
|------|------|------|
| 抽卡是否影响数值 | **否，纯装饰** | 保留Roguelike公平性核心，避免P2W争议 |
| 抽卡与核心玩法的关系 | 纯平行，不影响局内 | Steam单机游戏，社区对P2W极度敏感 |
| 抽卡货币 | 存在印记(Existence Mark) | 通过游戏内获取(通关/成就/挑战) + 可选真实货币购买 |
| 抽卡核心情感 | 收集欲+个性化表达 | 让玩家"我的行者与众不同" |
| 商业模型 | 抽卡+DLC外观包 | 抽卡为持续收入，DLC为大型内容包 |

|--------|------|----------|------|

**抽卡实现代码：**

```text
public class GachaSystem
{
    private int pityLegendary = 0;  // 传说保底计数
    private int pityMythic = 0;     // 神话保底计数

    public GachaResult Roll(bool isTenPull = false)
    {
        int count = isTenPull ? 10 : 1;
        var results = new List<GachaItem>();

        for (int i = 0; i < count; i++)
        {
            pityLegendary++;
            pityMythic++;

            // 硬保底
            if (pityMythic >= 500)
            {
                results.Add(GetMythicItem());
                pityMythic = 0;
                pityLegendary = 0;
                continue;
            }
            if (pityLegendary >= 100)
            {
                results.Add(GetLegendaryItem());
                pityLegendary = 0;
                continue;
            }

            // 软保底：50抽后传说概率+2%/抽
            float legendaryRate = 0.09f;
            if (pityLegendary > 50)
            {
                legendaryRate += (pityLegendary - 50) * 0.02f;
                legendaryRate = math.Min(legendaryRate, 1.0f);
            }

            // 神话软保底：200抽后神话概率+0.5%/抽
            float mythicRate = 0.01f;
            if (pityMythic > 200)
            {
                mythicRate += (pityMythic - 200) * 0.005f;
                mythicRate = math.Min(mythicRate, legendaryRate); // 不超过传说率
            }

            float roll = Random.value;
            if (roll < mythicRate)
            {
                results.Add(GetMythicItem());
                pityMythic = 0;
                pityLegendary = 0;
            }
            else if (roll < mythicRate + legendaryRate)
            {
                results.Add(GetLegendaryItem());
                pityLegendary = 0;
            }
            else if (roll < mythicRate + legendaryRate + 0.30f)
            {
                results.Add(GetUncommonItem());
            }
            else
            {
                results.Add(GetCommonItem());
            }
        }

        // 十连保底：至少1个稀有及以上
        if (isTenPull && results.All(r => r.Rarity == Rarity.Common))
        {
            results[9] = GetUncommonItem(); // 最后一抽强制稀有
        }

        return new GachaResult(results);
    }
}
```

#### 抽卡动画设计——时间裂缝效果

**单抽动画（总时长3.5秒）：**

| 时间 | 动画 | 音效 |
|------|------|------|
| 0~0.5s | 屏幕中央出现小型时间裂隙(紫色→蓝色渐变)，缓慢扩张 | 低频嗡鸣渐强 |
| 0.5~1.5s | 裂隙爆发，金色光芒涌出，屏幕白闪0.1秒 | 玻璃碎裂音+冲击波音 |
| 1.5~2.5s | 稀有度决定性画面：白=微光回落 / 绿=绿光脉冲 / 金=金色粒子环绕 / 彩虹=屏幕彩虹闪光+震屏 | 白=轻微叮 / 绿=清脆叮 / 金=钟声 / 神话=合唱音 |
| 2.5~3.5s | 物品卡片从裂隙中飞出居中，放大到300×300px展示 | 卡片出现音(纸张声) |

**十连动画（总时长8秒）：**

| 时间 | 动画 | 音效 |
|------|------|------|
| 0~1.0s | 巨大时间裂隙开启(比单抽大2倍)，紫蓝能量汇聚 | 强力嗡鸣+低频脉动 |
| 1.0~2.0s | 裂隙稳定，10道光束依次射出(每0.1秒1道) | 每道光束1个短音 |
| 2.0~5.0s | 10张卡片在屏幕中以环形排列，依次翻面展示稀有度(0.3秒/卡) | 翻面音(不同稀有度不同音高) |
| 5.0~6.0s | 最高稀有度的卡片飞到中央放大展示 | 对应稀有度音效 |
| 6.0~8.0s | 全部10张卡片缩小排列在结果面板中，玩家可逐一点击查看 | 背景音渐弱 |

**跳过动画：** 任意时刻按Esc/Space/B键可跳过，直接显示结果面板。

## 8.3.3 皮肤/外观/装饰系统

### 外观系统概览

外观系统允许玩家自定义角色的视觉表现，所有外观物品均为纯装饰，**不影响任何数值**。

**可自定义的外观维度（8个维度）：**

| 维度 | 代码 | 槽位 | 默认数量 | 可解锁数量 | 说明 |
|------|------|------|----------|-----------|------|
| 角色皮肤 | COS_SKIN | 1 | 5(每角色1) | 10 | 整体外观替换 |
| 武器外观 | COS_WEAPON | 1 | 5(每武器1) | 15 | 武器模型替换 |
| 技能特效 | COS_SKILL_FX | 1 | 1(默认) | 6 | 核心攻击特效替换 |
| 击杀特效 | COS_KILL_FX | 1 | 1(默认) | 4 | 击杀敌人时的消散效果 |
| 时间特效 | COS_TIME_FX | 1 | 1(默认) | 3 | 时间操控视觉效果 |
| 称号 | COS_TITLE | 1 | 0 | 20+ | 角色名下方显示的文字 |
| 头像框 | COS_AVATAR_FRAME | 1 | 1(默认) | 8 | 存档界面/排行榜头像边框 |
| 足迹 | COS_FOOTPRINT | 1 | 1(默认) | 5 | 移动时地面留下的痕迹 |

**外观数据结构：**

```text
[System.Serializable]
public class CosmeticSlot
{
    public string slot_id;        // "COS_SKIN"
    public string equipped_id;    // 当前装备的外观ID
    public List<string> unlocked; // 已解锁的外观ID列表
}

[System.Serializable]
public class CosmeticItem
{
    public string id;             // "SK-SWD-001"
    public string name;           // "苍穹审判者"
    public string slot;           // "COS_SKIN"
    public Rarity rarity;         // 稀有度
    public string scene_path;     // PackedScene路径
    public string icon_path;      // 图标路径
    public string source;         // 获取来源: "gacha"/"achievement"/"shop"/"hidden"/"dlc"
    public string source_detail;  // 具体来源描述
    public bool is_default;       // 是否默认外观
}
```

#### 预览功能

| 操作 | 效果 |
|------|------|
| 点击外观卡片 | 角色预览区实时切换该外观(0.3秒渐变过渡) |
| 悬停外观卡片 | 角色预览区叠加该外观的半透明预览(alpha=0.5) |
| 点击"预览动画" | 角色预览区播放该外观的攻击/移动/待机动画循环 |
| 切换槽位标签 | 角色预览区保持其他槽位已装备外观，仅替换当前槽位预览 |

#### 组合展示

外观系统支持自由组合——皮肤+武器+特效可以跨稀有度、跨风格搭配。

- 组合预览在左侧角色预览区实时反映
- 无"套装"硬性绑定（不像某些游戏必须成套才有效果）
- 但某些"主题组合"有特殊的组合展示提示：
  - "苍穹审判者皮肤 + 原界裁决者剑" → 提示"神圣裁决组合"（纯文字提示，无额外效果）
  - "深渊漫步者皮肤 + 虚无裂隙剑 + 虚无侵蚀特效" → 提示"虚无行者组合"
  - 共8组主题组合，均为纯装饰性文字提示

public interface IChoiceProvider
{
    ChoiceType Type { get; }
    List<ChoiceOption> GenerateOptions(PlayerState player, ChoiceContext context);
    void OnChoiceMade(ChoiceOption selected, PlayerState player);
    void OnChoiceSkipped(PlayerState player);
    bool CanReroll(PlayerState player);
    int GetRerollCost(PlayerState player);
}

// 选择选项数据
[System.Serializable]
public class ChoiceOption
{
    public string id;
    public string name;
    public string icon_path;
    public Rarity rarity;
    public string mechanic_text;
    public string flavor_text;
    public List<SynergyHint> synergies;
    public bool is_new_discovery;
    public Dictionary<string, float> stats; // 数值详情
    public string time_interaction;         // 时间系统交互描述
}

// 选择上下文
public class ChoiceContext
{
    public ChoiceSource source;  // ELITE_ROOM, BOSS_ROOM, TREASURE, etc.
    public int current_floor;    // 当前层(1-5)
    public int rooms_cleared;    // 已清房间数
    public float luck_modifier;  // 幸运修正
}
