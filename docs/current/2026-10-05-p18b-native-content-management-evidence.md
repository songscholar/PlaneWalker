Main configures the retained data-only installer before child Host boot, feeds
the exact selected pack specs into the production Registry, and activates the
canonical Profile in its verified save domain. Hub exposes native folder install,
refresh, enable checkboxes and disabled-only uninstall. Failed selection writes
retain the live Main, assembly and original Base bytes, and render a retry.
Successful selection commits before an actual scene reload.

Meta catalog authority now follows the exact selected content through Player
loadout, Run domain, Save envelope, tutorial binding, narrative recovery and
terminal settlement. Explicit wrong-catalog Run and envelope validation refuse;
a failed domain restore preserves its prior catalog. Base compatibility defaults
remain available to historical callers without a selected-content authority.

The real Main integration seeds a valuable Base Profile with 73 shards, two
deaths and extension data. It installs an Expansion-only local item, refuses
stale and failed physical selection, reloads into the exact unranked local
assembly, launches, checkpoints and cold-restarts Main again. Native resumption
retains the same Run and Profile identity. Actual route entry and Player death
settle the local Profile, then a real selection restart returns to Base. Original
Base primary bytes, currency and statistics remain identical throughout.
Both live native Runs and cold active receipts refuse all package mutations.

## Remaining Program Gates

This focused milestone does not certify the full product. The broader tutorial
regression run passed six of seven scenes; its combat-checkpoint and detached
training cleanup failures are assigned to the active P16R native combat recovery
milestone. Known historical live Runs require explicit content migration instead
of silent rebinding; the four-source refusal is tested and preserves bytes.
The actual engine rejected the existing Linux/BSD export preset, while macOS PCK
export passed. Three-platform export correction and clean-checkout certification
remain part of the active build milestone. No external storefront, credentials,
public deployment or arbitrary executable Mod is required by this local adapter.

The native integration, explicit catalog propagation and independently pinned
compatibility ledger are retained in focused local commits. The content manager
keeps isolated saves after packages are disabled; reverting the integration does
not require deleting valuable Base or local save files.
