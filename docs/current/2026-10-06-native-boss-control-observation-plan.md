## Problem and Scope

One Boss control refresh currently composes three complete Boss snapshots for
generic telegraphs, cold threat facts and sprite/root presentation. Time
Sovereign additionally takes a complete snapshot for its Watch. Each copy
includes retained mechanism claims/history and composed child authorities.
Ordinary presentation needs only the current detached action, native frame and
terminal state, all of which already have authoritative read-only queries.

This slice owns only `launch_hostile_actor.gd`, `launch_boss_actor.gd`, its new
acceptance scene and these documents. BossRuntime is owned by another lane.
Keep the complete Time Sovereign self-rewind landing and Watch branches, every
query-less runtime fallback, deferred contact/flush ordering, action-to-pose
mapping, accessibility options and actual visual output. Do not change gameplay,
save/replay schemas, UI design, entity/history budgets or the frozen native750.
