## Production Boundary

The owned preparation hook constructs and adopts one private complete candidate.
Boss Forge, Forest, Void, Ruin wall and charge postprocessing adjusts that same
candidate before either public export or native marker issuance. Public
preparation still exports the original complete detached ticket and batch,
including exact field order, Variant types and actual burn source/attacker
Nodes. Native preparation returns only an empty RefCounted marker and detached
batch. The marker has no state, owner, frame, Dictionary or Array fields.

Only the actual canonical HostileFrameBridge and HostileActor/BossActor Script
objects use this protocol. Matching resource-path strings is insufficient;
the fixture exercises distinct Scripts taking over the canonical paths.
Summon, ordinary-copy and unknown Actor/Bridge subclasses retain their public
preparation path, including real lease and retirement behavior. Malformed
native output refuses without attempting public preparation a second time.

The native lifecycle authenticates the exact Actor marker, weak captured
authority, exact bound registry and frame Callable, run, live roster and marker
in the current Bridge record. The current preparation record is transient.
Original live-before, Health, strict restore, room, teleport/phase landing and
dynamic Boss Forest guards still execute. Publication preserves the original
semantics because Effects legitimately settles additional live damage receipts
after Actor commit; there is no new full-after snapshot equality check.

Accepted candidate rollback, complete transaction restore, public/native
publication, configuration, same-provider authority rebind, same-source
identity reconfiguration and identity retirement revoke the marker. Native
mutations and Bridge preparation/publication transitions refuse reentry.
Bridge compensation preserves its original encounter, Effects, Health, Actor
pre-weapon checkpoint and registry order. A failed rollback still clears active
records and returns false. Held old markers cannot authenticate a later record
even when its frame number is the same.
