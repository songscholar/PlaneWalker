`HostileFrameBridge` and adds the authoritative boundary-readiness guard.
At this source, Bridge `_uses_native_actor_frame` and Actor
`_native_frame_bridge_binding` both require the exact base Script object.
The production subclass therefore takes the public fallback. Direct
`HostileFrameBridge.new()` protocol fixtures do not prove Main uses tokens.

counts, even when native count is zero. A future production adapter fix needs

change the source under the frozen editor/release baseline.

## Diagnostic Changes

The archived generator wraps 245 actual methods and retains a complete
wrapper manifest. It adds native preparation, owned Actor/Boss/Bridge
helpers, marker ownership, the private candidate construction and detached
batch export. The removed Boss public prepare override is explicitly absent;
its inherited base method and Boss owned helper are measured. Void's old
`_can_restore_snapshot_uncached` is absent because its full validation is
inline in `can_restore_snapshot`, which remains measured.

Mechanical diagnostic-only leaf helpers preserve the exact built-ins and
their arguments while separately measuring Boss and Void snapshot bytes,
configuration bytes, Void event checkpoint encoding/decoding, replay
observation/payload bytes and ZSTD compression. Public behavior and data are
unchanged. Recursive safety and codec functions bypass their own timer during
self-recursion, so their inclusive entry measurements retain complete work
without a mutex on each descendant.

The per-thread timer retains caller-to-child edges in addition to inclusive
and exclusive method totals. This distinguishes Boss-child snapshot reads
from event receipts and identifies which caller repeatedly serializes or
validates a complete value. Added timers, mutexes and edge accounting change
scheduling; these values attribute work and cannot certify a frame budget.
