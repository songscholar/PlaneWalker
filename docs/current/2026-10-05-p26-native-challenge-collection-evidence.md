## Delivered

Main enrolls its actual carried Boss Rush and Daily Flow storage scopes. Returning
from a mode claims only the promoted validated result. The gallery opens a
dedicated earned-equipment collection with persistent toggles, authored modifier
values and cosmetic swatches. Explicit synchronization retries pending Profile
claims. A failed equipment promotion preserves the committed selection and
exposes the existing save-retry notice. Opening the collection locks content
mutation; closing it restores the authored gallery and controller focus.

The panel retains a separate render epoch so duplicate synchronization redraws
usable controls without changing the durable Profile revision. Retired callbacks
cannot repeat a published equipment mutation. This layer consumes the shared
authority; frozen Player combat effects are certified separately.
