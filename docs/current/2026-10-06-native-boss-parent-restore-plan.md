## Observed Copy

The latest actual diagnostic attributes 1.801 exclusive ms per measured frame
to three complete Boss restores. After validated independent child restores,
the parent deep-copies the whole composed input and immediately erases all ten
child fields. Those child histories already belong to independently restored
authorities; copying them again cannot contribute to the retained parent.

## Scoped Change And Acceptance

Keep complete validation, mutable Action selection, child restore ordering,
failure handling and legacy classification intact. A private parent-copy
function removes the same ten fields from a shallow input envelope, then
deep-copies the remaining parent state. Preserve exact field order and types,
optional Void-half state, caller isolation and subsequent frame behavior.

Before production edits, an actual five-Boss fixture must fail only the missing
parent-copy-path count. At actual idle, warning, active, recovery and terminal
boundaries, retain original deep-copy-then-erase parent bytes and complete
restored snapshot bytes. Count one private parent copy per accepted restore;
refused full-schema/owner/action/child corruption must perform no parent copy
and leave live state exact. Mutate supplied nested parent and child arrays
after restoration: parent and independently installed children must remain
detached. Verify repeated restore, historical reads and the next actual frame.
Run complete Boss/cache/template, native transaction, Void/Time and recorder
neighbors with strict paired runtime logs before a focused commit.

This slice proves removal of discarded child copies, not integrated CPU
benefit. Frame-budget, saturation, sustained recording, rendered, final clean
certification, UI and human gates remain separate.
