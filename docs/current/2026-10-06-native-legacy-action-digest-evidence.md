## Narrow Production Boundary

Only the two legacy flag digest expressions in `LaunchBossRuntime.restore_snapshot`
change. They read the existing current-regime immutable Action validation
template using the complete typed Boss context, phase, enrage and both current
geometry/response flags. The old expressions configured a second mutable
current-regime Action only to read this same normalized definition digest.

Actual restoration still selects and configures independent mutable current
or historical Actions, then invokes the original Action, control, conversion,
arena, auxiliary and receipt restore checks. Public Action configuration,
snapshot validation, template shape, deep ownership, four-entry capacity,
encoded byte limits, oversized fallback and context invalidation are unchanged.
No generic mutable-from-template entry point is introduced.

## Executable RED And GREEN

`build/native-legacy-action-digest-red-3` is the valid RED. Its 56 assertion
failures are exclusively the two warm construction-count assertions across
seven boundaries for current and historical Void and Time. All five authored
Bosses retain exact typed state, legacy flags, independent mutable instances,
immutable template bytes, next-frame outputs, refusal and reconfiguration
behavior. No script/parse failure or leak is present.

The earlier `-red` fixture incorrectly assumes an integral float mechanism
phase must refuse and installs historical state before a Boss request, which
legitimately synchronizes it back to the current regime. `-red-2` corrects those
assumptions but still expects historical state after retirement; the original
Boss intentionally synchronizes the ended Action to its current regime. Both
invalid setups are retained. Final RED uses a fractional invalid phase,
installs an independently committed historical Action after the current Boss
request, and checks the authentic transition to current state at retirement.
Production validation is not changed to accommodate fixture expectations.

`build/native-legacy-action-digest-green` passes the complete focused fixture
and strict paired logs. After warm authority validation, every current
restoration creates exactly one independent mutable Action. Historical Void
geometry and Time response restorations retain their original two-candidate
current-then-historical selection. The extra digest-only construction is gone.
Repeated restores create different mutable instances and retain exact typed
Boss/auxiliary snapshots and the same immutable template. Warning, active,
recovery and retirement boundaries produce exact independent next-frame hit,
effect and auxiliary outputs. Typed schema forgery, fractional mechanism
phase and foreign identity/digest refuse without changing complete state;
reconfiguration clears templates and rejects the previous owner.

## Measurement Still Required

Each Void or Time restoration now additionally computes one complete typed
configuration context for template lookup. Eliminated mutable constructions
do not prove a net CPU improvement: context serialization itself has a cost.
No new native 600-frame probe is run for this slice. The earlier combined
`26a5d98` report still has 57.742-ms mean complete-frame work and cannot certify
the 16.667-ms budget. A later uninstrumented measurement must decide the net
effect. Rendered throughput, sustained recording, saturation, the 45-minute
soak, complete UI and human playtesting remain separate open gates.
