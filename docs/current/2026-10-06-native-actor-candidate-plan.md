## Problem and Scope

The integrated 120-frame diagnostic attributes 1.281 ms/frame of exclusive
time to Actor preparation. Its candidate construction deep-copies the complete
before state, then replaces runtime, status, position, knockback, action credit
and optional affix runtime. Retained histories in those replaced branches are
copied and immediately discarded.

Construct the after dictionary in the same field order using the freshly owned
replacement snapshots. Deep-copy unchanged weapon claims/order, metadata, room
motion and optional affix configuration separately. Preserve every scalar type,
Node identity, optional field, complete ticket equality, validation, returned
ticket/batch copy and Boss postprocessing. Own only LaunchHostileActor, the new
acceptance scene and this plan/evidence. Do not change BossActor, BossRuntime,
Bridge, schemas, histories, gameplay budgets, UI or the frozen native750.

## Executable Acceptance

- Retain an actual original-construction baseline before implementation. This
  behavior-preserving slice uses the explicitly authorized original/candidate
  microbenchmark alternative to a failing behavior test. Final strengthened
  missing-constructor detection is collected retrospectively in an isolated
  original-source checkout; this slice does not claim strict preimplementation
  RED ordering. Subsequent slices must collect meaningful RED before production
  edits, as required by AGENTS.md.
- Compare actual prepared before/after state against the original deep-copy and
  replacement algorithm with `var_to_bytes`, including insertion order/types.
- Run actual ordinary, Shielded-affix and five authored Boss actors in validated
  native rooms. Populate real status Node references and nested metadata/claims.
- Mutate returned before, after and batch branches independently; complete live
  state and retained ticket remain unchanged, sibling branches stay isolated,
  forged tickets remain refused and the pristine ticket remains accepted.
- Commit, compensate, retry and publish actual frames. Observe exact before/after
  bytes and consumed-ticket rejection. Exercise a real body collision and retain
  the exact collision Node plus burn source/attacker object identities.
- Repeatedly call the actual new constructor and the original algorithm on the
  same actual frame snapshots. Record elapsed microseconds and overwritten branch
  serialized bytes; assert parity/ownership but no hardware timing threshold.
- Run focused actual Actor/Bridge/Boss/affix/spatial neighbors with strict paired
  stdout/engine-log validation. Avoid competing with integrated performance600.
- Review exact paths, retain a focused local commit and send its evidence to the
  integration lead. Keep native750 supervision active.

Constructor measurements do not certify frame rate or the gameplay/UI gates.
