---

## 4.1 角色设计

### 4.1.1 角色设计原则

**核心原则：机制差异，而非数值调整**

1. **独特玩法体验**：每个角色必须拥有改变核心循环的专属机制，而非简单的"攻击力+20%"式数值加成。角色机制应重构玩家与游戏系统的交互方式。
2. **武器适配非锁定**：角色对武器有推荐适配，但不存在绝对最优解。任何角色使用任何武器都应可通关，适配关系体现为"玩法流畅度"和"Build上限"的差异，而非"能不能用"。
3. **风险-回报曲线差异化**：每个角色的风险-回报曲线形状不同——行者线性、时之守卫阶梯式、虚空行者指数式、原界骑士分段式、时间领主脉冲式。
4. **操作复杂度梯度**：行者(1星) → 时之守卫(2星) → 原界骑士(3星) → 虚空行者(4星) → 时间领主(5星)，提供从入门到精通的学习路径。
5. **叙事-玩法统一**：角色的背景故事必须在其机制中得到体现和验证，世界观设定不是装饰而是机制来源。

### 4.1.2 五个角色完整设计

---

#### 4.1.2.1 行者（Walker）

**定位**：均衡型 | 适应所有武器 | 无明显弱点与极端优势  
**操作复杂度**：★☆☆☆☆（入门角色）

---

**背景故事**

行者是位面之间最古老的职业——在原界碎裂之前，行者便是穿梭于各个平行位面的旅人，维系着位面间的微妙平衡。当虚无第一次侵蚀原界时，无数行者试图修复裂隙，却大多被虚无吞噬。如今，最后的行者独自踏上旅程，他没有特殊的守护之力，没有虚空的馈赠，没有骑士的武装，也没有领主的权柄——他拥有的，只有行走本身。每一次失败都是下一条路径的起点，每一次死亡都让他更接近终点。行者相信：走得够远，就能走到原界碎裂之前。

**外观描述**

- 中等体型，灰白色兜帽长袍，下摆随风飘动
- 面部被兜帽阴影遮蔽，仅露出淡金色双眼
- 腰间佩戴可替换的武器挂点（随武器切换外观变化）
- 移动时脚下留下淡蓝色时之残影，0.5秒后消散
- 受伤时兜帽边缘出现虚无侵蚀纹路（纯装饰，随HP降低增多）

**初始属性表**

| 属性 | 数值 | 说明 |
|:---|:---:|:---|
| HP | 200 | 基础生命值 |
| ATK | 30 | 基础攻击力 |
| DEF | 15 | 基础防御力 |
| SPD | 5.0 | 移动速度（格/秒） |
| 时之能量上限 | 100 | 时间操控资源 |
| 闪避次数 | 3 | 连续闪避上限 |
| 闪避无敌帧 | 0.25s | 单次闪避无敌时长 |

**专属被动技能：旅途印记（Path Mark）**

- **机制描述**：行者每次切换房间时，获得1层"旅途印记"（最多叠加10层）。每层印记使当前房间内所有伤害提升3%，且在房间结束时每层回复2HP。死亡后印记清零并保留50%转化为"记忆碎片"（局外成长资源）。
- **触发条件**：通过房间出口进入新房间时自动触发
- **效果细节**：
  - 伤害加成：3% × 印记层数（10层 = 30%）
  - 回复量：2 × 印记层数（10层 = 20HP/房间结束）
  - 记忆碎片转化：死亡时印记数 × 5
- **设计意图**：鼓励持续推进而非反复刷怪，"死亡也有收获"降低入门挫败感

**专属主动技能：时间回溯（Time Recall）**

- **按键**：LB / Q键
- **效果**：行者在当前位置留下一个时间锚点（持续8秒），再次按下技能键可瞬移回锚点位置，并回复锚点留下时刻与当前时刻之间所受伤害的25%。若8秒内未使用则锚点消失。
- **冷却**：12秒（从锚点消失/使用后开始计算）
- **时之能量消耗**：30
- **进阶用法**：可在Boss战中预留下锚点，吃一轮爆发伤害后回溯回复，实现"先卖血再回溯"的高风险操作
- **设计意图**：赋予行者"试错"能力，与其他角色的防御/爆发机制形成差异化

**推荐武器与原因**

- **首选：剑** — 剑的均衡攻防与行者的均衡属性天然契合，旅途印记的逐层增伤完美匹配剑的稳定输出节奏
- **次选：拳套** — 拳套的高频攻击能快速消耗敌人，配合时间回溯的位移形成打-撤-打循环
- **可用：弓/枪/杖** — 均无惩罚，但无法发挥角色机制的额外加成

**专属Build方向**

**方向一：无尽旅途流**
- 核心思路：最大化旅途印记层数，追求房间内高伤害加成+房间外回复
- 核心道具：「行者之靴」（房间切换时额外获得1层印记）、「回忆之冠」（印记层数≥5时攻速+20%）、「记忆编织者」（记忆碎片获取量+50%）
- 核心祝福：时之神·行（每3层印记获得额外1秒无敌帧时间）
- 预期DPS乘区：印记30% × 攻速20% × 祝福15% ≈ 1.77倍基础

**方向二：回溯循环流**
- 核心思路：缩短时间回溯冷却，反复卖血-回溯形成永续循环
- 核心道具：「悖论沙漏」（时间回溯冷却-30%）、「裂隙之心」（回溯回复量从25%提升至40%）、「双子锚点」（可同时存在2个锚点）
- 核心祝福：虚空之眼·悖论（回溯时对起点与终点之间路径上的敌人造成1.5倍ATK的时间伤害）
- 预期效果：每8秒一个完整回溯循环，DPS与生存双提升

**方向三：万器精通流**
- 核心思路：利用行者无惩罚适配所有武器的特性，构建多武器联动Build
- 核心道具：「万能武器架」（武器切换速度+50%）、「行者手札」（每装备一种未重复类型的武器增伤5%）
- 核心祝福：原界·万象（使用与上一次不同武器攻击时，该次伤害+25%）
- 预期效果：通过频繁切换武器维持增伤Buff

**解锁条件**

- 默认解锁，游戏开始即可使用

#### 4.1.2.2 时之守卫（Guardian of Time）

**定位**：格挡/防御型 | 格挡成功触发时间减速 | 反击核心  
**操作复杂度**：★★☆☆☆

---

**背景故事**

时之守卫曾是原界时间圣殿的最高守卫——他们的职责是守护"时间之核"，维持所有位面的时间流速统一。当虚无侵蚀时间圣殿时，守卫们以自身为盾抵御了七日七夜，最终时间之核碎裂，每一块碎片嵌入了守卫们的灵魂。如今，时之守卫带着碎片行走于位面之间，他们不再守护圣殿，而是守护"时间不在此处断裂"这个承诺本身。每一次格挡，都是时间碎片的共鸣；每一次反击，都是被冻结的刹那。

**外观描述**

- 高大魁梧体型，银白色全板甲，胸口处嵌入发光的蓝色时间碎片
- 左臂佩戴巨型护手（格挡动画的核心视觉元素）
- 头盔面甲为时钟表盘造型，指针随格挡冷却转动
- 格挡成功时全身发出蓝色脉冲波纹，周围敌人出现时间凝滞的视觉残影
- 移动速度缓慢但步伐沉稳，每一步在地面上留下时钟刻度纹路

**初始属性表**

| 属性 | 数值 | 说明 |
|:---|:---:|:---|
| HP | 280 | 基础生命值（全角色最高） |
| ATK | 25 | 基础攻击力（全角色最低） |
| DEF | 30 | 基础防御力（全角色最高） |
| SPD | 3.8 | 移动速度（全角色最低） |
| 时之能量上限 | 120 | 时间操控资源 |
| 闪避次数 | 2 | 连续闪避上限（较少） |
| 格挡无敌帧 | 0.15s | 完美格挡判定窗口 |

**专属被动技能：时间壁垒（Chrono Bulwark）**

- **机制描述**：时之守卫的闪避替换为"格挡"操作。格挡成功（在0.15秒判定窗口内按LT/L键）时，触发"时间凝滞"效果——周围半径6格内所有敌人减速70%，持续3秒；同时获得1层"壁垒充能"（最多5层）。每层壁垒充能使下一次攻击伤害提升15%，且消耗1层充能。非完美格挡（在0.15s~0.4s窗口）仅获得50%减伤，不触发凝滞，获得0.5层充能。
- **触发条件**：完美格挡（0.15s窗口）/ 普通格挡（0.15s~0.4s窗口）
- **效果细节**：
  - 完美格挡：100%减伤 + 周围敌人减速70%/3秒 + 1层壁垒充能
  - 普通格挡：50%减伤 + 0.5层壁垒充能
  - 充能攻击：每层+15%伤害，攻击消耗1层（5层=75%增伤单次攻击）
  - 减速场半径：6格
  - 格挡失败（0.4s后或未操作）：正常受伤
- **设计意图**：将防御行为本身变成进攻资源，"以守为攻"的核心循环

**专属主动技能：时之堡垒（Chrono Fortress）**

- **按键**：LB / Q键
- **效果**：时之守卫进入堡垒状态（持续4秒），期间正面所有伤害被格挡（无需按键），每次格挡自动触发时间凝滞并叠加壁垒充能。堡垒状态期间无法移动，但攻击速度+40%。结束后若壁垒充能满5层，自动释放"时间震荡波"——对周围8格内敌人造成 3.0×ATK 的时间伤害并击退。
- **冷却**：18秒
- **时之能量消耗**：40
- **设计意图**：高风险的"定点输出"窗口——无法移动是代价，多层充能+震荡波是回报

**推荐武器与原因**

- **首选：剑** — 剑的攻击节奏与壁垒充能完美同步，蓄能→释放的单次高伤与剑的重击契合
- **次选：拳套** — 拳套的快速攻击可快速消耗壁垒充能，形成"格挡→充能→快速释放"循环
- **可用：枪** — 枪的攻击距离可弥补移速不足
- **不推荐：弓/杖** — 远程武器无法充分利用壁垒充能的近战增伤

**专属Build方向**

**方向一：完美壁垒流**
- 核心思路：追求完美格挡率，最大化壁垒充能获取与消耗
- 核心道具：「守卫之誓」（完美格挡窗口+0.05秒）、「充能护符」（壁垒充能上限从5提升至8，每层增伤降为12%）、「时间共振盾」（格挡时回复5HP）
- 核心祝福：时间之核·壁垒（壁垒充能满层时，攻击附带2秒时间凝滞效果）
- 预期DPS：8层×12%=96%增伤（单次），配合频繁格挡可维持高充能

**方向二：堡垒阵地流**
- 核心思路：围绕时之堡垒技能构建定点输出循环
- 核心道具：「永恒壁垒」（堡垒状态持续时间+2秒）、「碎裂共鸣」（时间震荡波伤害+50%，范围+2格）、「不动如山」（堡垒期间每秒回复3HP）
- 核心祝福：原界·坚守（堡垒期间每格挡一次攻击，震荡波最终伤害+10%）
- 预期效果：6秒堡垒期+大范围高伤震荡波，适合Boss战定点爆发

**方向三：减速控制流**
- 核心思路：最大化时间凝滞的覆盖率，打造控场型Tank
- 核心道具：「时间编织者」（时间凝滞持续时间+1.5秒）、「迟缓之心」（时间凝滞范围+3格）、「衰老印记」（处于凝滞中的敌人受到的伤害+20%）
- 核心祝福：虚空·迟暮（被凝滞3秒以上的敌人进入"时间崩坏"状态，受到双倍时间伤害）
- 预期效果：近乎永续的减速场，将战斗节奏完全掌控

**解锁条件**

- 使用行者通关第2层（时光走廊）1次

#### 4.1.2.3 虚空行者（Void Walker）

**定位**：高风险高回报 | 生命越低伤害越高 | 虚空侵蚀双刃剑  
**操作复杂度**：★★★★☆

---

**背景故事**

虚空行者曾经也是普通行者——直到他在虚无侵蚀中坠入了虚空本身。在虚空的深处，他看见了原界碎裂的真相：虚无并非入侵者，而是原界的"反面"，是所有被遗忘的可能性的集合。虚空行者与虚无达成了契约——他允许虚无寄宿于自身，获得远超常人的力量，代价是虚无正在缓慢吞噬他的存在。他的身体一半是血肉，一半是虚空；每一次使用力量，虚无就更深入一步。他必须在虚无完全吞噬他之前找到修复原界的方法——否则，他将永远成为虚无的一部分。

**外观描述**

- 修长偏瘦体型，左半身为正常肤色，右半身为紫黑色虚空侵蚀态
- 右眼为正常金瞳，左眼为深紫色虚空漩涡
- 披风右侧为灰白色布料，左侧为流动的紫黑色虚空气体
- 攻击时右手武器附带紫黑色虚空粒子特效
- HP越低，虚空侵蚀范围越大（装饰性）：75%→右臂侵蚀，50%→右半身侵蚀，25%→全身70%侵蚀

**初始属性表**

| 属性 | 数值 | 说明 |
|:---|:---:|:---|
| HP | 150 | 基础生命值（全角色最低） |
| ATK | 35 | 基础攻击力（全角色最高） |
| DEF | 8 | 基础防御力（全角色最低） |
| SPD | 5.5 | 移动速度（较高） |
| 时之能量上限 | 80 | 时间操控资源（最低） |
| 闪避次数 | 4 | 连续闪避上限（全角色最高） |
| 闪避无敌帧 | 0.3s | 单次闪避无敌时长（较长） |

**专属被动技能：虚无共鸣（Void Resonance）**

- **机制描述**：虚空行者的伤害与当前HP百分比成反比。HP越低，攻击力加成越高。但HP低于30%时，每秒受到 2点 虚空侵蚀伤害（真实伤害，无视防御）。HP降至0时不会立即死亡，进入"虚空临界"状态（持续5秒），期间伤害再翻倍但持续掉血（5HP/秒），5秒后若未回复至1HP以上则真正死亡。
- **触发条件**：始终生效
- **效果细节**：
  - HP 100%~76%：攻击力 +10%
  - HP 75%~51%：攻击力 +30%
  - HP 50%~26%：攻击力 +60%
  - HP 25%~1%：攻击力 +100%
  - HP <30% 虚空侵蚀：2HP/秒真实伤害
  - 虚空临界（HP=0）：伤害再×2，5HP/秒掉血，持续5秒后判定死亡
- **设计意图**：将"血量管理"变成核心玩法——不是"避免受伤"，而是"精确控制受伤程度"

**专属主动技能：虚空吞噬（Void Devour）**

- **按键**：LB / Q键
- **效果**：虚空行者主动消耗当前20%最大HP（最低消耗10HP），对前方锥形范围（8格长，60度角）内所有敌人造成 4.0×ATK 的虚无伤害，并为自身回复造成总伤害15%的HP。若此技能击杀敌人，额外回复10HP并重置技能冷却。
- **冷却**：8秒（击杀重置）
- **时之能量消耗**：25
- **设计意图**：主动降低HP以触发更高增伤，同时提供回复途径实现"自循环"。击杀重置鼓励精准使用

**推荐武器与原因**

- **首选：弓** — 弓的安全距离允许虚空行者在高增伤区间（低HP）保持输出而不被近战击杀
- **次选：拳套** — 拳套的高频攻击与高ATK基础完美叠加虚无共鸣加成，高闪避次数提供容错
- **可用：剑** — 攻守兼备，适合中阶玩家尝试
- **不推荐：杖** — 杖依赖时之能量，虚空行者80的上限严重限制时间伤害输出

**专属Build方向**

**方向一：临界爆发流**
- 核心思路：将HP压至极低，追求最高伤害倍率的极限玩法
- 核心道具：「虚空之心」（虚无共鸣每档增伤额外+15%）、「死亡之舞」（HP低于25%时攻速+30%）、「悖论锁链」（虚空临界状态持续时间+3秒）

### 4.1.3 角色平衡

**角色间DPS对比目标**

基于"标准循环"（无道具/祝福，使用推荐武器，持续输出30秒），各角色的目标DPS范围：

| 角色 | 基础DPS | 理论最高DPS | 操作难度系数 | 有效DPS目标 |
|:---|:---:|:---:|:---:|:---:|
| 行者 | 90 | 180 | 1.0× | 90~180 |
| 时之守卫 | 70 | 250 | 1.3× | 91~192 |
| 虚空行者 | 105 | 380 | 1.6× | 66~238 |
| 原界骑士 | 85 | 280 | 1.4× | 61~200 |
| 时间领主 | 65 | 320 | 2.0× | 33~160 |

> - 基础DPS：不考虑角色机制的最简输出循环  
> - 理论最高DPS：完美操作+满层机制+最佳武器  
> - 操作难度系数：越高表示机制越难完全发挥  
> - 有效DPS目标 = 基础DPS ~ 理论最高DPS/操作难度系数  
> - 设计目标：所有角色的有效DPS目标范围有重叠区间（61~238），确保无角色绝对最优

**预期通关率（首次通关，普通难度）**

| 角色 | 预期通关率 | 平均通关尝试次数 | 设计意图 |
|:---|:---:|:---:|:---|
| 行者 | 45% | 3~5次 | 入门友好，容错高 |
| 时之守卫 | 40% | 4~6次 | 防御型需学习格挡节奏 |
| 虚空行者 | 25% | 6~10次 | 高风险需精准血量控制 |
| 原界骑士 | 35% | 5~7次 | 需熟练双武器切换 |
| 时间领主 | 20% | 8~12次 | 极高操作要求，通关成就感最强 |

**角色平衡调整原则**

1. **不削弱，只增强**：当某角色通关率过低时，增强该角色而非削弱其他角色
2. **机制优先于数值**：优先调整机制触发的便利性（如判定窗口、层数要求），再调整数值倍率
3. **保留操作奖励差距**：时间领主的理论上限必须始终最高，但有效DPS应与行者接近
4. **数据驱动**：每1000局游戏数据后检查各角色通关率偏差，偏差>10%时触发调整

### 4.2.2 伤害公式体系

**物理伤害完整公式**

```
基础物理伤害 = FATK × 武器倍率 × 技能倍率 × (1 + 独立增伤总和)

实际物理伤害 = 基础物理伤害 × (1 - 目标减伤率) × 随机波动
```

- **FATK** = BATK × (1 + ATK%有效值)
- **武器倍率**：每种武器每次攻击的独立倍率（见4.2.3武器DPS表）
- **技能倍率**：角色主动技能的倍率（如裂界斩1.5×）
- **独立增伤**：位面不稳25%、时间凝滞增伤20%等，加法叠加
- **目标减伤率** = 防御减伤 + 独立减伤（上限80%）
- **随机波动**：0.95 ~ 1.05 均匀分布

**时间伤害公式**

```
基础时间伤害 = FATK × TDM × 时间技能倍率

实际时间伤害 = 基础时间伤害 × (1 - 目标时间抗性) × 时间易伤乘区
```

- **TDM**：时间伤害系数（基础1.0×，时间领主1.5×）
- **时间技能倍率**：具体技能/攻击的时间伤害倍率
- **时间抗性**：敌人属性，0%~50%（Boss更高）
- **时间易伤**：冻结+30%等，乘法叠加
- **关键特性**：时间伤害无视物理防御，但受时间抗性影响

**虚无伤害公式**

```
基础虚无伤害 = FATK × VDM × 虚无技能倍率 × (1 + 虚无共鸣加成)

实际虚无伤害 = 基础虚无伤害 × (1 - 目标虚无抗性) × 虚无易伤乘区
```

- **VDM**：虚无伤害系数（基础1.0×）
- **虚无共鸣加成**：虚空行者被动，HP越低越高（0%~100%）
- **虚无抗性**：敌人属性，普通敌人0%，虚无系敌人50%
- **关键特性**：虚无伤害可对虚无系敌人触发"虚无吞噬"——击杀时回复造成伤害5%的HP

**暴击计算**

```
暴击判定：随机数 0~100 < CR有效值 → 暴击

暴击伤害 = 原始伤害 × CD有效值
```

- **暴击判定顺序**：先判定物理暴击，再独立判定时间暴击（虚无伤害不可暴击）
- **CR有效值**：min(CR基础 + CR加成, 75%)
- **CD有效值**：min(CD基础 + CD加成, 3.5×)
- **特殊规则**：时间领主的时间暴击独立计算，CR+15%专用于时间暴击

**防御减伤公式**

```
防御减伤率 = FDEF / (FDEF + 减伤常数K)

K = 50 + 攻击者等级 × 5
```

- **减伤常数K**：随攻击者等级增长，防止防御力在后期失效
- **示例计算**：
  - 玩家DEF=30，攻击者等级1：K=55，减伤率 = 30/85 = 35.3%
  - 玩家DEF=30，攻击者等级5：K=75，减伤率 = 30/105 = 28.6%
  - 玩家DEF=60，攻击者等级5：K=75，减伤率 = 60/135 = 44.4%
- **最终减伤** = 防御减伤率 + 独立减伤率（上限80%）
- **真实伤害**：虚空侵蚀等效果，无视所有减伤

**等级缩放**

```
等级HP缩放 = 基础HP × (1 + 等级 × 0.18)
等级ATK缩放 = 基础ATK × (1 + 等级 × 0.15)
等级DEF缩放 = 基础DEF × (1 + 等级 × 0.12)
```

- 等级范围：1~10（每层+1~2级）
- 缩放公式同时适用于玩家和敌人
- 玩家等级由房间数推进：每清3个房间等级+1
- 敌人等级由层数决定：每层基础等级+2

**综合伤害计算示例**

> 场景：行者（ATK=40，CR=25%，CD=1.8×）使用剑重击（武器倍率1.5×）攻击5级敌人（DEF=20，时间抗性10%），附带10%独立增伤

```
FATK = 40
基础物理伤害 = 40 × 1.5 × 1.0 × 1.10 = 66
敌人K = 50 + 5×5 = 75
防御减伤 = 20/95 = 21.1%
实际物理伤害 = 66 × (1 - 0.211) × [0.95~1.05] = 52.1 × [0.95~1.05] = 49.5~54.7

若暴击：52.1 × 1.8 = 93.8 × [0.95~1.05] = 89.1~98.5

时间附伤（行者1.0×）：40 × 1.0 × 1.0 × (1-0.10) = 36 × [0.95~1.05] = 34.2~37.8

总伤害（不暴击）= 49.5~54.7 + 34.2~37.8 = 83.7~92.5
总伤害（暴击）= 89.1~98.5 + 34.2~37.8 = 123.3~136.3
```

| 商店折扣概率 | 20% | 10% | 5% |
| 复活点数量 | 3/局 | 2/局 | 1/局 |

**动态难度调整（DDA）**

系统在每层结束时根据玩家表现动态微调下一层难度，范围±15%：

```
DDA系数 = 1.0 + Σ(各指标偏差 × 权重)

指标与权重：
- HP剩余百分比偏差 = (实际HP% - 目标HP%) × 0.003
  目标HP%：普通70%, 困难50%, 噩梦30%
- 击杀速度偏差 = (目标击杀时间 / 实际击杀时间 - 1) × 0.004
- 受击频率偏差 = (目标受击次数 / 实际受击次数 - 1) × 0.003
  目标受击次数：普通5次/房间, 困难7次/房间, 噩梦10次/房间

DDA系数范围：0.85 ~ 1.15
应用方式：下一层敌人HP × DDA系数, 敌人ATK × DDA系数
```

**DDA示例**

> 玩家在普通难度第3层结束时：HP剩余85%（目标70%），击杀平均1.0秒（目标1.2秒），受击2次/房间（目标5次/房间）

```
HP偏差 = (85% - 70%) × 0.003 = +0.045
击杀偏差 = (1.2 / 1.0 - 1) × 0.004 = +0.0008
受击偏差 = (5 / 2 - 1) × 0.003 = +0.0045

DDA系数 = 1.0 + 0.045 + 0.0008 + 0.0045 = 1.0503
→ 第4层敌人HP和ATK提升5%
```

**DDA规则**

1. DDA仅微调，不改变难度档位（普通不会变成困难）
2. DDA不对Boss生效（Boss数值固定）
3. 连续2层DDA>1.10时，第3层额外赠送1个恢复道具
4. 连续2层DDA<0.90时，第3层精英敌人+1
5. DDA数值在UI中不可见（避免玩家meta-gaming）
