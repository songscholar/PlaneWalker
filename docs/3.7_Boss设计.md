## 3.7.1 Boss设计框架

### Boss设计原则

**什么是有趣的Boss：**

1. **模式可学习**：Boss的每个招式必须有清晰的视觉/音频预警信号。玩家在第1~2次被击中后应能理解"我本可以躲开"，而非"这不可能反应"。核心公式：**预警时间 ≥ 玩家反应时间（12帧=0.2秒）+ 决策时间（6帧=0.1秒）+ 闪避启动（5帧）= 23帧最低预警**。教学层Boss预警 ≥ 40帧，最终Boss最低预警 ≥ 25帧。
2. **阶段变化重塑战斗**：阶段切换不是单纯的"更快的同一Boss"，而是引入至少1个新机制或改变1个核心交互规则。玩家需要重新适应，而非仅仅更精确地重复相同操作。
3. **公平的惩罚**：Boss的每个伤害窗口都是玩家自身失误的结果，而非随机或不可预见的。连续攻击（连段）中每次单独判定都有独立闪避窗口，不存在"一但中了第一下就必吃全段"的设计。
4. **弱化窗口明确**：Boss每次攻击后有明确的后摇窗口供玩家输出。窗口时长与招式威胁成正比——大招后摇长，小招后摇短。最低输出窗口：15帧（0.25秒）。
5. **Build包容性**：5种武器+时间操控系统都能有效对抗每个Boss。不设计"必须用远程"或"近战必死"的招式，而是通过不同方式创造等价优势。
6. **演出与游戏性统一**：Boss登场、阶段切换、死亡都需有演出时刻，但演出期间必须保持玩家操控（除短暂不可跳过的2~3秒强制演出）。参考Hades的Boss登场演出——镜头推进、Boss台词、音效冲击，然后立即回归操控。

### v1.1 时间技能正向交互原则

Boss不应大量免疫时间技能。Boss可以拥有抗性、递减和反制，但每个时间技能都必须有正向用途。设计目标不是"禁止玩家用核心机制"，而是让玩家学会"什么时候、在哪里、以什么目的使用时间"。

| 时间技能 | Boss战正向用途 | 不推荐设计 |
|----------|----------------|------------|
| 时间停止 | 延长Boss后摇、冻结弹幕/召唤物、短暂暴露弱点 | 直接免疫或只给0.3秒硬直 |
| 时间回溯 | 利用残影诱导Boss面向、穿越弱点路径造成收益、纠正高风险站位 | Boss同步回溯HP完全抵消玩家收益 |
| 时间加速 | 压缩机制处理时间、打满连击触发破防、快速处理场地机关 | Boss用减速场完全抵消玩家加速 |
| 时间裂隙 | 减速弹幕、切割Boss移动路径、延长机关窗口、保护撤退路线 | Boss随手摧毁裂隙且无补偿窗口 |

**验收标准**：每个Boss至少列出4条"玩家如何用时间技能打得更聪明"的策略；若Boss有反制，反制后必须暴露可利用的冷却、后摇或弱点窗口。

### Boss属性体系

**基础属性定义：**

| 属性 | 代码字段 | 基准单位 | 说明 |
|------|---------|---------|------|
| 生命值 | `bossHP` | 点 | Boss承受伤害的上限，基于层数倍率 |
| 攻击力 | `bossATK` | 点/次 | 单次攻击基础伤害值 |
| 移动速度 | `bossMoveSpeed` | 格/秒 | Boss常规移动速度 |
| 冲刺速度 | `bossDashSpeed` | 格/秒 | Boss冲刺/突进速度 |
| 旋转速度 | `bossTurnSpeed` | 度/秒 | Boss转向速度，影响追踪精度 |
| 阶段数 | `phaseCount` | 个 | Boss的战斗阶段数量 |
| 硬直抗性 | `bossStaggerResist` | 0~1 | 对玩家攻击产生硬直的抗性 |
| 击退抗性 | `bossKnockResist` | 0~1 | 对击退效果的抗性 |
| 霸体值 | `bossPoise` | 点 | 被消耗后才会产生硬直，每秒恢复 |
| 狂暴计时 | `enrageTimer` | 秒 | 进入狂暴阶段的剩余时间 |

**HP倍率计算公式：**

```
Boss基础HP = 层级基准HP × (1 + (层数L - 1) × 0.5)
  L1: 层级基准HP × 1.0
  L2: 层级基准HP × 1.5
  L3: 层级基准HP × 2.0
  L4: 层级基准HP × 2.5
  L5: 层级基准HP × 3.0

Boss实际HP = Boss基础HP × 路径缩放 × 游戏难度系数

路径缩放 = 1.0 + (房间数R - 8) × 0.02    // 每多1房HP+2%，补偿玩家更多资源
游戏难度系数 = 0.85(简单) / 1.0(普通) / 1.3(困难)
```

**阶段HP阈值：**

| 阶段 | 阈值规则 | 说明 |
|------|---------|------|
| 第1阶段 | HP > 60% | 基础招式集，学习阶段 |
| 第2阶段 | HP 30%~60% | 加入新机制/招式，战斗升级 |
| 第3阶段（如有） | HP < 30% | 极限阶段，所有招式可用，节奏最快 |
| 狂暴 | 计时触发 | 见下方狂暴机制 |

**狂暴机制（Enrage）：**

```
狂暴触发条件: Boss战斗持续时间 > 狂暴计时（enrageTimer）
各Boss狂暴计时:
  L1: 300秒(5分钟)
  L2: 270秒(4分30秒)
  L3: 240秒(4分钟)
  L4: 210秒(3分30秒)
  L5: 180秒(3分钟)

狂暴效果:
  ATK × 1.5
  moveSpeed × 1.3
  所有招式冷却 -40%
  新增"狂暴专属招式"（不可闪避的范围压制技）
  视觉: Boss全身发出红色脉冲光效，BGM变为狂暴变奏
  狂暴后不可逆转——设计意图: 防止玩家无限消耗Boss
```

**多阶段状态机结构：**

```
┌───────────────────────────────────────────────────┐
│                   Boss AI Core                     │
├───────────────────────────────────────────────────┤
│                                                   │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐   │
│  │ INTRO    │ →  │ PHASE_1  │ →  │ PHASE_2  │   │
│  │ (演出)   │    │ (基础)   │    │ (升级)   │   │
│  └──────────┘    └──────────┘    └──────────┘   │
│                       ↑               ↓          │
│                       │          ┌──────────┐    │
│                       │          │ PHASE_3  │    │
│                       │          │ (极限)   │    │
│                       │          └──────────┘    │
│                       ↓               ↓          │
│                  ┌──────────┐   ┌──────────┐    │
│                  │ ENRAGED  │   │  DEATH   │    │
│                  │ (狂暴)   │   │ (死亡)   │    │
│                  └──────────┘   └──────────┘    │
│                                                   │
│  每个PHASE内:                                     │
│  ┌─────────────────────────────────────┐         │
│  │ IDLE → SELECT_ATTACK → EXECUTE →   │         │
│  │ COOLDOWN → IDLE                     │         │
│  └─────────────────────────────────────┘         │
└───────────────────────────────────────────────────┘
```

**阶段切换条件：**

| 条件类型 | 代码逻辑 | 说明 |
|---------|---------|------|
| HP阈值 | `if (bossHP / bossMaxHP <= threshold)` | 最常用，HP降到阈值时触发 |
| 强制切换 | 当前招式执行完毕后强制切换 | 确保不在招式中途切换（避免Bug） |
| 演出插入 | 阶段切换时播放2~3秒演出动画 | Boss姿态变化+台词+BGM变奏 |
| HP锁 | 切换演出期间Boss无敌且HP锁定 | 防止玩家在演出中输出 |

**招式选择权重系统：**

```text
struct BossAttackEntry {
    string attackId;          // 招式ID
    float baseWeight;         // 基础选择权重
    float cooldown;           // 冷却时间(秒)
    float lastUsedTime;       // 上次使用时间
    int consecutiveCount;     // 连续使用次数
    float maxConsecutive;     // 最大连续次数
    string[] requiredPhases;  // 可用阶段
    float minHPPercent;       // 最低HP%才可用
    float maxDistance;         // 最大使用距离
    float minDistance;         // 最小使用距离
}

float GetAttackWeight(BossAttackEntry entry) {
    float weight = entry.baseWeight;
    
    // 冷却惩罚：冷却中权重=0
    if (runtime_time - entry.lastUsedTime < entry.cooldown) return 0f;
    
    // 连续使用惩罚：连续使用越多权重越低
    weight *= math.Pow(0.4f, entry.consecutiveCount);
    
    // 距离适配：距离越远，近战招式权重越低
    float dist = DistanceToPlayer();
    if (dist > entry.maxDistance || dist < entry.minDistance) return 0f;
    float distFactor = 1.0f - math.Abs(dist - (entry.minDistance + entry.maxDistance) / 2f) 
                                / ((entry.maxDistance - entry.minDistance) / 2f);
    weight *= math.Max(0.3f, distFactor);
    
    // HP越低，高威胁招式权重越高
    float hpRatio = bossHP / bossMaxHP;
    if (hpRatio < 0.3f) weight *= (entry.baseWeight > 5f) ? 1.5f : 0.8f;
    
    return weight;
}

string SelectAttack() {
    var validAttacks = attacks.Where(a => a.requiredPhases.Contains(currentPhase));
    var weights = validAttacks.Select(a => GetAttackWeight(a)).ToList();
    float totalWeight = weights.Sum();
    if (totalWeight <= 0f) return "idle"; // 安全降级
    
    float roll = Random.Range(0f, totalWeight);
    float cumulative = 0f;
    for (int i = 0; i < validAttacks.Count(); i++) {
        cumulative += weights[i];
        if (roll <= cumulative) return validAttacks.ElementAt(i).attackId;
    }
    return validAttacks.Last().attackId;
}
```

**招式执行帧序列规范：**

每个Boss招式必须定义以下帧序列（60fps基准）：

| 帧阶段 | 代码字段 | 说明 | 可中断 |
|--------|---------|------|--------|
| 预警帧 | `warningFrames` | 视觉/音频信号展示，Boss身体变化/地面警示 | 否 |
| 前摇帧 | `windupFrames` | Boss蓄力/准备动作，姿态明确变化 | 否（除非被玩家打断Boss霸体） |
| 判定帧 | `activeFrames` | 伤害判定生效，判定区可见 | 否 |
| 后摇帧 | `recoveryFrames` | 收招恢复，Boss不可行动但也无判定 | 否 |
| 空闲帧 | `idleFrames` | 后摇结束后的短暂等待，防止连续攻击过于密集 | 是 |

```
总招式帧数 = warningFrames + windupFrames + activeFrames + recoveryFrames
玩家安全输出窗口 = recoveryFrames（后摇期间）+ idleFrames
预警总时间 = warningFrames + windupFrames（玩家可反应时间）
```

**场地障碍物设计约束：**

- 障碍物数量：3~6个
- 障碍物不可完全遮挡Boss（最多遮挡30%视野）
- 障碍物可被Boss的特定招式破坏（增加动态变化）
- 障碍物位置每局随机，但保证场地4个象限各至少1个
- 弹幕类招式不可穿过障碍物（给予玩家掩体策略）

## 3.7.2 第1层Boss - 遗迹守护者（Guardian of the Ruins）

### 背景故事

遗迹守护者是原界崩塌前最后一任"守门人"的残影。当大崩塌发生时，守门人用自己的身体封住了遗迹核心的裂隙，阻止虚无从内部吞噬这片碎片。千年来，他的意识早已消散，只留下被裂隙能量固化的石壳和永不停歇的守护本能。位面行者踏入遗迹深处时，守护者的古老程序被重新激活——他无法分辨来者是敌是友，只会执行最后的命令：**"禁止任何人接近核心。"**

击败守护者后，他的石壳碎裂，内部露出一颗闪烁的时之碎片——那是他千年来守护的东西，也是通往下一层位面的钥匙。

### 外观描述

- **身高**：3.5格（远大于普通敌人）
- **体型**：人形，石质躯壳，全身覆盖青灰色岩石甲壳
- **头部**：无面，面部是一块光滑的黑色石板，中央有一道发光的蓝色裂隙（核心所在）
- **双臂**：左臂是巨大的方形石盾（2.0格宽），右臂是粗壮的石拳
- **背部**：4根石柱状突起，从脊柱向外延伸，顶部分别有蓝色发光节点
- **移动方式**：沉重的步行，每一步产生地面震尘特效
- **阶段变化**：
  - P1：完整的石壳，蓝色裂隙稳定发光
  - P2：石壳出现大面积裂纹，裂隙发出红橙色光，背部石柱断裂2根
  - 狂暴：全身裂纹布满红光，行动加速，每步伴随碎石飞溅

## 3.7.3 第2层Boss - 虚空树母（Void Tree Matriarch）

### 背景故事

虚空树母曾是位面碎片上最古老的"世界树"的残根。在大崩塌中，世界树为了保护这片碎片的生灵，将自己的根系深深扎入虚无之海，以自身为锚点稳定位面。然而，虚无的力量远超她的想象——千年的侵蚀让她的意识扭曲，根系变成了汲取生命而非滋养生命的虚空触须。如今，她不再是生命之母，而是死亡之母，用虚空的孢子感染一切靠近的生物，将它们转化为自己的"子嗣"。

她的树洞中心还保存着一颗翠绿的种子——那是世界树最后的纯净意志，也是她仅存的人性。

### 外观描述

- **体型**：中央树干直径3.0格，高5.0格，位于场地中央偏后
- **树干**：灰黑色扭曲树干，表面布满紫黑色脉络（虚空侵蚀）
- **根须**：6条粗壮根须从树干底部向四周延伸，每条根须长4~6格
- **树冠**：稀疏的黑色枝干，挂满紫色发光孢子囊
- **面部**：树干中央有一个类似面孔的树洞，内部发出暗紫色幽光
- **阶段变化**：
  - P1：6条根须完整，树冠紫色孢子稳定
  - P2：3条根须断裂，树冠半秃，树洞发出红紫色光，更多孢子释放
  - 狂暴：树干裂开，内部全是虚空紫光，根须疯狂抽打

## 3.7.4 第3层Boss - 时之叛徒（Traitor of Time）

### 背景故事

时之叛徒原名"赛拉斯·永时针"，曾是时之议会最杰出的位面行者之一。他是最早发现时间操控深层秘密的人——不仅能停止和回溯时间，还能"编辑"时间线中的事件。然而，当他试图使用这种力量阻止大崩塌时，发现自己每一次修改都会导致另一条时间线的崩塌。在绝望中，他做出了禁忌的选择：试图将所有时间线折叠为一条，从而彻底消灭虚无——代价是抹除所有其他位面行者的存在。

时之议会将他放逐至时间裂隙，但裂隙非但没有毁灭他，反而赋予了他操控时间本身的力量。他不再是位面行者——他成了时间的叛徒，能够反制一切时间操控。

他对位面行者说的第一句话："你和曾经的我一样天真。时间不是武器，时间是牢笼。"

### 外观描述

- **身高**：2.0格（与玩家同高，人形Boss）
- **体型**：修长的人形，穿着破败的时之议会长袍（金色纹路已褪色为灰白）
- **头部**：半透明的时间扭曲面容——时而清晰时而模糊，仿佛在不同时间线间闪烁
- **双臂**：左手持一把碎裂的怀表（武器），右手掌心有一个时间漩涡
- **特效**：身体周围时刻有细小的时间碎片飘散；移动时留下0.5秒的残影
- **阶段变化**：
  - P1：灰白长袍，沉稳姿态，使用时间操控对抗玩家
  - P2：长袍碎裂半褪，身体半透明化，时间碎片更大更多，行动更狂暴
  - 狂暴：身体几乎完全透明，仅被时间碎片和金色能量勾勒出轮廓

### 核心机制：时间操控反制

**这是第3层Boss的核心设计——Boss会与玩家进行时间技能博弈。反制不是惩罚玩家使用核心机制，而是要求玩家观察反制冷却并寻找反制后的收益窗口。**

| 玩家时间技能 | Boss反制行为 | 反制效果 | 玩家可利用窗口 |
|-------------|-------------|---------|----------------|
| 时间停止 | Boss在时停生效1.2秒后尝试解除，并释放时间冲击波 | Boss行动恢复；冲击波半径4格，造成20点时间伤害+击退2格 | 解除动作有45帧后摇；若玩家在解除前打中怀表弱点，冲击波取消且Boss后摇延长1秒 |
| 时间回溯 | Boss标记玩家回溯终点并短暂追击 | Boss不回溯HP，只闪现到玩家旧路径附近 | 玩家若让回溯路径穿过Boss，可在路径上留下"时间裂痕"，Boss踩中后受到时间伤害并减速 |
| 时间加速 | Boss展开短时减速场 | 半径6格区域内玩家移速-30%，持续2秒 | 加速期间连续命中6次可打破减速场，触发3秒破防 |
| 时间裂隙 | Boss向裂隙释放时间脉冲 | 裂隙持续时间减半，但不会立即消失 | 被脉冲命中的裂隙变为不稳定裂隙，2秒后爆发并延长Boss当前后摇 |

**反制触发逻辑：**

```text
void OnPlayerTimeSkillUsed(TimeSkillType skillType) {
    float reactionDelay = Random.Range(0.3f, 0.8f); // 0.3~0.8秒反应延迟
    StartCoroutine(CounterTimeSkill(skillType, reactionDelay));
}
```

**注**：反制不是100%成功——每次Boss反制后有15秒的"反制冷却"，期间Boss无法反制时间技能。玩家可以选择诱导Boss交出反制，再用下一次时间技能获得完整收益。

**时间技能正向策略清单：**

| 时间技能 | 推荐用法 |
|----------|----------|
| 时间停止 | 在Boss准备解除时攻击怀表弱点，取消冲击波并制造额外输出窗口 |
| 时间回溯 | 预设回溯路径穿过Boss，让路径裂痕成为额外伤害源 |
| 时间加速 | 在Boss减速场内强行打满连击，换取破防窗口 |
| 时间裂隙 | 把裂隙放在Boss常用闪现落点，诱导不稳定裂隙爆发 |

## 3.7.5 第4层Boss - 熔炉领主（Forge Lord）

### 背景故事

熔炉领主是由位面熔炉的意志与无数位面行者的遗骸融合而成的存在。位面熔炉是大崩塌前用于锻造位面核心的终极设施——每一次新位面的诞生都始于这座熔炉的火焰。然而大崩塌时，最后一批试图修复世界的位面行者将自己投入熔炉，试图以自身为燃料重燃创世之火。

他们失败了。但他们的灵魂、意志和残骸与熔炉融为一体，诞生了一个新存在——熔炉领主。他拥有所有献身者的记忆碎片和锻造位面的原始力量，但他已不再是人类，也不再是位面行者。他是熔炉本身。

他的身体就是熔炉，他的每一次攻击都是在锻造——锻造毁灭。

### 外观描述

- **形态1——铸造者（The Smith）**：
  - 身高3.0格，人形，全身覆盖暗红色熔岩铠甲
  - 左臂是巨大的铁锤（2.5格长），右臂是熔炉喷口
  - 头部是燃烧的铁盔，面部只有2个白色火焰瞳孔
  - 移动时脚下留下熔岩脚印（0.5秒后消失）

- **形态2——熔炉本体（The Furnace）**：
  - 身高4.0格，不再人形——身体展开为巨大的熔炉结构
  - 中央是一个燃烧的炉口（3格直径），四周伸出4条铁砧臂
  - 底部是3条粗壮的炉腿支撑
  - 此形态Boss固定在场地中央

- **形态3——锻成者（The Forged）**：
  - 身高2.5格，重新人形但更为精炼
  - 全身银白色金属，关节处有红色熔岩光纹
  - 双手持一把巨大的锻成品巨剑（3.0格长）
  - 移动速度大幅提升，攻击更快更致命

## 3.7.6 第5层最终Boss - 虚无之王（King of the Void）

### 背景故事

虚无之王不是一个人，不是一个神，不是一种力量——虚无之王是"虚无"本身获得了意识的形态。

在大崩塌之前，虚无只是"存在"的对立面——没有意识，没有意志，仅仅是"无"。但当原界碎裂时，无数位面碎片的意识碎片跌入虚无之海，这些意识碎片中的一部分被虚无吸收，赋予了它自我意识。

虚无之王因此诞生。他拥有了思考能力，但他的思考逻辑与任何生命都不同——他不是一个"想要毁灭世界的反派"，他是"虚无本身发现了自己存在"这一事实后的自然反应。对虚无之王而言，存在本身就是一个错误，一个需要被纠正的异常。他不恨任何人，他只是在执行自己的本质——将一切归零。

他的王座位于所有位面碎片的交汇点——虚无之海的最深处。他坐在由无数位面碎片残骸堆叠而成的王座上，手中握着最后一道裂缝——那是原界核心最后的余烬。

### 外观描述

**阶段1——人形态（Humanoid Form）：**
- 身高2.2格，与玩家相近但略高
- 身穿虚无编织的王袍——王袍不是布料，而是不断流动的深紫色虚无能量
- 面容：一张苍白的、中性的面孔，双眼是深邃的虚无深渊（纯黑，无光）
- 右手持一柄虚无权杖（顶部有旋转的微型黑洞）
- 左手戴一只由位面碎片制成的手套
- 特效：脚下有微弱的虚无雾气，移动时空间微微扭曲

**阶段2——虚无形态（Void Form）：**
- 身高4.0格，不再人形
- 身体变为巨大的虚无漩涡——一个旋转的深紫色黑洞实体
- 中心有一个不断脉动的暗紫色核心（弱点所在）
- 周围环绕6条虚无触须（各长5格，可独立攻击）
- 特效：身体周围的空间明显扭曲，光线被弯曲

**阶段3——融合形态（Merged Form）：**
- 身高3.0格，重新人形但超越人类
- 右半身是人形态的苍白面孔和王袍
- 左半身是虚无形态的深渊漩涡和触须
- 面容分裂：右眼正常，左眼是旋转的黑洞
- 右手持权杖（可释放虚无能量），左手是虚无触须（可延伸攻击）
- 特效：左右半身交界处不断有位面碎片闪烁、崩塌、重组

## 3.7.7 Boss挑战模式

### Boss Rush模式设计

**解锁条件：** 通关1次（击败虚无之王）

**模式描述：**
- 连续挑战所有5个Boss，中间无普通房间
- 每击败1个Boss后获得选择奖励（祝福/道具/回复），然后立即进入下一个Boss

**难度缩放：**

| 参数 | Boss Rush值 |
|------|-----------|
| Boss HP | 原始HP × 1.2 |
| Boss ATK | 原始ATK × 1.1 |
| 玩家初始HP | 100（标准值） |
| 初始武器 | 自选 |
| 初始道具 | 0个 |
| 初始祝福 | 0个 |
| 初始金币 | 100 |
| Boss间回复 | 每Boss战后回复30%最大HP |

**Boss间奖励选择：**
- 每次Boss战后从3个选项中选择1个：
  - 祝福（从当前可用祝福池随机）
  - 道具（从稀有/传说池随机）
  - 完整回复（回复100%HP+时间能量）

**排行榜：**
- 记录通关时间
- 记录剩余HP百分比
- 记录使用的武器类型
- 全球排行榜 + 好友排行榜

**Boss Rush专属奖励：**

| 完成条件 | 奖励 |
|---------|------|
| 首次通关 | **行者之证**（传说道具）：所有Boss战中ATK+15%，解锁Boss Rush入场皮肤 |
| 5次通关 | **永恒行者**皮肤：玩家角色全身时间特效 |
| 无伤通关 | **虚无行者**皮肤：半透明虚无效果 |
| 10分钟内通关 | **速行者之靴**（稀有道具）：moveSpeed+15%，dashSpeed+20% |
