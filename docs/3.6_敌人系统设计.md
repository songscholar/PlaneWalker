# 3.6 敌人系统设计

---

## 3.6.1 敌人设计框架

### 敌人设计原则

**什么是有趣的敌人：**

1. **可读性优先**：每个敌人的攻击意图必须在动画前摇阶段即可辨识——颜色、姿态、特效三者至少其二给出信号。玩家死亡时应感到"我看懂了但没躲开"，而非"我不知道发生了什么"。
2. **单一核心交互**：每种敌人围绕1个核心机制设计（如格挡、冲刺、召唤），避免功能重叠。玩家的"顿悟时刻"来自理解并克制该核心机制。
3. **弱点明确**：每个敌人有至少1个可利用的弱点窗口（攻击后摇、蓄力暴露、移动轨迹锁定），弱点窗口持续0.5~1.2秒。
4. **节奏差异化**：快攻型敌人迫使玩家反应，重击型敌人迫使玩家贪刀后撤退，远程型敌人迫使玩家走位——不同节奏的敌人才产生配合压力。
5. **堆叠不无聊**：同一敌人3个同时在场时，行为仍需有差异（通过相位偏移、随机延迟、阵型逻辑实现），避免3个同步挥刀的木桩。

**敌人之间的配合关系：**

| 配合类型 | 描述 | 示例 |
|---------|------|------|
| 前排-后排 | 近战压制+远程输出，玩家必须处理其一 | 盾卫挡路+弓手射击 |
| 节奏打乱 | 慢速重击+快速轻击交替，破坏玩家闪避节奏 | 巨兵蓄力+盗贼连斩 |
| 区域控制 | 一个敌人封锁走位空间，另一个利用封锁区输出 | 冰霜法师冻结地面+冲锋兵直线冲击 |
| 召唤-本体 | 本体安全输出，召唤物消耗玩家资源 | 召唤师持续出兵+自身远程 |
| 增益-输出 | 一个敌人给另一个上buff，形成优先级判断 | 祭司给战士加攻速 |
| 时间差夹击 | 两个敌人从不同方向错峰攻击，无缝衔接 | 左右包夹的盗贼 |

### 敌人属性体系

| 属性 | 代码字段 | 基准单位 | 说明 |
|------|---------|---------|------|
| 生命值 | `hp` | 点 | 敌人承受伤害的上限 |
| 攻击力 | `atk` | 点/次 | 单次攻击基础伤害值 |
| 移动速度 | `moveSpeed` | 格/秒 | 1格=1世界单位，玩家基准移速=5.0 |
| 攻击频率 | `atkFreq` | 秒/次 | 两次攻击之间的最小间隔 |
| 检测范围 | `detectRange` | 格 | 进入范围触发"发现"状态 |
| 攻击范围 | `atkRange` | 格 | 可发动攻击的最大距离 |
| 击退抗性 | `knockResist` | 0~1 | 0=完全被击退，1=完全免疫 |
| 硬直抗性 | `staggerResist` | 0~1 | 0=攻击即硬直，1=永不硬直 |
| 威胁评级 | `threatLevel` | 1~5 | 影响生成权重和AI优先级 |

**威胁评级定义：**

| 威胁评级 | 定义 | 生成权重 | AI行为复杂度 |
|---------|------|---------|-------------|
| 1 | 炮灰/干扰型，单独威胁极低 | 1.0 | 仅追击+攻击 |
| 2 | 基础近战/远程，需关注但易应对 | 1.2 | 含1种特殊行为 |
| 3 | 核心威胁，处理不当会快速掉血 | 1.5 | 含2种攻击模式+1特殊行为 |
| 4 | 局势改变者，必须优先处理 | 1.0 | 含多攻击模式+配合行为 |
| 5 | 房间级威胁，存在即改变打法 | 0.6 | 含复杂行为链+环境交互 |

### 难度缩放公式

**全局缩放（基于当前层数 L，L=1~5）：**

```
HP倍率     = 1.0 + (L - 1) * 0.35           // L1=1.0, L2=1.35, L3=1.70, L4=2.05, L5=2.40
ATK倍率    = 1.0 + (L - 1) * 0.25           // L1=1.0, L2=1.25, L3=1.50, L4=1.75, L5=2.00
数量倍率    = 1.0 + (L - 1) * 0.15           // L1=1.0, L2=1.15, L3=1.30, L4=1.45, L5=1.60
```

**房间内缩放（基于房间序号 R，同一层内R从1递增）：**

```
HP额外倍率  = 1.0 + (R - 1) * 0.05          // 每过1房HP+5%
ATK额外倍率 = 1.0 + (R - 1) * 0.03          // 每过1房ATK+3%
精英概率    = 0.08 + (R - 1) * 0.02          // 初始8%，每房+2%，上限35%
```

**时间因子（进入当前层后经过的实时分钟数 T）：**

```
紧迫倍率    = 1.0 + max(0, T - 5) * 0.01    // 5分钟后每分钟全局+1%HP和ATK
```

**最终属性计算：**

```
finalHP   = baseHP × HP倍率 × HP额外倍率 × 紧迫倍率
finalATK  = baseATK × ATK倍率 × ATK额外倍率 × 紧迫倍率
finalCount = floor(baseCount × 数量倍率)
```

### 敌人AI行为树设计规范

**有限状态机结构（6态）：**

```
┌─────────┐
│  PATROL │ ← 初始状态/失去目标后
└────┬────┘
     │ 玩家进入detectRange
     ▼
┌─────────┐
│  ALERT  │ ← 发现目标，面向玩家，短暂停顿
└────┬────┘
     │ 0.3~0.6秒后（各敌人不同）
     ▼
┌─────────┐
│  CHASE  │ ← 向玩家移动，持续检测atkRange
└────┬────┘
     │ 玩家进入atkRange
     ▼
┌─────────┐
│ ATTACK  │ ← 执行攻击序列
└────┬────┘
     │ 攻击结束 + 后摇完毕
     ▼
┌─────────┐
│ RETREAT │ ← 部分敌人攻击后后退（可配置）
└────┬────┘
     │ 后退完成 / 超时
     ▼
┌─────────┐
│  DEATH  │ ← HP<=0 触发，播放死亡动画后销毁
└─────────┘
```

**状态转换规则（伪代码）：**

```text
enum EnemyState { PATROL, ALERT, CHASE, ATTACK, RETREAT, DEATH }

void UpdateState() {
    float distToPlayer = Vector3.Distance(transform.position, player.position);
    
    switch (currentState) {
        case PATROL:
            // 沿巡逻路径移动或原地待机
            if (distToPlayer <= detectRange && HasLineOfSight()) {
                TransitionTo(ALERT);
                alertTimer = enemyData.alertDuration; // 0.3~0.6s
            }
            break;
            
        case ALERT:
            FacePlayer();
            alertTimer -= deltaTime;
            if (alertTimer <= 0) TransitionTo(CHASE);
            if (distToPlayer > detectRange * 1.5) TransitionTo(PATROL); // 脱离
            break;
            
        case CHASE:
            MoveToward(player.position, moveSpeed);
            if (distToPlayer <= atkRange) {
                TransitionTo(ATTACK);
                SelectAttackPattern(); // 根据距离和冷却选择攻击模式
            }
            if (distToPlayer > detectRange * 1.5) TransitionTo(PATROL);
            break;
            
        case ATTACK:
            // 由攻击模式驱动，不在此处转换
            break;
            
        case RETREAT:
            MoveAwayFrom(player.position, moveSpeed * 0.6f);
            retreatTimer -= deltaTime;
            if (retreatTimer <= 0) TransitionTo(CHASE);
            break;
            
        case DEATH:
            // 不可转换，等待动画结束销毁
            break;
    }
}
```

**攻击模式执行规范：**

每条攻击模式分为三阶段，以帧为单位（60FPS基准）：

| 阶段 | 代码字段 | 说明 |
|------|---------|------|
| 前摇 | `windupFrames` | 信号展示阶段，可被打断（如果硬直抗性允许） |
| 活动 | `activeFrames` | 判定生效阶段，伤害判定在此期间 |
| 后摇 | `recoveryFrames` | 收招阶段，不可取消，玩家安全窗口 |

```text
struct AttackPattern {
    string name;           // 攻击名称
    int windupFrames;      // 前摇帧数
    int activeFrames;      // 活动帧数
    int recoveryFrames;    // 后摇帧数
    int damage;            // 伤害值 = enemy.atk × 伤害倍率
    float damageMultiplier;// 伤害倍率
    float range;           // 攻击范围(格)
    float angle;           // 攻击扇形角度(度)，360=全方向
    AttackShape shape;     // CIRCLE / RECT / SECTOR / LINE
    float cooldown;        // 冷却时间(秒)
    string[] effects;      // 附加效果ID列表
    string animationTrigger; // AnimationPlayer或AnimationTree触发器名
    string vfxPath;        // 特效路径
    string sfxPath;        // 音效路径
}
```

### 敌人1-1：碎岩卫兵（Shattered Sentinel）

**主题描述：** 遗迹中由碎石拼成的守卫，动作沉重而缓慢，手持残破的石盾。是最基础的近战教学敌人。

**属性数值：**

| 属性 | 值 |
|------|-----|
| HP | 80 |
| ATK | 12 |
| moveSpeed | 2.0 |
| atkFreq | 2.5秒/次 |
| detectRange | 6.0 |
| atkRange | 1.8 |
| knockResist | 0.6 |
| staggerResist | 0.4 |
| threatLevel | 1 |

**AI行为描述：**

- PATROL：原地待机，每隔3秒转向随机方向（左右各90度范围内）
- ALERT：面向玩家，停顿0.5秒，头顶出现橙色感叹号特效
- CHASE：以moveSpeed向玩家直线移动，无绕行逻辑
- ATTACK：进入atkRange后执行"石盾横扫"
- RETREAT：攻击后后退1.2格，持续0.8秒，后退移速=1.2
- DEATH：碎裂为3~5块碎石粒子飞散，0.6秒后销毁

**攻击模式表：**

| 攻击名 | 前摇(帧) | 活动(帧) | 后摇(帧) | 伤害 | 范围 | 形状 | 附加效果 | 冷却 |
|--------|---------|---------|---------|------|------|------|---------|------|
| 石盾横扫 | 30 | 8 | 25 | 12 | 1.8格 | SECTOR/180° | 无 | 2.5秒 |

- 前摇动画：举盾蓄力，右脚后撤一步，橙色蓄力光效从盾面扩散
- 活动动画：盾牌横向扫过180度弧线
- 后摇动画：盾牌回位，身体重心前倾后恢复

**特殊机制：** 无。纯基础教学敌人。

**配合关系：** 2~3个碎岩卫兵一起时，通过错峰攻击（每个卫兵的atkFreq初始偏移随机0~1.5秒）形成持续但不致命的压力。

### 敌人1-4：遗迹游魂（Ruins Wraith）

**主题描述：** 遗迹中徘徊的灵体，会穿过障碍物飘向玩家，在近距离自爆。教学"不可阻挡的逼近需要优先击杀"。

**属性数值：**

| 属性 | 值 |
|------|-----|
| HP | 50 |
| ATK | 20（自爆） |
| moveSpeed | 3.0 |
| atkFreq | 一次性（自爆后死亡） |
| detectRange | 8.0 |
| atkRange | 1.2（自爆触发距离） |
| knockResist | 0.3 |
| staggerResist | 0.2 |
| threatLevel | 2 |

**AI行为描述：**

- PATROL：以moveSpeed×0.3缓慢飘荡，可穿墙
- ALERT：身体膨胀20%，发出蓝色脉冲光效，停顿0.4秒后进入CHASE
- CHASE：以moveSpeed直线飘向玩家，可穿过所有障碍物，不寻路
- ATTACK：进入1.2格范围后执行"灵体自爆"（有1.0秒蓄力窗口）
- RETREAT：无（不自爆即不后退）
- DEATH：自爆时产生蓝色冲击波特效，0.3秒后销毁

**攻击模式表：**

| 攻击名 | 前摇(帧) | 活动(帧) | 后摇(帧) | 伤害 | 范围 | 形状 | 附加效果 | 冷却 |
|--------|---------|---------|---------|------|------|------|---------|------|
| 灵体自爆 | 60 | 6 | 0 | 20 | 2.0格 | CIRCLE | 自身死亡,击退1.0格 | 一次性 |

- 前摇动画：身体急速膨胀，发出越来越亮的蓝白色光，最后闪烁3次表示即将爆炸

## 3.6.6 精英敌人通用规则

### 精英化条件

| 条件 | 说明 |
|------|------|
| 触发概率 | `eliteChance = 0.08 + (roomIndex - 1) * 0.02`，上限0.35 |
| 每房间精英上限 | `maxElitesPerRoom = 1 + floor(roomIndex / 3)` |
| 不可精英化 | Boss、召唤物（萤火虫/小孢子等）、已精英化的敌人 |
| 精英生成时机 | 房间敌人生成时按概率随机选取，优先选取threatLevel≥3的敌人 |
| 代码实现 | `if (Random.value < eliteChance && eliteCount < maxElites && enemy.threatLevel >= 1 && !enemy.isSummon) { enemy.ApplyEliteTemplate(); }` |

### 精英基础属性变化

| 属性 | 变化 |
|------|------|
| HP | baseHP × 3 |
| ATK | baseATK × 1.5 |
| 体型 | ×1.15 |
| 新增技能 | 1个（各敌人定义中已指定） |
| 新增词缀 | 1~2个（见下方词缀系统） |

### 精英词缀系统

精英词缀在精英化时随机分配1~2个（第1~2层1个，第3~4层2个）。词缀不可重复，且互斥词缀不可同时出现。

| 词缀名 | 代码ID | 效果 | 互斥 | 适用层 |
|--------|--------|------|------|--------|
| **狂暴** | `FRENZY` | ATK+40%，moveSpeed+20%，但受到伤害+25% | 坚韧 | 1~4 |
| **坚韧** | `FORTIFIED` | HP额外+100%（总计×6），knockResist+0.3，但moveSpeed-25% | 狂暴 | 1~4 |
| **再生** | `REGENERATING` | 每2秒回复3%最大HP（战斗中） | 虚无 | 1~4 |
| **瞬移** | `TELEPORTING` | 每8秒随机传送到3~5格远处，传送前0.5秒身体闪烁 | 锚固 | 2~4 |
| **分裂** | `SPLITTING` | 死亡时分裂为2个HP=33%的普通版（非精英）敌人 | 虚无 | 2~4 |
| **护盾** | `SHIELDED` | 获得30%最大HP的护盾，护盾每20秒重新生成 | 再生 | 2~4 |

roomThreatScore = Σ(enemy.threatLevel × enemy.count × difficultyMultiplier)

L2: 1.5
L3: 2.2

**单房间敌人上限：**

|------|-------------|-------------|-------------|-----------|

| L3 | 8 | 2 | 28 | 6 |

**类型平衡规则：**

| 规则 | 说明 |
|------|------|
| 远程≤近战 | 远程型敌人数量不超过近战型敌人数量（含召唤物） |
| 辅助≤1/3 | 辅助型敌人（threatLevel=4以上且非直接输出型）不超过总数1/3 |
| 威胁5限1 | 同房间threatLevel=5的敌人最多1个 |
| 波次递增 | 多波次房间中，每波敌人总数不超过上限的60%，但总波次累计可达上限的150% |
| 最低近战 | 任何房间至少有1个近战型敌人（防止纯远程风筝战） |

**生成权重系统：**

每种敌人有一个基础生成权重（见各层敌人定义），实际权重受以下因素修正：

```
actualWeight = baseWeight
    × (1.0 - sameTypeInRoom × 0.15)     // 同类型每多1个权重-15%
    × (1.0 + missingRoleBonus)            // 缺少某种角色类型时对应类型+30%
    × layerMultiplier                     // 层数修正
    × (isFirstRoom ? 0.5 : 1.0)          // 第1间房权重减半（简单开场）

// missingRoleBonus: 如果房间中没有远程型敌人，远程型权重+30%
// layerMultiplier: 当前层设计的敌人权重×1.5，非当前层(回溯出现)×0.3
```

**波次生成模板：**

| 波次 | 生成规则 |
|------|---------|
| 第1波 | 总威胁分≤房间上限40%，近战:远程=2:1 |
| 第2波 | 总威胁分≤房间上限35%，可引入辅助型 |
| 第3波 | 总威胁分≤房间上限25%，精英概率+10% |
| 第4波(如有) | 总威胁分≤房间上限20%，精英概率+20%，保证至少1个精英 |

**回溯敌人规则（高级层出现低级层敌人）：**

| 规则 | 说明 |
|------|------|
| 出现概率 | 20%概率在高级层的某个房间中出现1~2个低级层敌人 |
| 属性缩放 | 低级层敌人属性按当前层缩放公式计算（不使用原始层数值） |
| 新增机制 | 低级层敌人可获得1个当前层主题的特殊技能（随机选取） |
| 示例 | L3出现1个碎岩卫兵，属性按L3缩放，额外获得"时间回溯"1次 |
