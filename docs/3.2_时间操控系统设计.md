# 3.2 时间操控系统深度设计

> **文档版本**: v1.0  
> **游戏**: Plane Walker: Chronicles of Collapse  
> **定位**: 时间操控是本作的核心特色系统，贯穿战斗、探索、Build构建的全部体验。  
> **设计原则**: 时间操控不是"锦上添花"的辅助功能，而是玩家战斗循环的核心支点——普通攻击为时间技能充能，时间技能创造输出窗口，两者交替形成节奏。

## 3.2.1 时之能量系统

### 3.2.1.1 基础参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 时之能量上限（BaseMaxChronos） | 100 | 基础上限，可通过祝福/道具提升 |
| 时之能量上限硬顶 | 200 | 任何增益不可超越的绝对上限 |
| 自然恢复速率 | 3 点/秒 | 站立时；移动时降至 2 点/秒 |
| 击杀恢复（普通敌人） | 8 点 | 击杀瞬发，无延迟 |
| 击杀恢复（精英敌人） | 20 点 | — |
| 击杀恢复（Boss） | 35 点 | Boss阶段切换时额外 +15 |
| 完美操作恢复——完美闪避 | 15 点 | 闪避帧 ±3帧 内触发 |
| 完美操作恢复——完美格挡 | 12 点 | 格挡窗口 ±2帧 内触发 |
| 完美操作恢复——连击保持 | 5 点/次 | 连击数 ≥10 时，每命中一次恢复 |
| 受伤惩罚 | -5 点 | 每次受到伤害扣减（不低于0） |

### 3.2.1.2 能量消耗与恢复完整公式

**基础消耗公式：**

```
ActualCost = BaseCost × (1 - CostReduction) × HasteMultiplier
```

- `CostReduction`：来自祝福/道具的消耗降低，上限 50%（即乘数不低于 0.5）
- `HasteMultiplier`：当连续使用时间技能时递增惩罚
  - 第1次：1.0
  - 第2次（距上次 ≤8秒）：1.2
  - 第3次（距上次 ≤8秒）：1.5
  - 第4次及以上（距上次 ≤8秒）：1.8
  - 超过8秒未使用时间技能则重置为1.0

**自然恢复公式：**

```
RegenPerSecond = BaseRegen × (1 + RegenBonus) × CombatStateModifier
```

- `BaseRegen` = 3.0
- `RegenBonus`：来自祝福/道具，上限 +100%（即翻倍）
- `CombatStateModifier`：
  - 非战斗状态：1.5
  - 战斗中站立：1.0
  - 战斗中移动：0.67
  - 战斗中攻击/闪避动作中：0.0（动作期间不自然恢复）

**击杀恢复公式：**

```
KillRegen = BaseKillRegen × (1 + KillRegenBonus) × ElapsedTimeDecay
```

- `BaseKillRegen`：见上表
- `KillRegenBonus`：来自祝福/道具，上限 +100%
- `ElapsedTimeDecay`：距离上次击杀的时间衰减
  - ≤2秒：1.0
  - 2~5秒：线性降至 0.6
  - >5秒：0.6（最低保底）

**完美操作恢复公式：**

```
PerfectRegen = BasePerfectRegen × (1 + PerfectBonus) × ComboMultiplier
```

- `BasePerfectRegen`：见上表
- `PerfectBonus`：来自祝福/道具，上限 +150%
- `ComboMultiplier`：
  - 连击数 <5：1.0
  - 连击数 5~14：1.2
  - 连击数 15~29：1.5
  - 连击数 ≥30：2.0

### 3.2.1.3 能量UI显示规则

**能量条布局：**
- 位置：屏幕底部中央偏左，角色血条下方
- 尺寸：200×12 像素（基准分辨率 1920×1080）
- 颜色渐变：0%~30% 深蓝(#1a237e)→中蓝(#1565c0)；30%~70% 中蓝→青蓝(#00bcd4)；70%~100% 青蓝→亮白蓝(#e0f7fa)
- 背景条：半透明黑(#000000, alpha=0.4)

**数字显示：**
- 能量条右端显示当前整数数值，字体 12pt，颜色同条颜色
- 上限非100时，显示"当前/上限"格式

**预警提示：**
- 能量 <20%：能量条边缘脉冲闪烁，频率 2Hz，颜色偏红(#e53935)
- 能量 <10%：闪烁频率升至 4Hz，同时屏幕边缘出现淡红色晕影（alpha=0.15，径向渐变）
- 能量 =0：能量条碎裂动画（0.3秒），能量条变灰(#424242)，显示"时间停滞"文字提示 1.5秒
- 能量恢复至 >20%：预警效果立即消退，能量条恢复动画 0.2秒

**技能图标能量指示：**
- 每个时间技能图标外圈有能量消耗预显示弧线
- 能量不足时，该技能图标灰度化 + 红色叉号
- 能量刚够时（差额 <5），图标边缘黄色脉冲提示

**时之能量变化飘字：**
- 恢复：向上飘出 "+X" 蓝色文字，0.8秒淡出
- 消耗：向下飘出 "-X" 紫色文字，0.8秒淡出
- 受伤扣减：向上飘出 "-X" 红色文字 + 短暂屏幕微震（振幅2px，持续0.1秒）

## 3.2.2 四大时间技能详解

### 3.2.2.1 时间停止（Chrono Freeze）

**完整效果描述：**
冻结当前场景中所有受时间影响的敌人、弹幕和环境物体。玩家自身不受影响。被冻结的目标无法移动、攻击、转身，但保留受击判定（可被攻击）。冻结期间玩家对被冻结目标造成的伤害有加成。

**帧级别时间线（60FPS基准）：**

| 阶段 | 帧数 | 持续时间 | 说明 |
|------|------|----------|------|
| 前摇 | 12帧 | 200ms | 玩家举起左手，掌心出现时钟符文；玩家可移动但不可攻击 |
| 生效 | 1帧 | ~16.7ms | 全屏时间冻结脉冲波扩散（纯视觉），所有受影响目标进入冻结 |
| 持续 | 180~360帧 | 3~6秒 | 基础持续3秒(180帧)；通过祝福/道具最多延至6秒(360帧) |
| 消退 | 30帧 | 500ms | 被冻结目标身上冰晶碎裂粒子效果，逐步恢复行动 |

**消耗与冷却公式：**

```
BaseCost = 35
ActualCost = 35 × (1 - CostReduction) × HasteMultiplier  // 见3.2.1.2
BaseCooldown = 12秒
ActualCooldown = 12 × (1 - CDR)  // CDR上限60%，即最低4.8秒
```

**冻结伤害加成：**
- 对冻结目标的伤害倍率：1.3×（基础）
- 每多冻结1秒，倍率 +0.05（最高 1.3 + 0.15 = 1.45×）

**与敌人交互规则：**

| 敌人类型 | 反应 | 说明 |
|----------|------|------|
| 普通敌人 | 完全冻结 | — |
| 精英敌人 | 完全冻结，但持续时间 ×0.6 | 3秒→1.8秒 |
| 时间构造体 | 免疫 | 该类敌人自带时之能量护盾 |
| 时间行者 | 反弹 | 25%概率反弹时间停止效果给玩家（玩家减速50%，持续1.5秒） |
| 章节Boss | 减半+递减 | 第一次冻结持续 ×0.4（1.2秒），同一Boss战中每次再使用再 ×0.5，最低至0.3秒 |
| 最终Boss | 高抗性转化 | 不长时间冻结，但会延长后摇、暴露弱点或冻结其弹幕/召唤物1秒 |

**与道具/祝福的联动列表：**

| 道具/祝福名 | 效果 |
|-------------|------|
| 永恒沙漏 | 时间停止持续时间 +1秒(60帧) |
| 冰川之心 | 时间停止期间玩家攻速 +30% |
| 时间猎手印记 | 时间停止中对冻结目标的暴击率 +25% |
| 裂隙共鸣器 | 时间停止消退时，在冻结敌人位置生成一个小型时间裂隙(半径2m，持续2秒) |
| 停滞碎片(×3叠加) | 每叠加1层，时间停止消耗 -5（最多-15） |
| 时光织女的祝福 | 时间停止消退后的2秒内，敌人移速 -20% |
| 碎时者之戒 | 时间停止中击杀敌人，恢复 10 点时之能量 |
| 绝对零度护符 | 时间停止持续期间，冻结目标每秒受到 攻击力×5% 的时之伤害 |

**升级路径：**

| 等级 | 解锁条件 | 强化效果 |
|------|----------|----------|
| Lv.1 | 初始 | 基础效果 |
| Lv.2 | 获得1个时间停止相关祝福 | 持续时间 +0.5秒(30帧) |
| Lv.3 | 获得3个时间停止相关祝福 | 消退时产生时之冲击波，半径3m，造成 攻击力×40% 伤害 |
| Lv.4 | 获得5个时间停止相关祝福 | 前摇取消（12帧→0帧），可攻击中瞬发释放 |
| Max | 获得"永恒沙漏"+"冰川之心" | 时间停止期间所有伤害倍率固定为 2.0× |

**视觉/音效设计方向：**
- 视觉：生效瞬间全屏色彩饱和度降至30%，加入蓝色色调滤镜；被冻结目标表面覆盖半透明冰晶/时钟碎片纹理；背景粒子（灰尘、落叶）完全静止
- 音效：生效时——低频轰鸣(60Hz正弦波，0.3秒衰减) + 时钟滴答声急促后骤停；消退时——玻璃碎裂音效 + 逆向时钟滴答声渐起
- 屏幕特效：生效脉冲波——从玩家位置向外的圆形冲击波，半径15m，0.2秒扩散完毕，半透明白色

### 3.2.2.2 时间回溯（Chrono Recall）

**完整效果描述：**
将玩家自身回溯到5秒前的位置、生命值、时之能量和状态。场景中敌人和环境不回溯。回溯后在原位置留下一个"时之残影"，残影持续2秒后消散，消散时对周围敌人造成时之伤害。

**帧级别时间线（60FPS基准）：**

| 阶段 | 帧数 | 持续时间 | 说明 |
|------|------|----------|------|
| 前摇 | 8帧 | 133ms | 玩家身体开始半透明化 + 倒带视觉效果 |
| 生效 | 6帧 | 100ms | 玩家瞬移至5秒前位置，血量/能量/状态瞬间回溯 |
| 残影生成 | 1帧 | ~16.7ms | 原位置生成时之残影实体 |
| 无敌窗口 | 30帧 | 500ms | 回溯后短暂无敌，防止被立即击杀 |
| 残影持续 | 120帧 | 2秒 | 残影存在，吸引附近敌人注意 |
| 残影消散 | 20帧 | 333ms | 残影爆散，造成范围伤害 |

**消耗与冷却公式：**

```
BaseCost = 45  // 四技能中最高消耗
ActualCost = 45 × (1 - CostReduction) × HasteMultiplier
BaseCooldown = 15秒
ActualCooldown = 15 × (1 - CDR)
```

**回溯回血限制：**
- 回溯后的生命值 = max(回溯时生命值, 1)
  - 即：如果5秒前生命值也极低，至少保证回溯后有1点HP
- 回溯后时之能量不低于 10（保底值），防止回溯后无法使用任何技能

**残影伤害：**
- 爆散伤害 = 攻击力 × 60%
- 爆散半径 = 3.5m
- 爆散附带 0.5秒减速 30%

**回溯状态快照内容：**
- 位置 (x, y, z)
- 朝向
- 当前生命值
- 当前时之能量（回溯后取5秒前值与当前值的较大者，但不超过上限）
- 当前Buff/Debuff列表（回溯清除所有Debuff，恢复5秒前的Buff）
- 武器状态（连击计数器回溯到5秒前的值）
- 动作状态（强制回到Idle）

**与敌人交互规则：**

| 敌人类型 | 反应 | 说明 |
|----------|------|------|
| 普通敌人 | 残影吸引仇恨2秒 | AI优先攻击残影 |
| 精英敌人 | 残影吸引仇恨1秒 | 之后重新锁定玩家 |
| 时间构造体 | 残影对其造成1.5×伤害 | 时之属性弱点 |
| 时间行者 | 可追击回溯轨迹 | 时间行者会沿玩家回溯路径移动，预判玩家位置 |
| 章节Boss | 免疫残影吸引 | Boss始终锁定玩家，不受残影干扰 |
| 最终Boss | 回溯时20%概率被Boss"时间锁定" | 玩家回溯后定身0.5秒 |

**与道具/祝福的联动列表：**

| 道具/祝福名 | 效果 |
|-------------|------|
| 回忆之镜 | 回溯距离增加至7秒 |
| 时之残响 | 残影伤害 +50%，爆散半径 +1.5m |
| 轮回之线 | 回溯后3秒内伤害 +20% |
| 不灭刻印 | 回溯如果回血量 >30%最大生命，额外获得2秒无敌 |
| 过去之眼 | 回溯时显示5秒前的敌人位置（半透明虚影），持续3秒 |
| 碎裂沙漏 | 残影消散时额外生成3个小型时之碎片弹幕，每个造成 攻击力×25% 伤害 |
| 时空织者的丝线 | 使用回溯后，下一次时间技能消耗 -30% |
| 因果逆转符 | 回溯清除Debuff时，每个被清除的Debuff恢复 5 点时之能量 |

**升级路径：**

| 等级 | 解锁条件 | 强化效果 |
|------|----------|----------|
| Lv.1 | 初始 | 基础效果 |
| Lv.2 | 获得1个回溯相关祝福 | 残影持续时间 +1秒(60帧) |
| Lv.3 | 获得3个回溯相关祝福 | 回溯后0.5秒内攻击必定暴击 |
| Lv.4 | 获得5个回溯相关祝福 | 回溯时可选择3/5/7秒（按住技能键0.5秒切换） |
| Max | 获得"回忆之镜"+"轮回之线" | 回溯后生成2个残影（原位置+2.5秒前位置），双倍爆散 |

**视觉/音效设计方向：**
- 视觉：前摇——玩家身体产生VHS倒带条纹噪点，从脚部到头部逐渐透明化；生效——旧位置爆出蓝色粒子环，玩家在新位置以"正向播放"方式出现（0.1秒内从透明到实体）；残影——半透明蓝色玩家模型，面朝回溯前方向，有轻微浮动动画
- 音效：前摇——磁带倒带声(高频→低频扫描)；生效——短促的"噗"音 + 钟表逆行声；残影消散——水晶碎裂 + 回声
- 轨迹线：回溯路径上显示一条淡蓝色光轨，持续1秒淡出，标示玩家移动路径

### 3.2.2.3 时间加速（Chrono Accelerate）

**完整效果描述：**
玩家自身进入时间加速状态，移动速度、攻击速度、闪避速度大幅提升，同时减缓时间感知（游戏以正常速度运行，但玩家操作的所有动作更快）。加速期间每次攻击附带时之伤害，且逐渐累积"时之过载"值——过载满后自动退出加速并受到反噬。

**帧级别时间线（60FPS基准）：**

| 阶段 | 帧数 | 持续时间 | 说明 |
|------|------|----------|------|
| 前摇 | 6帧 | 100ms | 玩家周围出现加速线特效 |
| 生效 | 1帧 | ~16.7ms | 进入加速状态 |
| 持续 | 最长600帧 | 最长10秒 | 过载值达到100或玩家主动取消时结束 |
| 过载预警 | — | 过载70~100期间 | 屏幕边缘橙色脉冲，频率随过载值增加 |
| 退出 | 15帧 | 250ms | 减速至正常，如果因过载退出则附带反噬 |
| 反噬硬直 | 45帧 | 750ms | 仅过载退出时：玩家动作减慢50%，不可使用时间技能 |

**消耗与冷却公式：**

```
BaseCost = 25  // 初始激活消耗
OvercostPerSecond = 8  // 持续期间每秒消耗
ActualCost = 25 × (1 - CostReduction) × HasteMultiplier
ActualOvercost = 8 × (1 - CostReduction)  // 持续消耗不受HasteMultiplier影响

BaseCooldown = 8秒（从退出加速开始计算）
ActualCooldown = 8 × (1 - CDR)
主动取消：消耗时之能量 = 已消耗总量，无反噬，冷却 ×0.6
过载退出：不额外消耗能量，但触发反噬硬直，冷却 ×1.0
```

**加速数值：**

| 属性 | 加速倍率 | 说明 |
|------|----------|------|
| 移动速度 | 1.6× | — |
| 攻击速度 | 1.4× | — |
| 闪避无敌帧 | 1.3× | 闪避距离 ×1.3 |
| 技能冷却流逝 | 1.5× | 加速期间其他技能CD加速流逝 |
| 时之能量自然恢复 | 0.5× | 加速期间恢复减半（代价） |

**时之过载系统：**
- 过载值范围：0~100
- 过载增长速率：12/秒（基础）
  - 攻击命中时额外 +3/次
  - 受到伤害时额外 +8/次
- 过载70以上时屏幕效果开始预警
- 过载达100自动退出 + 反噬

**附带的时之伤害：**
- 加速期间每次攻击额外附带 攻击力×15% 的时之属性伤害
- 此伤害不触发武器特效，但可触发"时之"相关祝福

**与敌人交互规则：**

| 敌人类型 | 反应 | 说明 |
|----------|------|------|
| 普通敌人 | 无特殊 | 正常受击 |
| 精英敌人 | 加速期间被击中5次后进入"时间错乱" | 错乱：随机方向移动2秒，攻击概率打偏 |
| 时间构造体 | 攻击附带伤害减半 | 时之抗性 |
| 时间行者 | 会尝试匹配玩家速度 | 时间行者加速至1.3×移速 |
| 章节Boss | 无特殊反应 | 但Boss攻击仍以正常速度判定 |
| 最终Boss | 加速期间受到的Boss伤害 +15% | 风险与收益并存 |

**与道具/祝福的联动列表：**

| 道具/祝福名 | 效果 |
|-------------|------|
| 闪电之心 | 加速移速倍率 +0.2（1.6→1.8） |
| 时间燃烧者 | 附带时之伤害 +10%（15%→25%） |
| 过载抑制器 | 过载增长速率 -4/秒（12→8） |
| 疾风刻印 | 加速期间闪避无敌帧额外 +5帧 |
| 时空压缩环 | 加速持续8秒以上时，攻速额外 +20% |
| 永动机碎片 | 加速期间击杀敌人恢复 5 过载值（降低过载） |

### 3.2.2.4 时间裂隙（Chrono Rift）

**完整效果描述：**
在目标位置创造一个时间扭曲区域（AOE场）。区域内的敌人时间流速降低（减速+行动延迟），玩家在区域内获得增益（冷却加速/伤害加成）。裂隙持续一段时间后坍缩，坍缩时对区域内敌人造成一次时之爆发伤害。可同时存在最多2个裂隙。

**帧级别时间线（60FPS基准）：**

| 阶段 | 帧数 | 持续时间 | 说明 |
|------|------|----------|------|
| 前摇 | 18帧 | 300ms | 玩家手臂挥出，发射裂隙投射物（飞行速度 15m/s） |
| 投射飞行 | 变动 | 距离/速度 | 最远射程 12m，到达目标位置或碰撞敌人后展开 |
| 展开动画 | 15帧 | 250ms | 裂隙从点扩展至完整半径 |
| 持续 | 360帧 | 6秒 | 裂隙稳定存在，持续影响区域内实体 |
| 坍缩预警 | 60帧 | 1秒 | 裂隙边缘收缩抖动，亮度增加 |
| 坍缩爆发 | 12帧 | 200ms | 裂隙急剧收缩至点后爆散 |

**消耗与冷却公式：**

```
BaseCost = 30
ActualCost = 30 × (1 - CostReduction) × HasteMultiplier
BaseCooldown = 10秒
ActualCooldown = 10 × (1 - CDR)

// 当已存在2个裂隙时，使用技能会替换最早生成的裂隙（立即坍缩）
```

**裂隙区域效果：**

## 3.2.3 武器-时间联动详解

> **核心设计理念**：每种武器拥有独特的"时间共鸣攻击"——在执行特定操作时，武器与时间操控产生联动，产生额外效果。这些联动不是自动触发的，而是需要玩家精确操作，形成"操作→回报"的正反馈循环。

### 3.2.3.1 剑——时之斩击（Chrono Slash）

**触发条件：**
- 在时间停止或时间加速状态中，执行重攻击（长按攻击键 ≥0.3秒后释放）
- 或：完美格挡成功后的1秒窗口内按下攻击键

**联动效果：**

| 属性 | 数值 | 说明 |
|------|------|------|
| 基础伤害 | 重攻击伤害 × 1.8 | 替代普通重攻击 |
| 斩击范围 | 扇形 120°，半径 3.5m | 比普通重攻击大50% |
| 时之附加伤害 | 攻击力 × 25% | 独立计算，时之属性 |
| 时之残痕 | 被击中的敌人留下"时之残痕" | 3秒内再次命中同一目标伤害 ×1.3 |
| 帧数据 | 前摇 20帧，生效 3帧，后摇 25帧 | 后摇可通过闪避取消(取消窗口第5~15帧) |

**与其他系统的交互：**
- 时之残痕可被时间裂隙刷新持续时间（敌人在裂隙中时残痕不倒计时）
- 时之斩击击杀敌人时，恢复 12 点时之能量（比普通击杀多4点）
- 时之斩击可破坏敌人的"时之护盾"（时间构造体的特殊护盾）

**进阶联动（需特定道具/祝福）：**

| 条件 | 增强效果 |
|------|----------|
| 装备"断时之刃" | 时之斩击前摇 -5帧，范围 +0.5m半径 |
| 装备"断时之刃"+ Lv.3时间停止 | 时之斩击命中时延长当前时间停止 0.5秒(30帧)/次，最多延长3秒 |
| 装备"剑圣的时空领悟" | 完美格挡→时之斩击连续输入时，伤害逐次 +20%（最多叠加3次） |
| 有"时之残响"祝福 | 时之残痕持续时间 +2秒，触发额外伤害时产生小型时之冲击波(半径1.5m, 攻击力×15%) |

### 3.2.4.2 Boss对时间技能的反应规则

**通用规则：**
- 每个Boss战开始时，Boss拥有"时间耐受值"(Temporal Tolerance)，初始为0
- 每次被时间技能影响，耐受值 +1
- 耐受值影响Boss对该时间技能的反应

| 时间技能 | 耐受值0 | 耐受值1 | 耐受值2 | 耐受值3+ |
|----------|---------|---------|---------|----------|
| 时间停止 | 持续×0.4(1.2秒) | 持续×0.2(0.6秒) | 持续×0.1(0.3秒) | 转化为弱点暴露/后摇延长0.5秒 |
| 时间加速 | 正常 | Boss攻速+10% | Boss攻速+20% | Boss攻速+30% |
| 时间裂隙 | 减速×0.3 | 减速×0.15 | 减速×0.05 | 不减速Boss本体，但减速弹幕/召唤物并保留坍缩伤害×0.5 |
| 时间回溯 | 正常 | Boss获得3秒"时间预知" | Boss获得5秒"时间预知" | 回溯时50%被时间锁定 |
| 时间回溯残影 | 1秒诱导面向 | 0.7秒诱导面向 | 0.4秒诱导面向 | 不吸引仇恨但可触发路径伤害 |

**"时间预知"效果**：Boss的攻击前摇中会显示红色预警区域（提前1秒），但同时Boss攻击频率+15%且更难被打断。

**耐受值衰减**：60秒未受时间技能影响，耐受值 -1（最低0）。每次Boss阶段切换，耐受值重置为0。

**特殊Boss——时之叛徒（第3层Boss）**：
- 时之叛徒不免疫所有时间技能，而是会在15秒反制冷却外尝试改写玩家的时间技能。
- 反制后必须暴露可利用窗口：怀表弱点、施法后摇、减速场可击破、不稳定裂隙爆发。
- 击败方式：诱导其交出反制，再在冷却期间使用时间技能获得完整收益；或利用反制动作本身制造输出窗口。

### 3.2.4.3 时间技能之间的组合效果

| 组合 | 组合名 | 效果 |
|------|--------|------|
| 时间停止→时间裂隙 | 冻结裂隙 | 在时间停止期间放置裂隙，时间停止消退后裂隙内所有效果 ×1.5，持续至裂隙结束 |

## 3.2.6 时间操控的技术实现要点

### 3.2.6.1 时间缩放系统架构

**核心概念**：为每个实体（Entity）维护独立的时间缩放系数（TimeScale），游戏主循环中根据每个实体的TimeScale调整其deltaTime。

**数据结构：**

```text
class_name TimeEntity
extends Node
{
    // 核心时间缩放系数，1.0=正常，0.0=完全停止，2.0=双倍速
    public float LocalTimeScale { get; private set; } = 1.0f;
    
    // 受时间技能影响的优先级（越高越容易被影响）
    public int TimeAffinity { get; set; } = 5; // 0=免疫, 1~10=优先级
    
    // 时间技能影响叠加列表
    private List<TimeEffect> _activeTimeEffects = new List<TimeEffect>();
    
    // 获取本帧的deltaTime
    public float ScaledDeltaTime => Time.unscaledDeltaTime * LocalTimeScale;
}

public struct TimeEffect
{
    public TimeEffectType Type;      // Stop, Slow, Accelerate, Rift
    public float Strength;           // 0.0~1.0, 影响强度
    public float RemainingDuration;  // 剩余时间(真实秒)
    public int SourceId;             // 来源实体ID（防止同一来源叠加）
}
```

**主循环集成：**

```text
// 在GameManager或TimeManager中
void Update()
{
    float rawDeltaTime = Time.unscaledDeltaTime;
    
    foreach (var entity in _timeEntities)
    {
        // 计算最终权重：多个时间效果取最强影响
        float maxSlowdown = 1.0f;
        float totalAcceleration = 0f;
        bool isStopped = false;
        
        foreach (var effect in entity._activeTimeEffects)
        {
            switch (effect.Type)
            {
                case TimeEffectType.Stop:
                    if (entity.TimeAffinity > 0)
                        isStopped = true;
                    break;
                case TimeEffectType.Slow:
                    maxSlowdown = math.Min(maxSlowdown, 1.0f - effect.Strength);
                    break;
                case TimeEffectType.Accelerate:
                    totalAcceleration += effect.Strength;
                    break;
                case TimeEffectType.Rift:
                    // 裂隙效果：对敌人=减速，对玩家=加速
                    if (entity.CompareTag("Enemy"))
                        maxSlowdown = math.Min(maxSlowdown, 1.0f - effect.Strength * 0.6f);
                    else if (entity.CompareTag("Player"))
                        totalAcceleration += 0.15f; // CD加速
                    break;
            }
        }
        
        if (isStopped)
            entity.LocalTimeScale = 0f;
        else
            entity.LocalTimeScale = math.Max(0.05f, maxSlowdown + totalAcceleration);
            // 最低0.05防止完全卡死，除非被Stop
        
        // 更新效果持续时间
        entity._activeTimeEffects.RemoveAll(e => 
        {
            e.RemainingDuration -= rawDeltaTime;
            return e.RemainingDuration <= 0;
        });
    }
}
```

**各子系统对接：**

| 子系统 | 对接方式 | 说明 |
|--------|----------|------|
| 动画系统 | animation_player.speed = LocalTimeScale | 动画播放速度随时间缩放 |
| 移动系统 | velocity *= ScaledDeltaTime | 移动距离随时间缩放 |
| 攻击系统 | 攻击前摇/后摇计时器用ScaledDeltaTime | 攻击节奏随时间缩放 |
| 粒子系统 | GPUParticles2D process_material.simulationSpeed = LocalTimeScale | 粒子随时间缩放 |
| 弹幕系统 | bullet.velocity *= ScaledDeltaTime | 弹速随时间缩放 |
| AI系统 | AI决策计时器用ScaledDeltaTime | AI思考频率随时间缩放 |
| 物理系统 | Engine.time_scale不可用（影响全局），改用自定义FixedUpdate频率 | 见下方物理处理 |
| 音频系统 | AudioSource.pitch = LocalTimeScale | 音调随时间缩放(可选) |

**物理系统特殊处理：**
- 不使用Engine.time_scale（全局影响）
- 改为在FixedUpdate中调整每个物理实体的velocity：
  ```text
  void FixedUpdate()
  {
      float scaledFixedDelta = Time.fixedDeltaTime * LocalTimeScale;
      // 对Rigidbody: 不直接修改，而是通过自定义力的方式
      rb.velocity = baseVelocity * LocalTimeScale;
      // 或者：使用rb.maxLinearVelocity限制被减速的物体
  }
  ```
- 被完全停止(Stop)的物体：设置PhysicsBody2D冻结 = true，记录原始velocity，恢复时还原
- 注意：物理碰撞检测仍需正常工作（被冻结物体仍需被攻击命中），所以碰撞体不关闭

### 3.2.6.2 回溯系统实现（状态快照策略）

**快照频率：**
- 每 10帧（约166ms）拍摄一次完整快照
- 5秒回溯 = 最多30个快照
- 7秒回溯 = 最多42个快照

**快照数据结构：**

**快照缓冲区（环形缓冲区）：**

```text
public class SnapshotBuffer
{
    private PlayerSnapshot[] _buffer;
    private int _head;      // 写入位置
    private int _count;     // 当前数量
    private int _capacity;  // 最大容量(42 for 7秒)
    
    public SnapshotBuffer(int capacity)
    {
        _capacity = capacity;
        _buffer = new PlayerSnapshot[_capacity];
        _head = 0;
        _count = 0;
    }
    
    public void Push(PlayerSnapshot snapshot)
    {
        _buffer[_head] = snapshot;
        _head = (_head + 1) % _capacity;
        if (_count < _capacity) _count++;
    }
    
    // 获取目标时间的快照（找最接近的）
    public PlayerSnapshot GetSnapshotAtTime(float targetTime)
    {
        // 从最新到最旧搜索
        int bestIndex = -1;
        float bestDiff = float.MaxValue;
        
        for (int i = 0; i < _count; i++)
        {
            int idx = (_head - 1 - i + _capacity) % _capacity;
            float diff = math.Abs(_buffer[idx].Timestamp - targetTime);
            if (diff < bestDiff)
            {
                bestDiff = diff;
                bestIndex = idx;
            }
            if (_buffer[idx].Timestamp < targetTime)
                break; // 已经过目标时间，不需要继续
        }
        
        if (bestIndex >= 0)
            return _buffer[bestIndex];
        
        return default; // 无可用快照
    }
    
    public void ClearSnapshotsAfter(float time)
    {
        // 回溯后清除"未来"快照，防止重复回溯
        for (int i = 0; i < _count; i++)
        {
            int idx = (_head - 1 - i + _capacity) % _capacity;
            if (_buffer[idx].Timestamp > time)
            {
                _buffer[idx] = default;
            }
        }
    }
}
```

**回溯执行流程：**

```text
public async流程 ExecuteRecall(float recallSeconds)
{
    // 1. 查找目标快照
    float targetTime = GameTime - recallSeconds;
    PlayerSnapshot target = _snapshotBuffer.GetSnapshotAtTime(targetTime);
    
    if (target.Equals(default(PlayerSnapshot)))
    {
        // 无可用快照，回溯失败，返还50%能量
        _chronosEnergy += actualCost * 0.5f;
        yield break;
    }
    
    // 2. 播放前摇动画(8帧)
    yield return PlayRecallWindup(8);
    
    // 3. 保存当前位置作为残影生成点
    Vector3 phantomPosition = transform.position;
    Quaternion phantomRotation = transform.rotation;
    
    // 4. 应用快照状态
    transform.position = target.Position;
    transform.rotation = target.Rotation;
    _health = math.Max(target.Health, 1f); // 保底1HP
    _chronosEnergy = math.Max(target.ChronosEnergy, 10f); // 保底10能量
    ApplyBuffs(target.Buffs);
    RemoveAllDebuffs(); // 清除当前Debuff
    // 不恢复旧Debuff
    
    // 5. 清除"未来"快照
    _snapshotBuffer.ClearSnapshotsAfter(targetTime);
    
    // 6. 生成时之残影
    SpawnChronoPhantom(phantomPosition, phantomRotation);
    
    // 7. 无敌窗口(30帧)
    SetInvincible(30);
    
    // 8. 播放回溯特效
    PlayRecallEffect();
}
```

```text
class_name ChronoPhantom
extends Node2D

    public float ExplosionDamage;     // = 攻击力 × 60%

    private List<EnemyAI> _attractedEnemies = new List<EnemyAI>();

        Collider[] hits = PhysicsQuery.OverlapSphere(transform.position, 8f, collision_mask.Enemy);
        foreach (var hit in hits)
        {
            EnemyAI enemy = hit.GetComponent<EnemyAI>();
            if (enemy != null && !enemy.IsBoss)
            {
                float attractDuration = enemy.IsElite ? 1f : 2f;
                enemy.OverrideTarget(this.gameObject, attractDuration);
            }
        }

        }

            queue_free();
        }
    }
```

### 3.2.6.3 性能优化要点

**1. 快照内存优化：**
- 单个PlayerSnapshot估算大小：~200字节（含Buff列表）
- 42个快照 ≈ 8.4KB，可忽略
- **关键**：Buff/Debuff列表使用预分配池，避免GC
  ```text
  private List<BuffInstance> _buffPool = new List<BuffInstance>(16); // 预分配
  ```
- 快照使用值类型(struct)避免堆分配
- 仅快照玩家数据，不快照敌人/环境（敌人不回溯）

**2. 时间缩放性能优化：**
- 维护一个全局的`TimeEffectRegistry`，使用空间分区（Spatial Grid）快速查询区域内的受影响实体
- 裂隙范围查询：
  ```text
  // 使用网格分区而非PhysicsQuery.OverlapSphere
  SpatialGrid.QueryCircle(riftPosition, riftRadius, entity => 
  {
      entity.AddTimeEffect(new TimeEffect(TimeEffectType.Rift, 0.6f, riftDuration, riftId));
  });
  ```
- 空间网格分辨率：2m×2m格子，典型场景(60m×60m) = 30×30 = 900格

**3. 时间停止的全局处理：**
- 时间停止时，不需要逐个设置所有敌人的TimeScale
- 改为在`TimeManager`中维护一个全局标志`IsGlobalTimeStopped`
- 各实体在计算LocalTimeScale时自动检查此标志：
  ```text
  if (TimeManager.IsGlobalTimeStopped && this.TimeAffinity > 0)
      LocalTimeScale = 0f;
  ```
- 但部分免疫实体需要特殊处理：TimeAffinity = 0 的实体不受影响

**4. 回溯视觉轨迹优化：**
- 回溯路径线使用LineRenderer，顶点数限制为30
- 玩家每10帧记录位置到路径点列表
- 回溯时一次性设置LineRenderer位置
- 路径线材质使用简单Unlit/Transparent，避免复杂shader

**5. 裂隙区域渲染优化：**
- 裂隙地面效果使用Projector组件（而非实时生成网格）
- Projector材质使用简单混合shader，绘制圆形渐变纹理
- 裂隙边缘使用单个环形Mesh + 扭曲Shader
- 最多3个裂隙同屏 = 3个Projector，性能可控

**6. 时间加速的MotionBlur优化：**
- 不使用全屏后处理MotionBlur（太昂贵）
- 改为：仅在玩家模型上使用径向模糊Shader
- 或：使用简单的拖尾效果（TrailRenderer），长度随速度缩放
- 拖尾粒子数上限：50个/秒

**7. 粒子系统的时间缩放优化：**
- 批量设置粒子系统的simulationSpeed：
  ```text
  // 缓存所有需要受时间影响的粒子系统
  private List<GPUParticles2D> _timeAffectedParticles;
  
  void UpdateParticleTimeScales()
  {
      float scale = _cachedLocalTimeScale;
      foreach (var ps in _timeAffectedParticles)
      {
          if (ps.main.simulationSpeed != scale)
          {
              var main = ps.main;
              main.simulationSpeed = scale;
          }
      }
  }
  ```
- 注意：`GPUParticles2D process_material.simulationSpeed`赋值会创建GC分配，应缓存只在值变化时更新
- 更优方案：使用`GPUParticles2D.Simulate()`手动驱动，但需评估性能

**8. 帧率无关设计：**
- 所有时序相关的数值使用"真实秒"而非"帧"
- 文档中的帧数仅作为60FPS下的参考
- 实际计算：
  ```text
  float durationSeconds = frameCount / 60f; // 帧转秒
  // 实际更新用
  timer += Time.unscaledDeltaTime * LocalTimeScale;
  ```

**9. 网络同步（如果未来有多人模式）：**
- 时间技能效果由主机(Host)计算并广播
- 快照数据仅主机保存
- 时间缩放系数同步频率：每秒2次（非实时，容许0.5秒偏差）
- 回溯操作：客户端发送回溯请求，主机验证后执行

**10. 调试工具：**
- Inspector中显示每个实体的`LocalTimeScale`实时值
- 可视化裂隙范围（Gizmos画圆）
- 快照缓冲区可视化（时间轴上标记快照点）
- 时间效果列表可视化（当前实体受哪些效果影响）
- 控制台命令：`timescale [value]` 全局缩放，`chronos [value]` 设置能量
