## 8.4.1 装备强化系统总览

### 8.4.1.1 设计哲学

装备强化系统遵循**低数值、高手感、强解锁**原则：局外永久强化提供熟悉感、武器偏好表达和少量容错，局内临时强化提供Build变化与爆发成长。两者在体验上互补，但不能形成叠加通胀。

**核心设计原则：**

1. **永久强化天花板受控**：枢纽永久强化最高+5级，总ATK加成+25%，并计入局外总战斗收益软上限，确保局内Build仍是通关核心驱动力
2. **风险-回报阶梯降噪**：强化等级越高，成本和失败压力越高，但收益不能指数化；高风险内容优先放在局内事件或虚空淬炼扩展池
3. **武器差异化**：每种武器拥有独特的强化收益曲线和附魔适配，不存在"所有武器最优解相同"的情况
4. **失败不毁灭体验**：最高失败惩罚为降级（非碎裂），虚空淬炼的碎裂风险可通过Meta节点完全规避
5. **熟练度与强化分工**：武器熟练度前期提供少量数值，后期主要提供手感、配方、训练挑战和流派入口，鼓励深度使用而非反复切换

## 8.4.2 枢纽永久强化——基础强化

### 8.4.2.1 强化概述

**位置**：枢纽锻造区——装备强化台 (x:200, y:1000)  
**NPC**：熔炉匠师 (x:350, y:1100)  
**前置条件**：Meta节点F-01解锁（消耗5时之碎片）  
**可强化对象**：5种武器（剑/弓/枪/杖/拳套），每种武器独立强化等级  
**货币消耗**：时之碎片（永久货币）

### 8.4.2.2 五级强化详细表

| 强化等级 | 成功率 | 时之碎片消耗 | 效果 | 失败惩罚 | 失败碎片返还 | 前置条件 |
|:---:|:---:|:---:|------|------|:---:|------|
| +1 | 100% | 5 | ATK+5% | 无 | — | Meta F-01 |
| +2 | 90% | 10 | ATK+10% | 无（碎片不返还） | 0 | Meta F-01 |
| +3 | 75% | 20 | ATK+15% | 无（Meta F-05前：等级-1；F-05后：不降级） | 5 | Meta F-01 |
| +4 | 55% | 35 | ATK+22% | 等级-1（Meta F-05后：不降级，碎片仍消耗） | 10 | Meta F-05 |
| +5 | 35% | 50 | ATK+25% | 等级-1（Meta F-05后：不降级，碎片仍消耗） | 15 | Meta F-05 |

**失败机制详解：**

- **Meta F-05之前**（原始规则）：+3强化失败时等级降回+2，+4失败降回+3，+5失败降回+4。降级后再次强化需重新消耗碎片并重新判定成功率
- **Meta F-05之后**（保护规则）：强化失败不再降级，当前等级保持不变，但消耗的时之碎片不返还（仅返还部分，见上表"失败碎片返还"列）。此保护仅对+3及以上等级生效
- **+1和+2永不降级**：无论是否解锁Meta F-05，+1和+2强化失败都不会降级
- **连续失败保护**：同一装备连续失败2次后，第3次尝试成功率+15%（叠加上限后不超过100%）。此buff在成功后清零

### 8.4.2.3 各武器强化收益差异

不同武器在相同强化等级下的收益存在差异，体现武器设计哲学：

| 武器 | +1效果 | +2效果 | +3效果 | +4效果 | +5效果 | 额外收益说明 |
|------|--------|--------|--------|--------|--------|-------------|
| 剑 | ATK+5% | ATK+10% | ATK+15% | ATK+20% | ATK+25% | 均衡收益，每级额外+1%DEF |
| 弓 | ATK+5% | ATK+10% | ATK+15% | ATK+20% | ATK+25% | 每级额外+1%暴击率 |
| 枪 | ATK+5% | ATK+10% | ATK+15% | ATK+20% | ATK+25% | +3起额外+2%攻击距离 |
| 杖 | ATK+5% | ATK+10% | ATK+15% | ATK+20% | ATK+25% | 每级额外+1时之能量上限 |
| 拳套 | ATK+5% | ATK+10% | ATK+15% | ATK+20% | ATK+25% | +3起额外+1%攻速 |

> 设计意图：主效果(ATK加成)统一，副效果差异化，确保不存在"绝对最优武器选择"，而是与角色Build产生二次联动

## 8.4.4 虚空淬炼

### 8.4.4.1 虚空淬炼概述

**位置**：枢纽锻造区——虚空淬炼炉 (x:150, y:1200)  
**NPC**：熔炉匠师 (x:350, y:1100)  
**前置条件**：Meta节点F-04解锁  
**定位**：高风险高回报的装备特殊强化，为已+3及以上装备赋予"虚空"前缀和额外属性  
**每次Run间限次**：每件武器最多淬炼1次（不可反复淬炼刷新结果）

### 8.4.4.2 虚空淬炼规则

**前置要求**：装备强化等级≥+3  
**消耗**：30时之碎片（或3存在印记进行保底淬炼）  
**结果概率表**：

| 结果 | 概率(原始) | 概率(Meta F-05后) | 效果 |
|------|:---:|:---:|------|
| 虚空觉醒（成功） | 70% | 75% | 获得"虚空"前缀，攻击15%概率触发ATK×0.5的虚无伤害（范围2格）；虚无伤害无视20%防御 |
| 无变化 | 25% | 25% | 消耗碎片但不获得任何效果，装备保持原状 |
| 装备碎裂（失败） | 5% | 0% | 装备永久消失，强化等级和附魔全部丢失 |

**保底淬炼（消耗3存在印记）**：

- 100%触发虚空觉醒，0%碎裂，0%无变化
- 效果与普通虚空觉醒相同
- 每件装备仅可使用1次保底淬炼
- 设计意图：存在印记是稀缺资源，保底淬炼是"确定感"的兑换，适合高投入装备

### 8.4.4.3 虚空淬炼进阶——虚空共鸣

当同一角色的两件以上+3装备均完成虚空觉醒时，触发**虚空共鸣**效果：

| 共鸣数量 | 共鸣效果 | 说明 |
|:---:|------|------|
| 2件 | 虚空觉醒触发概率+5%（15%→20%） | 轻微增益 |
| 3件 | 虚空伤害系数+0.2（0.5→0.7） | 显著伤害提升 |
| 4件 | 虚无伤害无视防御+10%（20%→30%） | 针对高防Boss |
| 5件 | 虚空觉醒触发时额外回复5HP | 生存向终极共鸣 |

> 设计意图：鼓励"全面虚空化"的极端Build路线，但5件全虚空是巨大投资（5件×30碎片+可能的失败成本），只在后期有可行性

### 8.4.4.4 虚空淬炼叙事包装

熔炉匠师台词：

- 淬炼前："将武器浸入虚空中……它可能获得超越位面的力量，也可能被虚无吞噬。你确定？"
- 淬炼成功："它回来了……但不一样了。虚空在它身上留下了痕迹。"
- 无变化："虚空拒绝了它。或许是它的意志太强——又或者，太弱。"
- 碎裂（无F-05）："……我警告过你了。这就是虚空的代价。我们失去的不只是一把武器。"
- 保底淬炼："用存在印记锚定……这次，虚空无法拒绝。"

## 8.4.5 局内临时强化

### 8.4.5.1 局内强化概述

局内临时强化是Run中获取的短期装备增益，**仅当次Run有效**，死亡或通关后完全清零。与枢纽永久强化形成"基础值+爆发值"的双层结构。

**获取途径**：地牢中的特殊房间/事件/商店  
**叠加规则**：与枢纽永久强化加算（同属性加算），与魂之祭坛乘算（不同乘区）  
**每局上限**：5种临时强化各最多叠加至对应最大等级

### 8.4.5.3 局内临时强化与永久强化的叠加计算

```
最终ATK = (基础ATK × (1 + 永久强化加成% + 祭司祝福加成% + 虚无侵蚀加成%)) 
         × (1 + 魂之祭坛ATK加成%) 
         × (1 + 道具/流派祝福机制收益折算%)

计算示例（行者+剑+5，3级祭司祝福，2级虚无侵蚀，3级魂之祭坛ATK）：
= (30 × (1 + 0.25 + 0.24 + 0.30)) × (1 + 0.12) × (1 + 各种机制收益%)
= (30 × 1.79) × 1.12
= 53.7 × 1.12
= 60.1 (不含道具/流派祝福机制收益，基础2.00倍)
```

> 设计验证：永久强化贡献25%，局内临时强化贡献54%，魂之祭坛贡献12%。魂之祭坛只补短板，最终强度仍应主要来自道具触发器、时间技能窗口、武器节奏和风险件。

## 8.4.6 武器熟练度系统

### 8.4.6.1 熟练度概述

武器熟练度是与玩家使用特定武器深度绑定的独立成长系统。与装备强化不同，熟练度不消耗任何货币，纯粹通过**使用武器的时间与命中次数**积累。

**核心设计意图**：
1. 奖励深度使用而非频繁切换——"专精一器，胜于百器平庸"
2. 为玩家提供"不知不觉变强"的被动成长感——即使强化失败，熟练度也在稳步增长
3. 解锁武器专属强化选项——高熟练度解锁独特附魔/强化配方

### 8.4.6.2 熟练度等级与数值

每种武器独立计算熟练度，等级从0到10。

| Lv.1 | 100 | 该武器ATK+1% | 解锁该武器基础附魔配方 |
| Lv.2 | 300 | 该武器ATK+2% | 无 |
| Lv.3 | 600 | 该武器ATK+3%，攻速+2% | 解锁该武器专属附魔选项1 |
| Lv.4 | 1,000 | 该武器ATK+4%，攻速+3% | 无 |
| Lv.5 | 1,600 | 该武器ATK+5%，攻速+4%，暴击率+2% | 解锁该武器专属附魔选项2 |
| Lv.6 | 2,500 | 该武器ATK+6%，攻速+5%，暴击率+3% | 无 |

## 8.4.7 强化系统数值平衡验证

### 8.4.7.1 满投入场景数值验证

**场景**：行者，剑+5（永久），Lv.10剑熟练度，2附魔(EN-06+EN-08)，虚空觉醒，3级祭司祝福，2级虚无侵蚀，3级魂之祭坛ATK。该场景是极限压力测试，不代表首发常规局。

| 加成来源 | ATK加成 | 乘区 |
|---------|:---:|------|
| 基础ATK | 30 | 基础值 |
| 永久强化+5 | +25% | 加算区A |
| 熟练度Lv.10 | +10% | 加算区A |
| 祭司祝福3级 | +24% | 加算区A |
| 虚无侵蚀2级 | +30% | 加算区A |
| **加算区A合计** | **+94%** | **30 × 1.94 = 58.2** |
| 魂之祭坛ATK 3级 | +12% | 乘算区B，v1.1补短板上限 |
| **乘算区B后** | — | **58.2 × 1.12 = 65.2** |
| 道具/流派祝福机制收益折算(假设中值) | +50% | 乘算区C，主要来自行为改变而非纯ATK |
| **最终ATK** | — | **65.2 × 1.50 = 97.8** |

**结论**：v1.1中魂之祭坛不再作为核心DPS乘区，满投入场景应重新校验为"局外数值不超过30%，局内机制/风险/操作贡献70%+"。永久养成是熟悉感和选项解锁，不是胜利来源。

| 对比维度 | 新手(0局) | 中阶(15局) | 老手(50局) | 差距倍率(新/老) |

## 8.4.8 新手教学流程设计

### 8.4.8.1 教学设计哲学

1. **做中学，非读中学**：所有教学点必须通过实际操作完成，不使用纯文本教程页
2. **逐步解锁，信息分层**：新手3局内只教授核心机制，高级机制通过游戏进程自然解锁
3. **失败即教学**：新手死亡不惩罚，而是触发"学习时刻"提示
4. **可跳过但不可遗漏**：教学可跳过，但关键操作必须至少执行1次才能推进
5. **三局保护**：前3局给予额外保护和引导，第4局起进入正常难度曲线

### 8.4.8.2 十个教学点逐步设计

#### 教学点1：移动与闪避（第1局，第1个房间）

| 属性 | 详情 |
|------|------|
| **触发时机** | 首次进入地牢第1层第1个房间 |

## 8.4.9 教学提示系统

### 8.4.9.1 提示系统概述

教学提示系统是贯穿整个游戏流程的上下文敏感型提示框架，不仅服务于新手教学，更在玩家遇到新机制时提供即时帮助。

**设计原则：**
1. **不打断游戏节奏**：提示以非模态UI呈现，不暂停游戏，不强制等待
2. **上下文敏感**：只在玩家首次遇到特定情境时触发，同一提示不重复出现
3. **可配置**：玩家可在设置中调整提示频率（详细/标准/简洁/关闭）
4. **渐退机制**：同一类型提示触发2~3次后自动停止

### 8.4.10.3 保护退出的平滑过渡

保护不是"一刀切"消失，而是**逐项平滑退出**：

```
保护强度曲线（以敌人ATK修正为例）：

第1局: ████████████████████░░░░░  75%
第2局: █████████████████░░░░░░░░  85%
第3局: ██████████████████░░░░░░░  95%
第4局: █████████████████████████  100% (正常)

其他保护项同样遵循渐进退出，但退出速度不同：
- 药水携带上限：第4局直接恢复（硬切换）
```

### 8.4.11.2 强化成功率技术实现

```
function calculateEnhanceSuccess(
  currentLevel: int,
  hasMetaF05: bool,
  consecutiveFailures: int
): float {
  // 基础成功率表
  const baseRates = [1.0, 0.9, 0.75, 0.55, 0.35];
  
  if (currentLevel < 0 || currentLevel > 4) return 0;
  
  let rate = baseRates[currentLevel];
  
  // 连续失败保护：每2次连续失败+15%
  if (consecutiveFailures >= 2) {
    rate = min(1.0, rate + 0.15);
  }
  
  return rate;
}

function processEnhanceFailure(
  currentLevel: int,
  hasMetaF05: bool
): int {
  // +1和+2永不降级
  if (currentLevel <= 2) return currentLevel;
  
  // Meta F-05后不降级
  if (hasMetaF05) return currentLevel;
  
  // 原始规则：降1级
  return currentLevel - 1;
}

function getShardRefundOnFailure(currentLevel: int): int {
  // 失败时碎片返还
  const refunds = [0, 0, 5, 10, 15]; // +1~+5失败
  return refunds[currentLevel];
}
```

```
function getNewbieProtectionModifier(
```
