## 1. 核心概念 (Core Concept)

### 1.1 一句话描述
> 穿越位面的行者，在崩塌的世界碎片中战斗，收集「时之碎片」，对抗吞噬一切的「虚无」。

### 1.2 核心循环 (Core Loop)
```
选择角色/武器 → 进入5层地牢 → 用时间技能和武器节奏解决房间 → 获取流派启动件/补强件/风险件 → 挑战Boss → 解锁新选项 → 开始新一轮
```

### 1.3 独特卖点 (USP)
1. **时间操控机制**: 时间停止/回溯/加速/裂隙四大核心技能，每种武器与时间有独特联动 → [详见3.2](3.2_时间操控系统设计.md)
2. **五武器系统**: 剑/弓/枪/杖/拳套，每种有完整招式树和独特机制 → [详见3.1](combat-system-design.md)
3. **可识别Build流派**: 首发围绕8个核心流派设计，优先保证每个选择改变打法，而不是堆叠系统数量 → [详见0](0_深度收敛与系统职责设计.md)
4. **位面穿梭**: 程序化生成的5层地牢，每层6-9个房间，单局目标30-45分钟 → [详见3.5](3.5_地牢生成与关卡设计.md)
5. **5角色差异化**: 不是数值调整，而是机制差异，每个角色改变游戏方式 → [详见4](4_角色与数值体系设计.md)

### 1.4 v1.1 深度收敛原则

本项目的设计优先级从"内容数量"调整为"可感知策略深度"。所有系统必须服务四个深度支柱：

| 深度支柱 | 设计目标 |
|----------|----------|
| 时间掌控深度 | 时间停止/回溯/加速/裂隙分别改变输出窗口、预设收益、节奏压榨和地形控制 |
| 武器节奏深度 | 五武器保持各自操作问题，后期Build不能把它们都变成同一种高频触发器 |
| Build草拟深度 | 首发只锁定8个核心流派，玩家应在第2层结束前看出本局方向 |
| 风险经济深度 | 诅咒和高风险事件改变打法约束，而不是简单倍率交易 |

**系统职责边界**：

| 系统 | 首要职责 |
|------|----------|
| 道具 | 触发器、弹幕、残影、位移、特殊规则、流派启动件 |
| 祝福 | 强化时间技能或武器流派 |
| 诅咒 | 高风险高回报，改变打法约束 |
| 天赋 | 本局路线选择，不做细碎属性点 |
| 魂祭坛 | 小幅补短板，不成为Build核心 |
| 局外Meta/强化 | 解锁选项、便利性、流派入口，直接战斗数值保持低占比 |

## 2. 世界观与叙事 (World & Narrative)

→ **完整设计详见 [2_世界观与叙事进度设计.md](2_世界观与叙事进度设计.md)**

### 2.1 核心世界观
世界原本是统一的「原界」，在「大崩塌」中碎裂成无数「位面碎片」。碎片在「虚无之海」中漂流，随时可能被虚无吞噬。玩家扮演「Plane Walker」（位面行者）——能在位面间穿梭的特殊存在。

### 2.2 五层地牢的世界观关联
| 层 | 名称 | 世界观意义 |
|----|------|-----------|
| 1 | 遗迹废墟 | 原界的残骸，崩塌前的文明遗迹 |
| 2 | 虚空森林 | 虚空滋生的生命体，扭曲的生态 |
| 3 | 时间裂隙 | 大崩塌的时间断层，过去和未来交错 |
| 4 | 位面熔炉 | 位面碎片被重塑的场所 |
| 5 | 虚无王座 | 虚无的核心领地 |

### 2.3 四大势力
| 势力 | 描述 | 与玩家关系 |
|------|------|-----------|
| 时之议会 | 位面行者的组织，维护位面平衡（有内部派系分歧） | 盟友/任务发布 |
| 虚无教团 | 崇拜虚无，企图加速世界崩塌（有自己的哲学逻辑） | 敌对势力 |
| 位面商人 | 在各位面间贸易的中立群体 | 交易/获取道具 |
| 碎片原住民 | 生活在位面碎片中的各种生物 | 中立/可敌可友 |

### 2.4 叙事方式
- **碎片化叙事**: 道具描述、环境细节、NPC对话拼凑世界
- **4+1结局**: 根据选择和收集进度解锁，含隐藏真结局
- **3条隐藏剧情线**: 特定条件触发的深层剧情

## 3. 游戏系统 (Gameplay Systems)

### 3.1 战斗系统
→ **完整设计详见 [combat-system-design.md](combat-system-design.md)**

**核心框架**:
- 60fps基准，Fixed Timestep
- 动作优先级：闪避(5) > 格挡(4) > 特殊技(3) > 普攻链(2) > 移动(1)
- 动作三阶段：前摇 → 活动帧 → 后摇，后摇可取消
- 8帧输入缓冲窗口，12帧连招输入窗口
- 伤害类型：物理 / 时间 / 虚无 / 元素

**五武器概览**:

| 武器 | 定位 | 核心机制 | 时间联动 |
|------|------|---------|---------|
| 剑 | 平衡型近战 | 4段连击 + 完美格挡(0.15s窗口) | 格挡成功触发时间减速 |
| 弓 | 远程输出 | 3段蓄力 + 穿透 | 满蓄力箭创造时间裂隙 |
| 枪 | 中距离爆发 | 弹药限制 + 完美换弹(8帧窗口) | 完美换弹触发时间装填 |
| 杖 | 法术/控场 | 3种法术 + 组合系统 | 法术组合触发位面崩塌 |
| 拳套 | 近战连击/机动 | 5段连击 + 连击增益阶梯 | 连击越高时间越慢 |

### 3.2 时间操控系统
→ **完整设计详见 [3.2_时间操控系统设计.md](3.2_时间操控系统设计.md)**

**时之能量**: 上限100，自然恢复2/秒，击杀恢复5-15，完美操作额外恢复

| 技能 | 效果 | 消耗 | 冷却 |
|------|------|------|------|
| 时间停止 | 冻结敌人3秒(Boss减半) | 35 | 12秒 |
| 时间回溯 | 回溯5秒前的位置和状态 | 45 | 15秒 |
| 时间加速 | 自身1.6x移速+1.4x攻速，8秒 | 25+8/秒 | 8秒 |
| 时间裂隙 | 4m半径扭曲区域6秒，敌人减速 | 30 | 10秒 |

### 3.3 道具系统
→ **完整设计详见 [3.3_道具系统设计.md](3.3_道具系统设计.md)**

**首发道具规模**: 40-60个高辨识度道具（被动40-45，主动8-10）。200+道具仅作为EA/正式版扩展目标，不作为首发范围。
**槽位**: 20被动 + 2主动
**联动系统**: 优先服务8个核心流派，联动以机制替换/新效果为主，纯数值叠加为低优先级
**5种特殊商人**: 时间旅者 / 铁匠 / 暗市商人 / 收藏家 / 赌徒

### 3.4 祝福与诅咒系统
→ **完整设计详见 [3.4_祝福与诅咒系统设计.md](3.4_祝福与诅咒系统设计.md)**

**首发祝福**: 25-30个，优先强化时间技能或武器流派；43个完整设计作为储备池
**首发诅咒**: 15-18个，只保留能改变打法约束的风险选择；30个完整设计作为储备池
**联动矩阵**: 首发只启用服务8个核心流派的关键交互，其他联动延后到扩展池
**诅咒组合**: 首发最多2-3组清晰可预期的组合，不用隐藏组合堆复杂度
**4种净化机制**: 祭坛净化 / 商人驱除 / 事件交换 / Boss击杀

> v1.1收敛：首发祝福以时间技能/武器流派专精为主；诅咒只保留能改变打法约束的高风险选择，削弱纯倍率交易。

### 3.5 地牢生成
→ **完整设计详见 [3.5_地牢生成与关卡设计.md](3.5_地牢生成与关卡设计.md)**

**算法**: 图论拓扑 + BSP分区 + 走廊连接（三层混合）
**首发结构**: 5层，每层6-9个房间，单局30-45分钟
**房间模板**: 30种（10战斗 + 5精英 + 3宝藏 + 2商店 + 3事件 + 5Boss + 2休息）
**事件房**: 15种常规事件 + 3种特殊事件
**经济**: 金币获取/消耗/通胀控制系统
**难度曲线**: 三层缩放（层数 + 房间序号 + 时间因子）

### 3.6 敌人系统
→ **完整设计详见 [3.6_敌人系统设计.md](3.6_敌人系统设计.md)**

**敌人总数**: 27种（L1×4 + L2×6 + L3×6 + L4×6 + 通用5）
**AI**: 6态FSM（巡逻→警戒→追击→攻击→撤退→死亡）
**精英系统**: 10种词缀，HP×3 / ATK×1.5 / 新增1技能
**难度缩放公式**: finalHP = baseHP × (1+(L-1)×0.35) × (1+(R-1)×0.05) × (1+max(0,T-5)×0.01)

### 3.7 Boss设计
→ **完整设计详见 [3.7_Boss设计.md](3.7_Boss设计.md)**

| Boss | 层 | 核心机制 | 阶段数 |
|------|-----|---------|--------|
| 遗迹守护者 | 1 | 大范围攻击 + 弱点暴露 | 2 + 狂暴 |
| 虚空树母 | 2 | 场地交互(根须/孢子) | 2 + 狂暴 |
| 时之叛徒 | 3 | 时间技能博弈 + 反制冷却窗口 | 2 + 狂暴 |
| 熔炉领主 | 4 | 多形态变换 | 3 + 狂暴 |
| 虚无之王 | 5 | 人→虚无→融合三形态 | 3(无狂暴，第3形态即终极) |

**Boss时间交互原则**: Boss不大量免疫时间技能。每个Boss至少提供4种时间技能正向用法：延长后摇、暴露弱点、减速弹幕、诱导路径、触发场地机关等。

## 4. 角色与数值 (Characters & Numbers)

→ **完整设计详见 [4_角色与数值体系设计.md](4_角色与数值体系设计.md)**

### 4.1 五角色概览

| 角色 | 核心机制 | 推荐武器 | 解锁条件 |
|------|---------|---------|---------|
| 行者 | 旅途印记(换房增伤+回复)、时间回溯主动 | 全能 | 默认可用 |
| 时之守卫 | 完美格挡→时间减速+充能、4秒无敌堡垒 | 剑/杖 | 完成第3层 |
| 虚空行者 | HP越低伤害越高、HP<30%吸血、5秒临界 | 拳套/枪 | 累计死亡50次 |
| 原界骑士 | 双武器切换、位面共振蓄力6层=72%增伤 | 任意双武器 | 无伤击败最终Boss |
| 时间领主 | 所有攻击附1.5x时间伤害、时间支配主动 | 杖/弓 | 收集所有神话道具 |

### 4.2 核心数值
- **伤害公式**: DMG = ATK × SkillMult × (1 + BuffSum) × TypeAdv × CritMod - FDEF/(FDEF+K)
- **防御减伤**: FDEF/(FDEF+K)，K=200时100防御≈33%减伤
- **暴击**: CRIT_RATE基础5%，CRIT_DMG基础150%
- **难度档**: 普通(1.0x) / 困难(1.5x HP, 1.3x ATK) / 噩梦(2.0x HP, 1.6x ATK)

## 8. 附录 (Appendix)

### 8.1 参考游戏
- **Hades**: 战斗节奏、叙事方式、角色差异、UI品质
- **Dead Cells**: 武器多样性、地图设计、视觉风格、数值平衡
- **Risk of Rain 2**: 道具组合、Build深度
- **The Binding of Isaac**: 道具数量、诅咒系统、联动关系
- **Returnal**: 时间操控概念、Boss演出

### 8.2 术语表
- **Roguelike**: 随机地牢、永久死亡
- **Roguelite**: 带永久解锁进度的Roguelike变体
- **Build**: 道具+技能+祝福+诅咒的组合配置
- **Meta**: 跨局永久进度
- **Run**: 一局完整游戏流程
- **Proc**: 触发效果 (Programmed Random Occurrence)
- **FSM**: 有限状态机 (Finite State Machine)
