# 3.3 道具系统深度设计

> **文档版本**：v1.1  
> **最后更新**：2026-05-25  
> **适用游戏**：《Plane Walker: Chronicles of Collapse》  
> **设计目标**：首发40-60个高辨识度道具，服务8个核心流派，时间操控核心

> v1.1收敛：200+道具是EA/正式版扩展目标，不作为首发范围。首发优先保证每个道具改变玩家行为，减少纯ATK/HP/暴击等基础数值道具。

---

## 3.3.1 道具设计方法论

### 3.3.1.1 道具设计原则

**原则一：每个道具必须改变玩家做决策的方式**

有趣的道具不是简单的"攻击力+10%"——那是属性点。有趣的道具让玩家在拿起它的那一刻就重新思考自己的玩法。例如：
- "每次闪避后下一次攻击暴击" → 玩家开始故意闪避
- "击杀敌人回复1%最大生命值，但生命回复效果减半" → 创造选择困境
- "时间回溯的距离越远，造成的伤害越高" → 玩家开始蓄力时间回溯

**原则二：道具必须可叠加才有Roguelike的快感**

参考Risk of Rain 2，道具的堆叠感是核心体验。设计时必须考虑：
- 线性叠加：每层+固定值（如+10%暴击率/层）
- 递减叠加：第N层效果为 base × (1 - 0.3^(N-1))（如闪避率）
- 阈值叠加：达到特定层数触发质变（如3层触发额外效果）
- 所有可堆叠道具必须定义堆叠公式和理论上限

> v1.1约束：可堆叠不等于无限数值膨胀。普通堆叠道具允许提供手感或触发频率提升，但不应成为主要DPS来源；高稀有度道具优先做机制变化。

**原则三：联动大于单体**

单个道具只是有趣，两个道具联动才叫深度。每个道具设计时必须回答：
- 它和什么道具联动会产生质变？
- 它和什么道具联动会产生搞笑/惊喜效果？
- 它和什么道具不应该同时存在？

**原则四：时间机制是本游戏的灵魂**

所有道具设计必须从"时间"这个核心出发考虑：
- 道具本身是否与时间机制交互？
- 道具在时间回溯/冻结/加速状态下的行为是什么？
- 道具能否增强或弱化时间操控能力？

**原则五：可编程，无歧义**

每个道具效果的描述必须能直接翻译为代码逻辑，不允许出现"大幅增强""显著提升"等模糊词汇。

**原则六：标注流派职责**

每个首发道具必须标注服务对象：

- 8个核心流派之一：冻结爆发 / 回溯残影 / 裂隙陷阱 / 加速连击 / 低血虚无 / 完美格挡 / 弹幕穿透 / 分身召唤
- 或明确标记为"通用补短板"

未能服务上述目标的道具进入扩展池，不进入首发池。

### 3.3.1.2 道具命名规范

| 规则 | 说明 | 示例 |
|------|------|------|
| 中文主名 | 2-4字，有辨识度 | 破晓之眼、裂隙碎片 |
| 英文ID | UPPER_SNAKE_CASE，前缀表示分类 | `ATK_DAWN_EYE`, `TIM_RIFT_SHARD` |
| 前缀分类 | ATK=攻击, DEF=防御, UTI=功能, SPC=特殊, WEP=武器专属, TIM=时间 | `DEF_CHRONO_SHIELD` |
| 稀有度后缀 | 仅在ID中通过数据字段标记，不出现在名称中 | 数据字段 `rarity: "legendary"` |
| 堆叠型后缀 | 可堆叠道具ID末尾加`_STK` | `ATK_RAZOR_EDGE_STK` |
| 主动道具前缀 | ACT_ | `ACT_TIME_FREEZE` |

### 3.3.1.3 道具描述规范

每个道具必须包含两段文本，严格分离：

```
flavor_text: "在第三次纪元崩塌时，有一名学者试图用这枚透镜看清时间的尽头——他成功了。"
mechanic_text: "时间回溯时，在回溯路径上留下持续2秒的残影，残影对接触的敌人造成攻击力×0.5的时间伤害。"
```

**flavor_text 规范**：
- 长度15-50字
- 世界观相关，暗示道具来历
- 不出现任何数值
- 语气：神秘、碎片化、有历史感

**mechanic_text 规范**：
- 精确描述触发条件和效果
- 所有数值用具体数字
- 标明伤害类型（物理/时间/元素）
- 标明触发时机（命中时/击杀时/受击时/使用技能时/时间操控时）

### 3.3.1.4 道具测试清单

新道具上线前必须通过以下5项测试：

**测试1：独立性测试**
> 道具单独存在时是否有意义？是否过于依赖其他道具才能生效？
> 通过标准：单独使用时效果清晰可感知，不依赖任何特定搭配。

**测试2：堆叠测试**
> 可堆叠道具叠到1/3/5/10层时，效果是否仍然合理？
> 通过标准：10层时不会导致帧率下降、数值溢出或逻辑死循环。

**测试3：时间交互测试**
> 道具在时间回溯/冻结/加速下的行为是否明确定义？
> 通过标准：5种武器各自使用该道具时，时间操控下无异常行为。

**测试4：联动冲突测试**
> 道具与所有已有道具组合是否产生未定义行为？
> 通过标准：与反联动列表中的道具同时获取时有明确的排斥/降级规则。

**测试5：趣味性测试**
> 这个道具让玩家改变了玩法吗？还是只是"数值+X"？
> 通过标准：至少有1个玩法改变维度（决策方式、移动模式、攻击节奏、时间操控策略）。

## 3.3.2 道具分类体系

### 3.3.2.1 按稀有度分类

| 稀有度 | 颜色代码 | 掉落权重 | 设计目标 | 首发数量 | 扩展目标 | 堆叠上限 |
|--------|----------|----------|----------|----------|----------|----------|
| 普通(Common) | #FFFFFF 白 | 60% | 改变单一维度，少量堆叠 | 18-22 | 80 | 5-20 |
| 稀有(Uncommon) | #1EFF00 绿 | 30% | 改变玩法节奏，有条件触发 | 14-18 | 60 | 3-8 |
| 传说(Legendary) | #0070DD 蓝 | 9% | 改变核心机制，创造新build | 6-8 | 40 | 1-2 |
| 神话(Mythic) | #A335EE 紫 | 1% | 定义整个run，终极联动 | 2-4 | 20 | 1 |

**设计目标详解**：
- **普通级**：每局游戏的核心数量支撑，通过堆叠产生"越打越强"的快感。单层效果弱但叠加后质变。
- **稀有级**：给玩家"这个build有方向了"的感觉，通常附带条件触发。
- **传说级**：拿到一个就改变打法，build的核心锚点，不可大量堆叠。
- **神话级**：整个run围绕它运转，是玩家讨论"我拿到了XX然后怎样怎样"的话题种子。

### 3.3.2.2 按功能分类

| 分类 | 代码 | 数量占比 | 说明 |
|------|------|----------|------|
| 攻击型 | ATK | 20% | 额外弹幕、攻击触发器、弱点规则；减少纯增伤/暴击 |
| 防御型 | DEF | 15% | 闪避触发、护盾规则、反击窗口；减少纯减伤/生命回复 |
| 功能型 | UTI | 15% | 移速、拾取范围、经济、地图揭示 |
| 特殊型 | SPC | 10% | 改变游戏规则的元道具（如改变掉落规则） |
| 武器专属型 | WEP | 15% | 仅对特定武器生效，分5子类：WEP_SWD/WEP_BOW/WEP_GUN/WEP_STF/WEP_FST |
| 时间型 | TIM | 20% | 与时间停止/回溯/加速/裂隙直接交互的道具 |

### 3.3.2.3 按触发方式分类

| 触发方式 | 代码 | 说明 | 示例 |
|----------|------|------|------|
| 被动常驻 | PASSIVE | 始终生效 | 攻击力+15% |
| 条件触发 | CONDITIONAL | 满足条件时触发 | 受击时20%概率生成护盾 |
| 主动使用 | ACTIVE | 玩家手动激活 | 冻结周围敌人3秒 |
| 套装触发 | SET | 满足套装件数时激活 | 3件时间型道具：时间回溯CD-30% |
| 堆叠触发 | STACK_THRESHOLD | 达到特定层数触发 | 累积5层后每次攻击额外发射1枚弹幕 |

### 3.3.2.4 道具槽位设计

**被动道具：**
- 无硬性槽位上限，最多携带 **20个不同被动道具**
- 堆叠型道具在UI中显示为单格+层数标记
- 超过20个时触发替换规则（见3.3.3.4）

**主动道具：**
- **2个主动道具槽位**
- 键位映射：主动1=LB/L1，主动2=RB/R2

## 3.3.3 道具池与掉落系统

### 3.3.3.1 道具池权重算法

**基础权重分配（单次掉落判定）：**

```
function rollItemRarity(source_modifier):
    // source_modifier由掉落源决定，见3.3.3.2
    weights = {
        "common":    60 * source_modifier.common_mult,
        "uncommon":  30 * source_modifier.uncommon_mult,
        "legendary":  9 * source_modifier.legendary_mult,
        "mythic":     1 * source_modifier.mythic_mult
    }
    // 幸运值影响：每点幸运值使稀有及以上权重+2%，普通权重-6%
    luck = player.stats.luck  // 基础0，道具可增加
    weights.uncommon  *= (1 + luck * 0.02)
    weights.legendary *= (1 + luck * 0.02)
    weights.mythic    *= (1 + luck * 0.02)
    weights.common    *= (1 - luck * 0.06)
    
    return weighted_random(weights)
```

**稀有度确定后，从对应池中随机选取具体道具：**

```
function rollSpecificItem(rarity, player_weapon_type):
    pool = item_database.filter(rarity == rarity)
    // 武器专属道具有3倍权重当玩家使用对应武器时
    for item in pool:
        if item.is_weapon_specific and item.weapon_type == player_weapon_type:
            item.weight *= 3
        elif item.is_weapon_specific and item.weapon_type != player_weapon_type:
            item.weight *= 0.1  // 不对应武器时极低权重，但不为0
    // 已拥有的唯一道具（max_stack=1）从池中移除
    pool = pool.filter(not (item.max_stack == 1 and player.has(item.id)))
    return weighted_random(pool)
```

### 3.3.3.2 掉落场景权重

| 掉落源 | common_mult | uncommon_mult | legendary_mult | mythic_mult | 道具掉落概率 |
|--------|-------------|---------------|----------------|-------------|-------------|
| 普通怪 | 1.0 | 1.0 | 0.5 | 0.0 | 5% |
| 精英怪 | 0.8 | 1.5 | 2.0 | 0.5 | 30% |
| Boss | 0.3 | 1.0 | 3.0 | 2.0 | 100%（必掉1-3个） |
| 宝箱(普通) | 1.0 | 1.5 | 1.0 | 0.3 | 100%（2-3个选项三选一） |
| 宝箱(黄金) | 0.5 | 1.0 | 2.0 | 1.0 | 100%（3个选项三选一） |
| 商店 | 0.5 | 1.5 | 2.0 | 1.0 | N/A（直接购买） |
| 时间裂隙(特殊) | 0.2 | 0.5 | 2.0 | 3.0 | 100%（仅时间型道具池） |

**掉落流程：**

1. 判定是否掉落（基于掉落概率）
2. 判定稀有度（基于权重算法）
3. 判定具体道具（基于池内权重+武器适配）
4. 若为宝箱/Boss，生成选择界面（三选一或展示全部）

### 3.3.3.3 道具解锁与发现机制

**初始状态：**
- 游戏开始时，仅有 **50个普通级 + 20个稀有级** 道具在池中
- 传说和神话道具需要通过成就解锁

**解锁条件：**

| 解锁类型 | 条件 | 效果 |
|----------|------|------|
| 击杀解锁 | 用特定武器击杀Boss | 解锁1个该武器的传说级道具 |
| 通关解锁 | 通关任意难度 | 解锁2个随机传说级道具 |
| 隐藏解锁 | 完成隐藏挑战（如不受伤通关1层） | 解锁1个神话级道具 |
| 联动发现 | 首次触发特定联动效果 | 该联动效果永久记录在图鉴中 |
| 累计解锁 | 累计获得该道具N次 | 道具在商店中出现概率+5% |

**发现机制：**
- 首次获取的道具在拾取时有**金色光效+特殊音效**
- 已发现的道具在图鉴中显示完整信息
- 未发现的道具在图鉴中只显示剪影和问号

### 3.3.3.4 道具替换规则

当被动道具已满20个时：

```
function onItemPickup(new_item):
    if passive_item_count >= 20 and new_item.is_passive:
        // 弹出替换界面：选择丢弃1个已有道具或放弃新道具
        show_replacement_ui(current_items, new_item)
        // 被替换的道具永久丢失（不可找回）
        // 替换时，被替换道具的堆叠效果立即移除
        return player_choice  // 保留的道具
    else:
        add_to_inventory(new_item)
```

**替换界面规则：**
- 新道具显示在中间，已有道具排列在周围
- 已有道具按"与新生道具联动程度"排序（有联动的排前面，提醒玩家）
- 确认替换后有1.5秒的"后悔时间"，期间可撤回

### 3.3.3.5 重roll机制

**基础规则：**
- 每层有1次免费重roll机会
- 重roll消耗金币：50 × 已重roll次数
- 重roll只影响当前选择界面的道具，不影响池的整体权重

**重roll交互：**
- 宝箱三选一界面：按Y/Triangle键重roll全部3个选项
- 商店界面：单个商品可重roll，消耗上述金币

**特殊道具影响重roll：**
- 道具`UTI_FORTUNE_COIN_STK`：每层额外+1次免费重roll（可堆叠）
- 道具`SPC_REROLL_ORACLE`：重roll后下次必定出更高稀有度

## 3.3.4 道具联动系统

### 3.3.4.1 联动类型分类

| 联动类型 | 代码 | 说明 | 示例 |
|----------|------|------|------|
| 数值叠加 | STAT_STACK | 两个道具的同类效果互相放大 | A:+50%暴击伤害 B:暴击时+伤害 → 暴击伤害×2后再加成 |
| 机制替换 | MECH_REPLACE | 一个道具改变另一个道具的触发机制 | A:受击时20%闪避 B:→ 闪避时触发时间回溯0.5秒 |
| 新效果触发 | NEW_EFFECT | 两个道具共存时产生全新的第三种效果 | A:火焰攻击 B:冰霜攻击 → 融合产生蒸汽范围伤害 |
| 视觉变化 | VISUAL | 仅改变视觉效果，不影响数值 | A:时间残影 B:→ 残影变为武器幻影同步攻击 |

### 3.3.4.2 联动矩阵设计方法论

**联动发现矩阵**：每个新道具设计时，必须填写联动矩阵的一行：

```
联动检查表（每新增一个道具必须填写）：
├── 与所有攻击型道具的关系（3句话描述交互）
├── 与所有时间型道具的关系（必须详细，这是核心）
├── 与5种武器专属道具的关系
├── 新增的联动对（至少定义2个新联动关系）
└── 反联动对（是否有不可共存的情况）
```

**联动优先级规则**：
1. 如果多个联动同时触发，按顺序：NEW_EFFECT > MECH_REPLACE > STAT_STACK > VISUAL
2. 如果两个NEW_EFFECT冲突，取道具ID字典序靠前的那个
3. 联动效果在道具获取/移除时即时生效/失效

### 3.3.4.3 具体道具联动关系（30组）

---

**联动 #1 — 烈焰之心 + 寒霜核心 = 蒸汽爆发**
- 道具A：`ATK_FLAME_HEART`（火焰攻击附带燃烧DOT）
- 道具B：`ATK_FROST_CORE`（攻击附带冰冻叠加）
- 联动类型：NEW_EFFECT
- 效果：同时对同一敌人施加燃烧和冰冻时，触发蒸汽爆炸，造成攻击力×1.5的范围伤害（半径3米），冷却0.5秒。燃烧和冰冻效果同时被消耗。

**联动 #2 — 时空裂隙 + 残影透镜 = 回溯斩击**
- 道具A：`TIM_RIFT_SHARD`（时间回溯时在路径留残影）
- 道具B：`TIM_PHANTOM_LENS`（残影对接触敌人造成攻击力×0.5伤害）
- 联动类型：STAT_STACK
- 效果：残影伤害从攻击力×0.5提升至攻击力×1.2，且残影会模仿玩家最后一次攻击动作。

**联动 #3 — 铁壁护符 + 时间冻结 = 绝对防御**
- 道具A：`DEF_IRON_AMULET`（受击时20%概率生成等于最大生命10%的护盾）
- 道具B：`ACT_TIME_FREEZE`（主动：冻结周围敌人3秒）
- 联动类型：NEW_EFFECT
- 效果：使用时间冻结时，立即获得等于最大生命30%的护盾，持续到冻结结束。

**联动 #4 — 连击之刃 + 疾风步 = 风暴连斩**
- 道具A：`WEP_SWD_COMBO_BLADE`（剑：连续命中同一敌人时伤害递增，每次+8%）
- 道具B：`UTI_GALE_STRIDE`（闪避后2秒内攻速+30%）

**套装判定逻辑：**

```
function checkSetBonuses(player):
    set_tags = count_tags(player.items)  // 统计各套装标签的道具数量
    for set_name, count in set_tags:
        set_def = set_definitions[set_name]
        if count >= 3:
            apply_bonus(set_def.bonus_3)
        if count >= 5:
            apply_bonus(set_def.bonus_5)
```

## 3.3.7 商店与经济

### 3.3.7.1 道具定价公式

```
function calculatePrice(item):
    // 基础价格（按稀有度）
    base_prices = {
        "common":    30,
        "uncommon":  80,
        "legendary": 200,
        "mythic":    500
    }
    base = base_prices[item.rarity]
    
    // 效果强度系数（0.8 - 1.5）
    // 根据道具效果的综合评分调整
    // 评分规则：每1%攻击力加成=0.01, 每1%防御=0.015, 特殊机制=0.1-0.3
    effect_modifier = item.effect_score  // 设计时预定义，范围0.8-1.5
    
    // 堆叠折扣：可堆叠道具单价较低但总价更高
    stack_modifier = 1.0
    if item.is_stackable:
        stack_modifier = 0.7  // 单层便宜30%
    
    // 楼层递增：每层商店价格+8%
    floor_modifier = 1 + 0.08 * current_floor
    
    // 随机波动：±10%
    random_modifier = random_range(0.9, 1.1)
    
    price = base * effect_modifier * stack_modifier * floor_modifier * random_modifier
    return round(price / 5) * 5  // 取整到5的倍数
```

**价格区间参考表：**

| 稀有度 | 1层价格区间 | 5层价格区间 | 10层价格区间 |
|--------|------------|------------|-------------|
| 普通 | 20-45 | 30-65 | 40-90 |
| 稀有 | 55-120 | 80-175 | 110-240 |
| 传说 | 140-300 | 210-440 | 300-600 |
| 神话 | 350-750 | 520-1100 | 750-1500 |

### 3.3.7.2 商店刷新规则

**基础规则：**
- 每层有1个商店房间（随机出现概率30%）
- 商店初始展示4个道具（2普通+1稀有+1随机传说或稀有）
- 每层商店有1次免费刷新机会
- 付费刷新：50 × 已刷新次数（第1次50，第2次100，以此类推）

**商店库存生成算法：**

```
function generateShopInventory(floor):
    slots = []
    slots.push(rollFromPool("common"))    // 固定1个普通
    slots.push(rollFromPool("common"))    // 固定1个普通
    slots.push(rollFromPool("uncommon"))  // 固定1个稀有
    
    // 第4个：根据楼层决定
    if floor >= 3:
        if random() < 0.15:  // 15%概率出传说
            slots.push(rollFromPool("legendary"))
        else:
            slots.push(rollFromPool("uncommon"))
    else:
        slots.push(rollFromPool("uncommon"))
    
    // 第5层起额外增加1个主动道具位
    if floor >= 5:
        slots.push(rollFromPool("active"))
    
    return slots
```

### 3.3.8.3 道具注册与查询系统设计

```python
# ============================================================
# 道具注册表（ItemRegistry）— 全局单例
# ============================================================

class ItemRegistry:
    """
    道具注册与查询系统
    - 启动时从JSON加载所有道具定义
    - 提供按ID/分类/稀有度/套装等多维度查询
    - 管理联动关系缓存
    """
    
    _instance = None
    _items: Dict[str, ItemDefinition] = {}        # id -> definition
    _synergy_matrix: Dict[Tuple[str,str], SynergyDef] = {}  # (id_a, id_b) -> synergy
    _anti_synergy_matrix: Dict[Tuple[str,str], AntiSynergyDef] = {}
    _set_definitions: Dict[str, SetDefinition] = {}
    _pool_cache: Dict[str, List[ItemDefinition]] = {}  # 缓存分池查询结果
    
    @classmethod
    def instance(cls) -> 'ItemRegistry':
        if cls._instance is None:
            cls._instance = cls()
            cls._instance.load_all()
        return cls._instance
    
    def load_all(self):
        """从 res://data/items/ 加载所有道具JSON文件"""
        for file_path in glob("res://data/items/**/*.json"):
            data = json.load(file_path)
            item = ItemDefinition.from_dict(data)
            self._items[item.id] = item
        self._build_synergy_matrix()
        self._build_pool_cache()
    
    def get(self, item_id: str) -> ItemDefinition:
        return self._items[item_id]
    
    def query(self, 
              rarity: Optional[str] = None,
              category: Optional[str] = None,
              trigger_type: Optional[str] = None,
              set_id: Optional[str] = None,
              is_stackable: Optional[bool] = None,
              exclude_ids: Optional[Set[str]] = None) -> List[ItemDefinition]:
        """
        多维度查询道具
        所有参数可选，None表示不过滤
        """
        results = list(self._items.values())
        if rarity:
            results = [i for i in results if i.rarity == rarity]
        if category:
            results = [i for i in results if i.category == category]
        if trigger_type:
            results = [i for i in results if i.trigger_type == trigger_type]
        if set_id:
            results = [i for i in results if i.set_info and i.set_info.set_id == set_id]
        if is_stackable is not None:
            results = [i for i in results if i.stack_config.is_stackable == is_stackable]
        if exclude_ids:
            results = [i for i in results if i.id not in exclude_ids]
        return results
    
    def get_synergy(self, item_a: str, item_b: str) -> Optional[SynergyDef]:
        """查询两个道具之间的联动关系"""
        key = (min(item_a, item_b), max(item_a, item_b))
        return self._synergy_matrix.get(key)
    
    def get_all_synergies_for(self, item_id: str) -> List[SynergyDef]:
        """查询一个道具的所有联动关系"""
        return [s for (a, b), s in self._synergy_matrix.items() 
                if a == item_id or b == item_id]
    
    def check_anti_synergy(self, item_a: str, item_b: str) -> Optional[AntiSynergyDef]:
        """检查两个道具是否有反联动"""
        key = (min(item_a, item_b), max(item_a, item_b))
        return self._anti_synergy_matrix.get(key)
    
    def roll_from_pool(self, 
                       rarity_weights: Dict[str, float],
                       source_modifier: SourceModifier,
                       player_weapon: str,
                       exclude: Set[str]) -> ItemDefinition:
        """
        从道具池中随机掉落一个道具
        完整实现3.3.3.1的算法
        """
        # 1. 判定稀有度
        rarity = self._roll_rarity(rarity_weights, source_modifier, player.luck)
        # 2. 从对应池中选取
        pool = self._pool_cache[f"rarity_{rarity}"]
        pool = [i for i in pool if i.id not in exclude]
        # 3. 武器专属权重调整
        weights = []
        for item in pool:
            w = 1.0
            if item.category.startswith("WEP_"):
                if item.category == f"WEP_{player_weapon}":
                    w = 3.0
                else:
                    w = 0.1
            weights.append(w)
        # 4. 加权随机
        return weighted_choice(pool, weights)
    
    def _roll_rarity(self, base_weights, source_mod, luck) -> str:
        """稀有度权重算法（见3.3.3.1）"""
        weights = {}
        for rarity, base_w in base_weights.items():
            mod_key = f"{rarity}_mult"
            mult = getattr(source_mod, mod_key, 1.0)
            w = base_w * mult
            if rarity != "common" and luck > 0:
                w *= (1 + luck * 0.02)
            elif rarity == "common" and luck > 0:
                w *= (1 - luck * 0.06)
            weights[rarity] = max(w, 0.01)
        return weighted_choice(list(weights.keys()), list(weights.values()))
    
    def _build_synergy_matrix(self):
        """构建联动矩阵（启动时一次性构建）"""
        for item in self._items.values():
            for synergy in item.interactions.synergies:
                key = (min(item.id, synergy.item_id), max(item.id, synergy.item_id))
                self._synergy_matrix[key] = synergy
            for anti in item.interactions.anti_synergies:
                key = (min(item.id, anti.item_id), max(item.id, anti.item_id))
                self._anti_synergy_matrix[key] = anti
    
    def _build_pool_cache(self):
        """按稀有度分池缓存"""
        for rarity in ["common", "uncommon", "legendary", "mythic"]:
            self._pool_cache[f"rarity_{rarity}"] = [
                i for i in self._items.values() if i.rarity == rarity
            ]

# 道具实例（ItemInstance）— 运行时数据

class ItemInstance:
    """
    玩家背包中的道具实例
    包含运行时状态：层数、冷却等
    """
    def __init__(self, definition: ItemDefinition):
        self.definition = definition
        self.stack_count = 1
        self.cooldown_timer = 0.0      # 主动道具冷却
        self.active_effects = []        # 当前活跃的效果ID列表
        self.acquired_floor = 0         # 获取楼层
        self.acquired_time = 0.0        # 获取时间（游戏内时间）
    
    @property
    def id(self) -> str:
        return self.definition.id
    
    @property
    def is_on_cooldown(self) -> bool:
        return self.cooldown_timer > 0
    
    def add_stack(self, count: int = 1):
        max_s = self.definition.stack_config.max_stack
        self.stack_count = min(self.stack_count + count, max_s)
    
    def tick_cooldown(self, delta: float):
        if self.cooldown_timer > 0:
            self.cooldown_timer = max(0, self.cooldown_timer - delta)
    
    def use(self, player) -> bool:
        """使用主动道具"""
        if self.is_on_cooldown:
            return False
        energy_cost = self.definition.active_config.energy_cost
        if player.time_energy < energy_cost:
            return False
        player.time_energy -= energy_cost
        self.cooldown_timer = self.definition.active_config.cooldown
        # 执行效果
        self._execute_effects(player)
        return True

# 道具管理器（InventoryManager）— 管理玩家背包
# ============================================================

class InventoryManager:
    MAX_PASSIVE_ITEMS = 20
    MAX_ACTIVE_ITEMS = 2
    
    def __init__(self):
        self.passive_items: Dict[str, ItemInstance] = {}  # id -> instance
        self.active_items: List[Optional[ItemInstance]] = [None, None]
        self.gold = 0
    
    def add_passive(self, definition: ItemDefinition) -> Optional[ItemInstance]:
        """添加被动道具"""
        if definition.id in self.passive_items:
            # 已有，尝试堆叠
            instance = self.passive_items[definition.id]
            if instance.definition.stack_config.is_stackable:
                instance.add_stack(1)
                return instance
            return None  # 不可堆叠且已有
        
        if len(self.passive_items) >= self.MAX_PASSIVE_ITEMS:
            return None  # 需要触发替换UI
        
        instance = ItemInstance(definition)
        self.passive_items[definition.id] = instance
        return instance
    
    def add_active(self, definition: ItemDefinition, slot: int = -1) -> bool:
        """添加主动道具"""
        if slot == -1:
            # 自动选择空槽
            if self.active_items[0] is None:
                slot = 0
            elif self.active_items[1] is None:
                slot = 1
            else:
                return False  # 两个槽都满了，需要替换
        
        self.active_items[slot] = ItemInstance(definition)
        return True
    
    def remove_passive(self, item_id: str):
        """移除被动道具"""
        if item_id in self.passive_items:
            del self.passive_items[item_id]
    
    def has(self, item_id: str) -> bool:
        return item_id in self.passive_items
    
    def get_set_counts(self) -> Dict[str, int]:
        """统计各套装的件数"""
        counts = {}
        for instance in self.passive_items.values():
            if instance.definition.set_info:
                set_id = instance.definition.set_info.set_id
                counts[set_id] = counts.get(set_id, 0) + 1
        return counts
    
    def check_synergies(self) -> List[SynergyDef]:
        """检查当前背包中所有活跃的联动"""
        registry = ItemRegistry.instance()
        active_synergies = []
        item_ids = list(self.passive_items.keys())
        for i in range(len(item_ids)):
            for j in range(i+1, len(item_ids)):
                synergy = registry.get_synergy(item_ids[i], item_ids[j])
                if synergy:
                    active_synergies.append(synergy)
        return active_synergies
```
