## 8.1.1 枢纽概述

### 概念定位

**"时之枢纽"（Chronos Nexus）**——位面行者的大本营，位于多个碎片交汇处的安全区域。崩后第三纪，时之议会利用最大的一块永恒之心碎片锚定此区域，建立起行者的中转站。枢纽本身是一个"正在被修补的残缺空间"——初始状态下荒凉破败，随着玩家推进Meta进度，枢纽逐步修复、扩建，从废墟变为繁荣的行者据点。

枢纽不是静态菜单，而是一个**可自由移动探索的2.5D场景**，玩家以角色形态在枢纽中行走、与NPC对话、使用各功能区域。枢纽的设计哲学：

1. **叙事载体**：NPC对话推进主线、揭示世界观、建立情感连接
2. **功能中枢**：所有局外操作（升级、购买、装备、出发）在此完成
3. **进度可视化**：枢纽的修复程度=玩家的Meta进度，空间本身即奖励
4. **情绪缓冲**：死亡后的安全港，让玩家在挫折后获得"回家"的安慰感

### 视觉风格和氛围

| 属性 | 描述 |
|------|------|
| **整体色调** | 深蓝灰色底色(#0d1117)+金色点缀(#ffc107)+青蓝光效(#00bcd4) |
| **光源** | 中央悬浮的永恒之心碎片作为主光源，发出温暖金色脉冲光；各区域有独立的辅助光源 |
| **材质** | 半坍塌的白色大理石+暗色金属框架+发光的时间符文纹路；修复后增加温暖木质和织物 |
| **氛围音效** | 持续的低频心跳声（永恒之心碎片）、远处的风声、偶尔的时间回响（钟声片段） |
| **动态元素** | 空气中飘浮的金色微粒（时之能量）、地面偶现的时间纹路脉冲、裂隙入口处的虚空涟漪 |
| **初始状态** | 昏暗、荒凉、半坍塌、NPC稀少、部分区域被碎石封锁 |
| **完全修复状态** | 明亮、温暖、繁荣、NPC全部在场、所有区域开放、装饰丰富 |

## 8.1.3 枢纽NPC系统

### NPC通用规则

**亲密度系统：**

每个NPC拥有隐藏的好感度值(0~100)，通过以下方式提升：

| 提升方式 | 好感度增量 | 冷却/限制 |
|---------|-----------|----------|
| 每次Run后与NPC对话 | +2 | 每次Run限1次/NPC |
| 完成NPC相关任务 | +5~15 | 取决于任务难度 |
| 赠送NPC偏好的物品 | +3~8 | 每个NPC每次Run限1件 |
| 在Run中完成NPC提及的目标 | +5 | 需NPC先提及 |
| 选择NPC倾向的对话选项 | +2~5 | 不限次数 |

**好感度阈值与解锁：**

| 好感度 | 等级名称 | 通用解锁 |
|--------|---------|---------|
| 0~19 | 陌生 | 基础对话、基础功能 |
| 20~39 | 熟悉 | 解锁第二条对话分支、偶尔赠送小礼物 |
| 40~59 | 信任 | 解锁第三条对话分支（含个人背景）、开放任务线 |
| 60~79 | 亲密 | 解锁第四条对话分支（深层秘密）、专属物品/升级 |
| 80~100 | 羁绊 | 完整对话解锁、结局相关选项、专属称号、特殊互动 |

**NPC对话系统技术规格：**

```
对话数据结构：
{
  npc_id: string,           // NPC唯一标识
  node_id: string,          // 对话节点ID
  precondition: {           // 前置条件（全部满足才可触发）
    min_affinity: int,      // 最低好感度
    max_affinity: int,      // 最高好感度（用于限定阶段）
    quest_flag: string[],   // 需要完成的任务标记
    item_flag: string[],    // 需要持有的物品标记
    run_count: int,         // 最低Run次数
    layer_reached: int,     // 最低到达层数
    boss_killed: string[],  // 需要击杀的Boss
    choice_made: string[],  // 需要做出的关键选择
  },
  text: string,             // 对话文本
  choices: [                // 玩家选项（0~3个）
    {
      text: string,         // 选项文本
      affinity_delta: int,  // 好感度变化
      next_node: string,    // 跳转节点
      set_flag: string,     // 设置标记
      reward: {             // 奖励（可选）
        currency: {type, amount},
        item: string,
        quest: string,
      }
    }
  ],
  auto_next: string,        // 无选择时自动跳转节点
  voice_line: string,       // 语音文件路径
  animation: string,        // NPC动画触发标记
}
```

### 货币结算公式

#### 魂（Soul）结算

```
保留魂 = Floor(Run内累计获得魂 × 保留比例)

保留比例计算：
  基础保留比例 = 30%
  Meta节点W-07(魂之记忆)加成 = +20%（提升至50%）
  Meta节点W-08(魂之回响)加成 = +20%（提升至70%）
  伙伴加成(奥德修斯) = +5%（最高75%）
  难度加成：困难+5%，噩梦+10%
  
  最终保留比例 = Min(基础 + Meta加成 + 伙伴加成 + 难度加成, 80%)
  （硬上限80%，防止积累过快）
```

**魂获取来源及权重：**

| 来源 | 魂数量 | 权重 |
|------|--------|------|
| 普通敌人击杀 | 3~8 | 基础 |
| 精英敌人击杀 | 30~60 | ×5 |
| Boss击杀 | 100~200 | ×15 |
| 宝箱 | 20~80 | 随机 |
| 事件奖励 | 10~50 | 随机 |
| 商店出售道具 | 道具价值×0.6 | - |

#### 时之碎片（Chronos Shard）结算

```
本次获得时之碎片 = 基础奖励 + 层数奖励 + Boss奖励 + 任务奖励 + 首次加成

基础奖励 = 5（每次Run最低保底）
层数奖励 = 到达层数 × 8（到达第3层 = 3×8 = 24）
Boss奖励 = 击败Boss数 × 15（击败2个Boss = 30）
任务奖励 = Run内完成的NPC任务对应奖励（变动）
首次加成 = 首次到达新层 × 20（首次到达第3层额外+20）
难度加成 = ×1.0(普通) / ×1.5(困难) / ×2.0(噩梦)
速度加成 = Run时间<20分钟 ×1.2 / <30分钟 ×1.1 / ≥30分钟 ×1.0

最终时之碎片 = Floor((基础+层数+Boss+任务+首次) × 难度 × 速度)
```

**时之碎片获取示例表：**

| Run描述 | 基础 | 层数 | Boss | 首次 | 难度 | 速度 | 总计 |
|---------|------|------|------|------|------|------|------|
| 第1次Run，死于L1 | 5 | 8 | 0 | 20 | ×1.0 | ×1.0 | 33 |
| 死于L3，击败2Boss | 5 | 24 | 30 | 0 | ×1.0 | ×1.1 | 64.9→64 |
| 通关L5普通，35min | 5 | 40 | 75 | 0 | ×1.0 | ×1.0 | 120 |
| 通关L5困难，25min | 5 | 40 | 75 | 20 | ×1.5 | ×1.1 | 231 |
| 通关L5噩梦，18min | 5 | 40 | 75 | 0 | ×2.0 | ×1.2 | 288 |

#### 存在印记（Existential Imprint）结算

```
存在印记获取方式：
  1. 隐藏在环境中的印记（每层1~3个，需要探索/解谜发现）
  2. 特定敌人掉落（精英20%概率，Boss 50%概率）
  3. 特殊事件奖励（变动）
  4. NPC任务奖励

```

## 8.1.8 局间节奏设计

### 时间目标

| 指标 | 目标值 | 容差范围 | 测量方式 |
|------|--------|---------|---------|
| 单次Run时长 | 35分钟 | 25~55分钟 | 从进入地牢到死亡/通关 |
| 短Run（早期死亡） | 10分钟 | 5~15分钟 | 死于L1~L2 |
| 中Run（中途死亡） | 25分钟 | 18~35分钟 | 死于L3~L4 |
| 长Run（通关） | 45分钟 | 35~55分钟 | 通关全部5层 |
| **死亡→下一局出发** | **90秒** | **60~120秒** | 从死亡画面到再次进入地牢 |
| 通关→下一局出发 | 3分钟 | 2~5分钟 | 含结局CG和枢纽变化 |
| 枢纽快速停留 | 30秒 | 15~60秒 | 仅对话+出发 |
| 枢纽深度停留 | 4分钟 | 2~8分钟 | 升级+购买+装备+剧情 |

### "死亡→下一局出发"周转时间分解

| 步骤 | 预计时间 | 可加速 |
|------|---------|--------|
| 死亡动画 | 3.0秒 | 否（情感设计需要） |
| 等待玩家输入 | 0~5秒 | 按键即跳过 |
| 结算界面浏览 | 10~20秒 | 可快速跳过（按确认直接进入转场） |
| 结算转场 | 4.0秒 | 否 |
| 枢纽NPC对话 | 0~30秒 | 可跳过（直行到裂隙） |
| 出发准备 | 20~40秒 | 可用上次配置快速出发 |
| 出发转场 | 3.8秒 | 否 |
| **总计（最快）** | **~41秒** | 全部加速操作 |
| **总计（正常）** | **~90秒** | 正常浏览+简短对话+标准出发 |

**快速出发功能：**

- 记住上次使用的角色+武器+难度组合
- 枢纽中走向裂隙入口时，按住确认键1秒直接使用上次配置出发（跳过5步选择流程）
- 前提：已完成至少3次Run（防止新手跳过教程）

### 枢纽停留行为引导

**设计目标：让枢纽停留时间在30秒~5分钟之间，既不过短（跳过叙事），也不过长（阻碍节奏）**

| 行为 | 引导策略 | 具体实现 |
|------|---------|---------|
| **停留过短（<15秒）** | 柔性阻挡 | 首次到达新层后NPC会主动叫住玩家、新解锁内容弹窗提示、裂隙入口"冷却"（3秒不可交互） |
| **停留过短（跳过所有对话）** | 奖励诱导 | NPC好感度奖励越来越丰厚、低好感度时部分Meta节点不可购买、关键剧情需要对话推进 |
| **停留过长（>5分钟）** | 柔性催促 | NPC对话循环（"你该出发了"）、裂隙入口光芒脉冲加速（视觉催促）、"存在磨损"提示（停留太久角色会开始出现消融效果，纯装饰） |
| **停留过长（反复刷商店）** | 自然限制 | 商店库存每次Run后更新（不能无限刷）、存在印记交易有每日上限 |
| **停留适中（1~3分钟）** | 正向反馈 | NPC好感度自然增长、枢纽氛围音乐更愉悦、出发时角色有信心动画 |

**NPC催促对话示例（停留超过5分钟后触发）：**

| NPC | 催促对话 |
|-----|---------|
| 奥德修斯 | "行者，裂隙不会永远等你。" |
| 墨菲斯 | "别磨蹭了，训练场不是用来发呆的。" |
| 赫尔墨斯 | "我的店不提供住宿服务，朋友。" |
| 菲娅 | "你的脚步声……在说'该走了'。" |
| 虚无歌者 | "……（沉默，但虚无的呼吸声加重了）" |

### 连续游戏疲劳控制

**设计目标：防止玩家连续长时间游戏导致体验下降和倦怠**

| 机制 | 触发条件 | 效果 | 设计意图 |
|------|---------|------|---------|
| **Run计数提示** | 连续3次Run未休息 | 屏幕右上角显示"你已经连续进行了3次行走" | 温和提醒 |
| **奖励衰减预警** | 连续5次Run | 提示"行者之殇风险增加——连续行走好感度获取降低50%" | 惩罚过度游玩 |
| **好感度衰减** | 连续5次Run后 | NPC好感度每次+2降为+1 | 减少连续游玩的奖励密度 |
| **强制休息建议** | 连续8次Run | 弹出"你的存在正在磨损，建议回到现实休息" | 强提示（可关闭） |
| **存在磨损视觉效果** | 连续5次Run后 | 角色在枢纽中的边缘开始出现灰色消融（纯装饰） | 视觉疲劳提醒 |
| **休息奖励** | 关闭游戏后重新打开 | 根据离线时间给予少量时之碎片奖励（最大8小时=时之碎片×10） | 正向激励休息 |

**疲劳系统数值：**

```
连续Run计数 = 本次启动游戏后完成的Run次数（不含之前启动的）

连续Run奖励修正：
  Run 1~4: 100%（正常）
  Run 5~7: 80%（好感度×0.8，时之碎片×0.9）
  Run 8~10: 60%（好感度×0.6，时之碎片×0.8）
  Run 11+: 50%（好感度×0.5，时之碎片×0.7）
  
休息奖励：
  离线时间 < 1小时: 0
  离线时间 1~4小时: 时之碎片 × Floor(离线小时数 × 2)
  离线时间 4~8小时: 时之碎片 × 10 (上限)
  离线时间 > 8小时: 时之碎片 × 10 (不再增加)
  
疲劳重置：
  关闭游戏再打开 → 连续Run计数清零 → 奖励修正恢复100%
```

**设计哲学说明：**

疲劳系统不是惩罚机制，而是**关怀机制**。Roguelike游戏容易让玩家陷入"再来一局"的循环，长时间游戏会导致判断力下降、挫败感累积。通过温和的奖励递减和视觉提醒，引导玩家适时休息。同时，休息奖励确保玩家不会觉得"不玩就亏了"——离线收益虽然不如在线，但不会为零。
