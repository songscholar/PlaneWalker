## 3.5.1 地牢生成算法

### 3.5.1.1 算法选型与架构

采用 **混合三层生成架构**：

| 层级 | 算法 | 职责 |
|------|------|------|
| 第一层：宏观布局 | 基于图论的房间拓扑图生成 | 确定房间数量、类型、连接关系、分支结构 |
| 第二层：空间映射 | BSP分区 + 房间放置 | 将拓扑图映射到2D网格空间，确定房间坐标与大小 |
| 第三层：微观填充 | 走廊连接 + 模板实例化 | 生成走廊路径、实例化房间模板、填充敌人/物品 |

**选择理由：**
- 图论层保证关卡可解性（必经路径、分支选择）
- BSP层保证空间布局合理（无重叠、紧凑）
- 模板层保证每个房间手工级品质（非纯程序化拼凑）

### 3.5.1.2 完整生成流程

**步骤1：初始化种子与层参数**

```
输入: seed(整数), floorIndex(1-5)
输出: 该层的完整地牢数据
```

根据 `floorIndex` 查表获取层参数：

```
FloorParams = {
    1: { roomCount: [8,10], branchRate: 0.3, specialRoomMin: { shop:1, treasure:1, event:1, rest:1 } },
    2: { roomCount: [9,11], branchRate: 0.35, specialRoomMin: { shop:1, treasure:1, event:1, rest:1 } },
    3: { roomCount: [10,12], branchRate: 0.4, specialRoomMin: { shop:1, treasure:1, event:2, rest:1 } },
    4: { roomCount: [10,13], branchRate: 0.45, specialRoomMin: { shop:1, treasure:2, event:1, rest:1 } },
    5: { roomCount: [8,10], branchRate: 0.2, specialRoomMin: { shop:1, treasure:1, event:1, rest:0 } },
}
```

**步骤2：生成房间拓扑图（图论层）**

1. 确定房间总数 `N = random_range(roomCount[0], roomCount[1])`
2. 创建起点房间（入口）和终点房间（Boss门）
3. 生成主路径：从起点到终点的最短路径，长度 = `N * (1 - branchRate)` 的整数部分
4. 从主路径节点上随机生长分支，分支长度 1-3 个房间
5. 标记每个房间的类型（战斗/精英/宝藏/商店/事件/休息/Boss）
6. 验证约束条件

**步骤3：BSP空间分区（空间映射层）**

1. 创建大矩形区域（如 200×200 网格单位，1单位=1米）
2. 递归二分分割（BSP），直到叶节点面积能容纳单个房间
3. 对每个叶节点，在内部随机放置房间矩形（留边距≥2单位）
4. 将拓扑图中的房间节点一一对应到BSP叶节点的房间矩形
5. 起点房间映射到最左下区域，Boss房间映射到最右上区域

**步骤4：走廊连接**

1. 遍历拓扑图的每条边
2. 对每对相邻房间，找到各自最近的门位置
3. 使用 L型走廊（先水平后垂直，或反之，随机选择）连接两门
4. 走廊宽度：2格（标准）或 3格（层4-5）
5. 走廊中随机添加转折点，避免纯直线

**步骤5：房间实例化**

1. 根据房间类型和尺寸，从对应模板库中选取模板
2. 实例化模板：放置碰撞体、装饰物、灯光
3. 在敌人生成点标记处填充敌人数据（由房间内容生成算法决定）

**步骤6：填充房间内容**

1. 调用房间内容生成算法（见3.5.4）生成敌人组合与波次
2. 放置宝箱/奖励
3. 放置环境危险

**步骤7：验证与修正**

1. 全房间可达性检测（BFS/DFS从起点出发）
2. 最短路径长度检查（应在 N*0.4 到 N*0.7 之间）
3. 特殊房间数量≥保底值
4. 若验证失败，回到步骤2重新生成

### 3.5.1.3 伪代码

```python
class DungeonGenerator:
    def generate(self, seed: int, floor_index: int) -> Dungeon:
        rng = SeededRNG(seed)
        params = FloorParams[floor_index]
        
        # === 第一层：图论拓扑 ===
        graph = self.generate_topology(rng, params)
        
        # === 第二层：BSP空间映射 ===
        bsp_root = self.bsp_partition(rng, 
            rect=Rect(0, 0, 200, 200),
            depth=0,
            max_depth=self.calc_bsp_depth(graph.room_count))
        rooms_rect = self.place_rooms(rng, bsp_root, graph)
        
        # === 第三层：走廊与实例化 ===
        corridors = self.generate_corridors(rng, graph, rooms_rect)
        dungeon = self.instantiate_rooms(rng, graph, rooms_rect, floor_index)
        dungeon.corridors = corridors
        
        # === 填充内容 ===
        for room in dungeon.rooms:
            self.populate_room(rng, room, floor_index)
        
        # === 验证 ===
        if not self.validate(dungeon, params):
            return self.generate(seed + 1, floor_index)  # 换种子重试
        
        return dungeon
    
    def generate_topology(self, rng, params) -> RoomGraph:
        N = rng.int_range(params.room_count[0], params.room_count[1])
        main_path_len = max(3, int(N * (1 - params.branch_rate)))
        
        graph = RoomGraph()
        
        # 创建主路径
        start = graph.add_room(RoomType.START, 0)
        prev = start
        for i in range(1, main_path_len - 1):
            # 主路径上奇数位为战斗房，偶数位留作特殊
            if i % 3 == 0:
                room_type = RoomType.ELITE
            else:
                room_type = RoomType.COMBAT
            node = graph.add_room(room_type, i)
            graph.add_edge(prev, node)
            prev = node
        boss = graph.add_room(RoomType.BOSS, N - 1)
        graph.add_edge(prev, boss)
        
        # 生成分支
        remaining = N - main_path_len
        main_nodes = graph.get_main_path()
        branch_count = 0
        while remaining > 0 and branch_count < main_path_len:
            anchor = rng.choice(main_nodes[1:-1])  # 不从起点/boss分出
            branch_len = min(rng.int_range(1, 3), remaining)
            prev_branch = anchor
            for j in range(branch_len):
                branch_room = self.pick_branch_room_type(rng, params, graph)
                node = graph.add_room(branch_room, graph.next_id())
                graph.add_edge(prev_branch, node)
                prev_branch = node
                remaining -= 1
            branch_count += 1
        
        # 保底特殊房间
        self.ensure_special_rooms(rng, graph, params)
        
        return graph
    
    def bsp_partition(self, rng, rect, depth, max_depth) -> BSPNode:
        node = BSPNode(rect)
        if depth >= max_depth or rect.area() < MIN_ROOM_AREA * 2:
            return node
        
        # 选择分割方向：宽>高则垂直分割，反之水平
        if rect.w > rect.h * 1.25:
            split_dir = VERTICAL
        elif rect.h > rect.w * 1.25:
            split_dir = HORIZONTAL
        else:
            split_dir = rng.choice([VERTICAL, HORIZONTAL])
        
        # 分割比例在 0.35-0.65 之间
        split_ratio = rng.float_range(0.35, 0.65)
        rect_a, rect_b = rect.split(split_dir, split_ratio)
        
        node.left = self.bsp_partition(rng, rect_a, depth + 1, max_depth)
        node.right = self.bsp_partition(rng, rect_b, depth + 1, max_depth)
        return node
    
    def place_rooms(self, rng, bsp_root, graph) -> dict:
        leaves = bsp_root.get_leaves()
        rooms_rect = {}
        rng.shuffle(leaves)
        
        for i, room_node in enumerate(graph.nodes):
            leaf = leaves[i]
            margin = 2  # 2格边距
            room_w = rng.int_range(
                max(MIN_ROOM_W, leaf.rect.w - 2 * margin),
                leaf.rect.w - margin
            )
            room_h = rng.int_range(
                max(MIN_ROOM_H, leaf.rect.h - 2 * margin),
                leaf.rect.h - margin
            )
            room_x = leaf.rect.x + rng.int_range(margin, leaf.rect.w - room_w - margin)
            room_y = leaf.rect.y + rng.int_range(margin, leaf.rect.h - room_h - margin)
            rooms_rect[room_node.id] = Rect(room_x, room_y, room_w, room_h)
        
        return rooms_rect
    
    def generate_corridors(self, rng, graph, rooms_rect) -> list:
        corridors = []
        for edge in graph.edges:
            rect_a = rooms_rect[edge.a]
            rect_b = rooms_rect[edge.b]
            
            # 找两房间最近的门位
            door_a, door_b = self.find_closest_doors(rect_a, rect_b)
            
            # L型走廊
            if rng.chance(0.5):
                # 先水平后垂直
                mid = Point(door_b.x, door_a.y)
                corridors.append(Corridor(door_a, mid, HORIZONTAL))
                corridors.append(Corridor(mid, door_b, VERTICAL))
            else:
                # 先垂直后水平
                mid = Point(door_a.x, door_b.y)
                corridors.append(Corridor(door_a, mid, VERTICAL))
                corridors.append(Corridor(mid, door_b, HORIZONTAL))
        
        return corridors
    
    def validate(self, dungeon, params) -> bool:
        # 可达性
        reachable = bfs(dungeon.start_room)
        if len(reachable) != dungeon.room_count:
            return False
        
        # 最短路径
        shortest = bfs_shortest_path(dungeon.start_room, dungeon.boss_room)
        min_acceptable = int(dungeon.room_count * 0.4)
        max_acceptable = int(dungeon.room_count * 0.7)
        if shortest < min_acceptable or shortest > max_acceptable:
            return False
        
        # 特殊房间保底
        for room_type, min_count in params.special_room_min.items():
            actual = dungeon.count_rooms(room_type)
            if actual < min_count:
                return False
        
        return True
```

### 3.5.1.4 生成约束

| 约束项 | 规则 | 说明 |
|--------|------|------|
| **全局可达** | BFS从起点出发可到达所有房间 | 死胡同允许，孤立区禁止 |
| **最短路径** | 起点到Boss的路径长度 ∈ [N×0.4, N×0.7] | N=房间总数 |
| **最长路径** | 起点到Boss最长路径 ≤ N | 含所有分支 |
| **特殊房间上限** | 商店≤2, 宝藏≤3, 事件≤3, 休息≤2 | 每层 |
| **特殊房间下限** | 见层参数表 | 每层保底 |
| **Boss房唯一** | 仅1个，且为终点 | 必须在拓扑末端 |
| **起点唯一** | 仅1个，且为入口 | 必须在拓扑首端 |
| **商店不可相邻** | 商店房间间至少隔1个战斗房 | 防止经济膨胀 |
| **分支深度** | 分支最长3个房间 | 防止过深死路 |
| **房间面积** | 普通房 12×12~20×20格，Boss房 24×24~30×30格 | 1格=1米 |
| **走廊宽度** | 层1-3: 2格，层4-5: 3格 | 越深越宽以容纳更多敌人 |
| **无死循环** | 拓扑图为有向无环图(DAG) | 禁止环状结构 |

### 3.5.1.5 种子系统

```python
class SeededRNG:
    """基于xorshift128+的可复现随机数生成器"""
    def __init__(self, seed: int):
        self.state = [seed, seed ^ 0xDEADBEEF]
    
    def next(self) -> int:
        """核心xorshift128+算法"""
        s1 = self.state[0]
        s0 = self.state[1]
        result = s0 + s1
        self.state[0] = s0
        s1 ^= s1 << 23
        self.state[1] = s1 ^ s0 ^ (s1 >> 18) ^ (s0 >> 5)
        return result & 0x7FFFFFFFFFFFFFFF
    
    def int_range(self, min_val, max_val) -> int:
        return min_val + (self.next() % (max_val - min_val + 1))
    
    def float_range(self, min_val, max_val) -> float:
        return min_val + (self.next() / (2**63)) * (max_val - min_val)
    
    def chance(self, probability) -> bool:
        return (self.next() / (2**63)) < probability
    
    def choice(self, list) -> any:
        return list[self.next() % len(list)]
    
    def shuffle(self, list) -> None:
        for i in range(len(list) - 1, 0, -1):
            j = self.next() % (i + 1)
            list[i], list[j] = list[j], list[i]
```

**种子使用规范：**

- 全局种子 `global_seed`：玩家开始新局时由系统生成或玩家输入
- 层种子 `floor_seed = hash(global_seed * 31 + floor_index * 17)`
- 房间种子 `room_seed = hash(floor_seed * 13 + room_index * 7)`
- 内容种子 `content_seed = hash(room_seed * 11 + content_type * 5)`

**种子存储：**
- 存入存档文件，保证加载后相同房间内容一致
- 日常种子（Daily Seed）：`daily_seed = hash(YYYYMMDD)`，全球排行榜用

| 属性 | 值 |
|------|-----|
| **房间数量** | 8-10 |
| **分支复杂度** | branchRate=0.3，1-2条短分支（1-2房） |

- 敌人基础HP=30，攻击力=8
- 敌人数量/房间：3-5只

- 本层为教学层，弹窗提示基本操作

## 3.5.4 房间生成规则

### 3.5.4.1 房间内容生成算法

```python
class RoomContentGenerator:
    def populate(self, rng: SeededRNG, room: Room, floor_index: int):
        if room.type == RoomType.COMBAT:
            self.populate_combat(rng, room, floor_index)
        elif room.type == RoomType.ELITE:
            self.populate_elite(rng, room, floor_index)
        # 宝藏/商店/事件/休息由模板交互定义，无需额外生成
    
    def populate_combat(self, rng, room, floor_index):
        # 确定敌人数量
        base_count = COMBAT_BASE_COUNT[floor_index]  # [3,4,5,5,4]
        variance = rng.int_range(-1, 2)
        enemy_count = max(2, base_count + variance)
        
        # 确定敌人组合
        enemy_pool = ENEMY_POOL[floor_index]
        enemies = []
        for i in range(enemy_count):
            enemy_type = rng.weighted_choice(enemy_pool)
            # 权重: 普通敌人60%, 快速敌人25%, 远程敌人15%
            enemies.append(self.create_enemy(rng, enemy_type, floor_index))
        
        # 确定波次
        wave_count = self.determine_waves(rng, enemy_count, floor_index)
        room.waves = self.split_into_waves(rng, enemies, wave_count)
    
    def determine_waves(self, rng, enemy_count, floor_index) -> int:
        # 波次概率表
        wave_table = {
            1: {1: 0.70, 2: 0.30, 3: 0.00},
            2: {1: 0.50, 2: 0.40, 3: 0.10},
            3: {1: 0.30, 2: 0.45, 3: 0.25},
            4: {1: 0.20, 2: 0.50, 3: 0.30},
            5: {1: 0.25, 2: 0.45, 3: 0.30},
        }
        roll = rng.float_range(0, 1)
        table = wave_table[floor_index]
        cumulative = 0
        for wave_num, prob in table.items():
            cumulative += prob
            if roll < cumulative:
                return wave_num
        return 1
    
    def split_into_waves(self, rng, enemies, wave_count) -> list:
        if wave_count == 1:
            return [enemies]
        
        waves = [[] for _ in range(wave_count)]
        # 第一波至少40%敌人
        first_wave_size = max(2, int(len(enemies) * 0.4))
        
        shuffled = list(enemies)
        rng.shuffle(shuffled)
        
        # 第一波
        waves[0] = shuffled[:first_wave_size]
        remaining = shuffled[first_wave_size:]
        
        # 后续波均分
        per_wave = len(remaining) // (wave_count - 1)
        for w in range(1, wave_count):
            start = (w - 1) * per_wave
            end = start + per_wave if w < wave_count - 1 else len(remaining)
            waves[w] = remaining[start:end]
        
        return waves
    
    def create_enemy(self, rng, enemy_type, floor_index) -> Enemy:
        # 基础属性缩放
        base_hp = ENEMY_BASE_HP[floor_index]  # [30,50,75,110,150]
        base_atk = ENEMY_BASE_ATK[floor_index]  # [8,12,18,25,35]
        
        # 个体变异：±15%
        hp_variance = rng.float_range(0.85, 1.15)
        atk_variance = rng.float_range(0.85, 1.15)
        
        return Enemy(
            type=enemy_type,
            hp=int(base_hp * hp_variance * ENEMY_TYPE_HP_MULT[enemy_type]),
            atk=int(base_atk * atk_variance * ENEMY_TYPE_ATK_MULT[enemy_type]),
        )
```

**敌人类型倍率表：**

| 敌人类型 | HP倍率 | ATK倍率 | 速度 | 说明 |
|----------|--------|---------|------|------|
| 普通 | 1.0 | 1.0 | 中 | 基础近战 |
| 快速 | 0.7 | 0.8 | 快 | 低血高机动 |
| 远程 | 0.6 | 1.3 | 慢 | 远程攻击 |
| 坦克 | 2.0 | 0.7 | 慢 | 高血低攻 |
| 精英 | 3.5 | 1.5 | 中 | 精英房专属 |

### 3.5.4.4 房间奖励生成规则

```python
class RoomRewardGenerator:
    def generate_reward(self, rng, room, floor_index, clear_time_seconds):
        reward = Reward()
        
        # === 金币奖励 ===
        base_gold = GOLD_BASE_PER_FLOOR[floor_index]  # [15,20,28,35,45]
        # 清关时间加成：60秒内清完+50%
        time_bonus = 1.5 if clear_time_seconds < 60 else 1.0
        # 房间类型加成
        type_mult = {
            RoomType.COMBAT: 1.0,
            RoomType.ELITE: 2.0,
            RoomType.BOSS: 5.0,
        }.get(room.type, 1.0)
        
        reward.gold = int(base_gold * time_bonus * type_mult * rng.float_range(0.8, 1.2))
        
        # === 概率掉落 ===
        # 小概率掉落生命球
        if rng.chance(0.25):  # 25%
            reward.heal_orbs = rng.int_range(1, 2)  # 每个恢复5HP
        
        # 精英房/特殊房概率掉落道具
        if room.type == RoomType.ELITE:
            if rng.chance(0.35):  # 35%
                reward.item = self.random_item(rng, floor_index, rarity='rare')
        elif room.type == RoomType.BOSS:
            reward.item = self.random_item(rng, floor_index, rarity='epic')
        
        # 时间碎片掉落（层3+）
        if floor_index >= 3 and rng.chance(0.15):
            reward.time_fragments = rng.int_range(1, 3)
        
        return reward
```

- **距离提示：** 当前房间到Boss房的最短房间数显示在小地图下方（如"距王座：4房间"）

### 3.5.5.4 快速旅行

- **不允许**回到已清理的房间（与Dead Cells一致，单向推进）
- **例外：** 在当前房间内可以自由移动（如返回房间入口处）
- **设计理由：** 防止玩家反复刷资源，保持紧迫感
- **分支提示：** 当玩家选择一条分支后，另一条分支会标记为"已放弃"（灰色），不再可进入

### 3.5.6.3 事件选取算法

```python
class EventSelector:
    def select_event(self, rng, floor_index, player_state) -> Event:
        # 构建可用事件池
        pool = []
        for event in ALL_EVENTS:
            if self.is_available(event, floor_index, player_state):
                pool.append((event, event.weight))
        
        # 特殊事件优先检查
        for special in SPECIAL_EVENTS:
            if special.check_trigger(player_state):
                if rng.chance(special.trigger_chance):
                    return special
        
        # 加权随机
        total_weight = sum(w for _, w in pool)
        roll = rng.float_range(0, total_weight)
        cumulative = 0
        for event, weight in pool:
            cumulative += weight
            if roll < cumulative:
                return event
        
        return pool[-1][0]  # fallback
    
    def is_available(self, event, floor_index, player_state):
        # 层限制：部分事件只在特定层出现
        if event.min_floor and floor_index < event.min_floor:
            return False
        if event.max_floor and floor_index > event.max_floor:
            return False
        # 不重复：同局中同一事件最多出现1次
        if event.id in player_state.seen_events:
            return False
        return True
```

```python
def shop_price(base_price, floor_index, item_rarity, reroll_count):
    floor_mult = 1.0 + (floor_index - 1) * 0.15  # 每层+15%
    rarity_mult = {'common': 1.0, 'rare': 1.8, 'epic': 3.0, 'legendary': 5.0}
    reroll_surcharge = 1.0 + reroll_count * 0.2  # 每次重roll+20%
    
    return int(base_price * floor_mult * rarity_mult[item_rarity] * reroll_surcharge)
```

### 3.5.7.3 通货膨胀控制

**机制1：价格递增**
- 每层商店道具价格基础值+15%
- 同一商店内每次重roll价格+20%

**机制2：金币衰减**
- 跨层时金币保留，但超过上限的部分按比例衰减
- 金币上限：`gold_cap = 500 + floor_index * 200`（层1:700, 层2:900, 层3:1100, 层4:1300, 层5:1500）
- 超出部分：`excess_gold = current_gold - gold_cap`，衰减后 `actual_gold = gold_cap + excess_gold * 0.5`

**机制3：死亡重置**
- 死亡后金币全部丢失（Roguelike核心）
- 但通过解锁系统可保留"银行"中的部分金币（见3.5.8跨局系统）

### 3.5.7.4 跨层经济平衡

**设计目标：** 单局结束时玩家应花费约80-90%的金币，略有结余但不富裕

**平衡手段：**

| 层级 | 预期收入 | 预期支出 | 结余 |
|------|----------|----------|------|
| 层1 | 260 | 150-200 | 60-110 |
| 层2 | 350 | 250-300 | 50-100 |
| 层3 | 510 | 400-480 | 30-110 |
| 层4 | 640 | 550-620 | 20-90 |
| 层5 | 620 | 550-600 | 20-70 |

**调整规则：**
- 若玩家金币 > 当前层cap的80%：事件房金币选项收益-30%
- 若玩家金币 < 当前层cap的20%：事件房金币选项收益+30%，敌人掉落+20%

```python
def get_gold_adjustment(current_gold, floor_index):
    cap = 500 + floor_index * 200
    ratio = current_gold / cap
    if ratio > 0.8:
        return 0.7  # 收益-30%
    elif ratio < 0.2:
        return 1.3  # 收益+30%
    else:
        return 1.0
```

**核心公式：** 难度 = 基础难度 × 层级系数 × 房间深度系数 × 时间系数

```
effective_difficulty = base_difficulty[floor] * depth_mult * time_mult

base_difficulty = {1: 1.0, 2: 1.5, 3: 2.2, 4: 3.0, 5: 4.0}

depth_mult = 1.0 + (room_index_in_floor / total_rooms_in_floor) * 0.3
# 房间越深，难度越高。最深房间比第一个房间高30%

time_mult = 1.0 + (seconds_in_floor / 600) * 0.15
# 每10分钟在本层停留，难度上升15%。最高0.45（30分钟后封顶）
time_mult = min(time_mult, 1.45)
```

```
enemy_hp = base_hp[floor] * (1 + 0.05 * rooms_cleared_in_floor)
```
