# Plane Walker 深度收敛与系统职责设计

**版本**: v1.1  
**日期**: 2026-05-25  
**定位**: 本文档是所有玩法、成长、数值和内容设计的上层约束。若其他文档与本文档冲突，以本文档为准。

---

## 0.1 设计收敛目标

当前版本从"内容广度"收敛到"可感知策略深度"。首发版本不追求系统数量最大化，而追求玩家在每局中能清楚回答三个问题：

1. 我现在的核心打法是什么？
2. 下一次选择会让我打法发生什么变化？
3. 我承担的风险换来了什么新的操作空间？

**首发体验目标**：

| 维度 | 收敛后目标 |
|------|------------|
| 地牢长度 | 5层，每层6-9个房间 |
| 单局时长 | 30-45分钟 |
| 首发道具池 | 40-60个高质量道具 |
| 首发核心流派 | 8个可识别流派 |
| 局外数值贡献 | 最终战斗力的15-25% |
| 局内构筑贡献 | 最终战斗力的75-85% |
| 玩家单次选择负担 | 2-3个清晰选项，不要求查表理解 |

## 0.2 四个深度支柱

游戏深度只从以下四个支柱产生。新增系统若不能强化其中至少一个支柱，应降级、合并或移除。

### 0.2.1 时间掌控深度

时间技能不是"强力按钮"，而是改变站位、输出窗口和风险承担方式的战斗语法。

| 时间技能 | 深度定位 | 玩家应做出的决策 |
|----------|----------|------------------|
| 时间停止 | 制造爆发窗口 | 现在冻结是为了安全输出，还是等Boss露弱点后爆发？ |
| 时间回溯 | 预先布置收益 | 我要在哪里留下过去位置，才能把回溯变成攻击/诱导/自救？ |
| 时间加速 | 压榨节奏 | 我要用更高风险换更短击杀时间，还是保留能量应对失误？ |
| 时间裂隙 | 地形与路径控制 | 我要把敌人引入裂隙、切割战场，还是保护自己撤退路线？ |

### 0.2.2 武器节奏深度

每把武器回答一个不同的操作问题，后期Build不能把所有武器都变成同一种高频触发器。

| 武器 | 核心问题 | 强化方向 |
|------|----------|----------|
| 剑 | 我能否在正确窗口反击？ | 完美格挡、反击爆发、短窗口输出 |
| 弓 | 我能否用站位换蓄力收益？ | 蓄力、穿透、远程弱点规划 |
| 枪 | 我能否管理弹药节奏？ | 完美换弹、弹幕窗口、爆发轮次 |
| 杖 | 我能否组合正确法术？ | 法术顺序、区域控制、时间异常 |
| 拳套 | 我能否维持连击压力？ | 连击阶梯、贴身机动、低容错高收益 |

### 0.2.3 Build草拟深度

玩家应该在第2层结束前看出"这局像什么流派"，第3层开始主动找补强件，而不是被大量随机数值淹没。

首发只锁定8个核心流派，每个流派由以下结构定义：

- 3个启动件：拿到任意1-2个即可提示方向。
- 2个收益件：让流派效率明显提高。
- 1个风险件：提供高上限但改变生存方式。
- 1个Boss应对方式：确保流派不是只会清小怪。

| 流派 | 核心玩法 | Boss应对方式 |
|------|----------|--------------|
| 冻结爆发 | 用时间停止/减速创造短爆发窗口 | 冻结转化为弱点暴露/后摇延长，而非硬控Boss |
| 回溯残影 | 预设回溯路径，留下残影输出或诱导 | 回溯路径穿过Boss弱点时触发额外伤害 |
| 裂隙陷阱 | 放置裂隙切割敌群和弹幕 | 裂隙可减速Boss弹幕、拉长安全窗口 |
| 加速连击 | 用时间加速压榨连击和击杀节奏 | 加速期间打满连击触发短暂破防 |
| 低血虚无 | 控制血线换伤害和吸血 | 低血状态获得更清晰的Boss预警或处决窗口 |
| 完美格挡 | 防御动作转化为反击资源 | 完美格挡Boss关键招式可制造反击窗口 |
| 弹幕穿透 | 利用穿透、弹药和弱点连锁 | 穿透命中场地核心或弱点获得额外弹药收益 |
| 分身召唤 | 残影/分身复制动作或牵制敌人 | 分身可诱导Boss面向，但不能替玩家承受所有机制 |

## 0.3 系统职责边界

为避免重复成长，每个系统只负责一个主要职能。

| 系统 | 主要职责 | 不应该承担的职责 |
|------|----------|------------------|
| 道具 | 触发器、弹幕、残影、位移、特殊规则、流派启动件 | 大量直接加ATK/HP/暴击的基础数值 |
| 祝福 | 强化时间技能或武器流派，让既有打法更专精 | 替代道具成为独立Build池 |
| 诅咒 | 高风险高回报，改变打法约束 | 简单的"+伤害/-生命"倍率交易 |
| 天赋 | 本局路线选择，确定中长期打法方向 | 细碎属性点、可无限叠的数值成长 |
| 魂祭坛 | 小幅补短板，帮助当局继续推进 | 成为核心Build来源或主要DPS成长来源 |
| 装备强化 | 低幅度长期熟悉感和武器偏好表达 | 让玩家靠局外数值碾压通关 |
| Meta解锁 | 解锁选项、便利性、信息、流派入口 | 大幅永久ATK/HP/DEF堆叠 |

## 0.4 局外成长约束

局外成长提供"下次我能尝试更多东西"的动力，而不是"下次我数值更高所以赢"。

| 项目 | 收敛后上限 |
|------|------------|
| 角色等级有效数值 | ATK +15%, HP +20%, DEF +15%, SPD +8% |
| 单武器永久强化 | 最高+5，累计ATK +25%以内 |
| Meta直接战斗数值 | 单项不超过5%，总直接战斗收益不超过15% |
| 局外总战斗收益 | 常规场景15-25%，极限满收集不超过30% |

优先把Meta节点设计成：

- 解锁新武器、新角色、新道具池。
- 增加重roll、预览、图鉴提示、训练功能。
- 开启新的诅咒、祝福、事件或流派入口。
- 提供新手保护和信息透明，而不是直接放大伤害。

## 0.5 内容规模策略

首发版本采用"小池高辨识度"，后续版本再扩展数量。

| 内容 | 首发目标 | 扩展目标 |
|------|----------|----------|
| 被动道具 | 40-45 | 100+ |
| 主动道具 | 8-10 | 20+ |
| 祝福 | 25-30 | 45+ |
| 诅咒 | 15-18 | 30+ |
| 天赋 | 5路线 × 3层核心节点 | 5路线 × 5层完整节点 |
| 敌人 | 18-22种 | 27+ |
| Boss | 5个 | 5个+变体/挑战模式 |

新增内容优先级：

1. 能启动或补强8个核心流派。
2. 能强化时间掌控或武器节奏。
3. 能制造新的风险-回报决策。
4. 纯数值内容只作为低稀有度填充，且数量受控。

## 0.6 Boss与时间技能交互原则

Boss不应大量免疫时间技能。Boss可以拥有抗性、递减和反制，但每个时间技能都必须有正向用途。

| 时间技能 | Boss交互原则 |
|----------|--------------|
| 时间停止 | 不长时间硬控Boss，但可延长后摇、暴露弱点、冻结召唤物或弹幕 |
| 时间回溯 | 不简单抵消Boss伤害，应奖励预设路径、残影诱导和回溯穿越弱点 |
| 时间加速 | 不只是增伤，应允许玩家压缩机制处理时间，打满连击触发破防 |
| 时间裂隙 | 不被Boss随手摧毁，应影响弹幕速度、Boss路径、场地机关或弱点窗口 |

设计验收标准：每个Boss至少列出4条"玩家如何用时间技能打得更聪明"的策略。

---

## 0.7 文档一致性规则

1. 首发主线统一为5层，不再使用10层经济或数值曲线作为默认口径。
2. 10层、200+道具、完整75+天赋等内容只作为DLC/EA扩展目标，不作为首发默认设计。
3. 若系统文档出现重复数值成长，以职责边界表为准进行削弱或合并。
4. 所有新增道具、祝福、天赋、诅咒都必须标注其服务的核心流派或明确写"通用补短板"。
